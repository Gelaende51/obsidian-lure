## שביל הניווט בכותרת

הנתיב המלא של ההערה בתוך הכספת מחליף את שם הקובץ החשוף בסרגל כותרת התצוגה — השורה שמתחת לשורת הכרטיסיות, זו שנושאת גם את כפתורי הקדימה והאחורה.

שני דברים בשורה ניתנים ללחיצה, ו**שם התיקייה פותח את הרשימה** קובע מי עושה מה:

| | שם התיקייה | המפריד שאחריו |
| --- | --- | --- |
| **פעיל** (ברירת מחדל) | בוחר את התיקייה הזו לעריכה | פותח את התיקייה |
| **כבוי** | פותח את התיקייה | יורד לתוך אותה תיקייה |

"פותח את התיקייה" פירושו כל מה שלחיצה על אותו מקטע עושה ב‑Obsidian נקי. בלי תוסף שמאזין שם, התיקייה מוצגת בסרגל הצד של סייר קבצים — מודגשת, ופרושה כדי להראות את תוכנה.

במקום שהערת התיקייה היא זו שאתם כבר קוראים, הלחיצה חושפת את התיקייה במקום זאת — אין דבר לפתוח שאינו כבר על המסך, וזה מה שהלחיצה השנייה תמיד סימלה.

עם [Folder notes](obsidian://show-plugin?id=folder-notes) מותקן, אותה לחיצה פותחת במקום זאת את הערת התיקייה, **בכל עומק**: ההערה נפתרת כאן על פי המוסכמה של אותו תוסף, במקום להשאיר לו את המענה. אותו תוסף מזהה רק תיקיות שהוא סימן, מה שבנתיב עמוק מתיקייה אחת אינן אף אחת מהן, כך שהלחיצה שפתחה הערה של תיקייה בשורש הייתה בעבר לא עושה דבר בעומק. שני תוספי הערות-תיקייה האחרים אינם מפרסמים מוסכמה לקריאה ומעולם אינם תובעים לעצמם את השורה, ולכן עם אלה המפריד חושף את התיקייה כרגיל. זהו התוסף היחיד מבין תוספי הערות-התיקייה שנמצא כטוען לעצמו את נתיב הכותרת; [Folder Note](obsidian://show-plugin?id=folder-note-plugin) ו‑[create folder notes with dropdown](obsidian://show-plugin?id=create-folder-notes-with-dropdown) מנהלים הערות תיקייה אך אינם מאזינים ללחיצה על שביל הניווט, ולכן עם אלה המפריד חושף את התיקייה כרגיל. ראו [תאימות](../compatibility.md#verified-against).

מפריד **מקבל קו תחתון רק כאשר לתיקייה שלפניו יש בפועל הערת תיקייה**, כך שהקו התחתון הוא הבטחה שיש שם משהו לפתוח — בכל עומק כאשר [Folder notes](obsidian://show-plugin?id=folder-notes) פועל, מכיוון שההערה נפתרת כאן במקום להיות מסומנת על ידי אותו תוסף. במקום שבו זה לא התוסף הפועל, שום דבר אינו מקבל קו תחתון ושום דבר אינו נפתח: המפריד חושף, כפי שהוא עושה כשאין תוסף הערות-תיקייה כלל. כל מפריד נשאר ניתן ללחיצה בכל מקרה — אחד בלי קו תחתון חושף ופורש את התיקייה שלו בסרגל הצד, מה שסמן העכבר עדיין מסמן. הקו התחתון עובר משם התיקייה בו־זמנית: כאשר ההחלפה פעילה, השם פותח את הרשימה, כך שסימונו כקישור להערה יהיה שקר.

**מצב שינוי שם/העברה גובר על שניהם**, מה שלא תאמר ההגדרה: שום דבר בשורה אינו פותח תיקייה כל עוד העברה ממתינה, כי פתיחה תזנח את ההעברה. שמות התיקיות נבחרים לעריכה והמפרידים יורדים — שניהם דרכים לבחור יעד — והקו התחתון נעלם כדי להראות שהפתיחה מושהית.

**שורש הכספת** הוא המקטע היחיד שאינו מקטע נתיב. אין לו הורה שממנו למנות אחים, ולכן הוא פותח במקום זאת את [רשימת המיקומים](#עיון-מחוץ-לכספת) — הכספות האחרות שלכם, תיקיית הבית, שורש מערכת הקבצים והכוננים המחוברים.

## המפריד של הכספת עצמה

המפריד מיד אחרי שם הכספת מייצג את הכספת עצמה ולא
תיקייה, ולכן הוא עושה מה שאף מפריד אחר אינו יכול:

| | לחיצה ראשונה | לחיצה הבאה |
| --- | --- | --- |
| **עם תוסף דף-פתיחה** (דף שמקדם את פניכם כשנפתח Obsidian) | פותח את הדף הזה בחלונית הזו | מקפל את עץ הקבצים |
| **בלעדיו** | מקפל את עץ הקבצים | מחזיר בדיוק את מה שהיה פתוח |

לחיצות רגילות, לא לחיצה כפולה: ברגע שהדף פתוח, אין למפריד
דבר נוסף לפתוח, כך שהלחיצה הבאה היא הקיפול — כמה זמן שלא ייקח
לכם.

הוא **מודגש בקו תחתון** כאשר יש דף פתיחה לפתוח, וזו אותה
הבטחה שמפריד של תיקייה נותן: יש שם משהו. הקיפול הוא מתג —
הלחיצה הבאה משחזרת את התיקיות שהיו פתוחות, ורק אותן, כך שעץ
שסידרתם לא הולך לאיבוד ממבט חטוף במשהו אחר.

## חלונית ללא קובץ

כרטיסייה ריקה, הגרף וכל דבר אחר שלא נוקב בשם קובץ מקבלים שורה
משלהם: הכספת, ואז מקטע אחד שאומר מה החלונית מכילה.

```
my-vault / :blank      a new tab
my-vault / :graph      the graph, local or global
my-vault / :<type>     anything else with no file
```

**רשימת שורש הכספת עצמה** מציעה גם דפים אלה, מתחת לתיקיות
ולהערות שבאמת נמצאות בה: בחירת `:graph` או `:search` שם גורמת
לחלונית לפתוח את התצוגה הזו, בדיוק כמו שבחירת הערה פותחת את
ההערה. אילו דפים קיימים נקרא מ‑Obsidian ולא נכתב כאן — כל תצוגה
שלא קיימת כדי להציג קובץ, כך שתוסף שרושם תצוגה משלו (כרטיסיית
בית, לוח שנה) מופיע בלי שהתוסף הזה יודע עליו דבר. תצוגות שזקוקות
לקובץ — Markdown, PDF, תמונות, קנבסים, בסיסי נתונים — אינן מוצעות:
אין להן דבר להציג.

הנקודתיים הן העיקר — אף קובץ או תיקייה לא יכולים להיקרא
`:graph`, כך שהשורה לא יכולה להיות מבולבלת עם נתיב שניתן לפתוח.
התווית מגיעה מסוג התצוגה ולא מהניסוח של Obsidian עצמו, כך שהיא
נקראת אותו הדבר בכל שפת ממשק, וסיומת `-view` בסוף מושמטת: תוסף
כרטיסיית-בית רושם את התצוגה שלו בתור `home-launcher-view`, והשורה
אומרת `:home-launcher`.

לחיצה על המרחב הריק, או על התווית עצמה, **פותחת את השדה בשורש
הכספת**: הקלידו נתיב ו‑<kbd>Enter</kbd> פותח אותו באותה החלונית
ממש, עם אותה השלמה, אותה רשימה ואותו שדה אדום שמציע ליצור את מה
שעדיין לא קיים. כרטיסייה ריקה היא מקום טוב להקליד לאן אתם רוצים
ללכת, וזו הסיבה שהיא קיימת.

התווית היא תווית ותו לא: בלי רשימה, בלי גרירה, בלי שינוי שם.
חלוניות בסרגלי הצד נשארות לגמרי ללא נגיעה — חלונית קישורים נכנסים
שומרת על הכותרת ש‑Obsidian נותן לה.

קנבסים, PDF, תמונות ובסיסי נתונים אינם זקוקים לכל זה. הם קבצים,
ולכן הם מקבלים סרגל נתיב רגיל.

## לחיצה על מקטע: החלפתו באח

לחיצה על שם תיקייה בוחרת את **שם התיקייה הזו** בשדה טקסט ופותחת את רשימת התיקייה **שכבה אחת מעל** — ההורה שלה. הקלדה או בחירת פריט מחליפות את התיקייה הזו באח ומשאירות את כל מה שמתחתיה ללא נגיעה, כך ש‑`Projects/2026/Kickoff.md` → לחיצה על `2026` → בחירת `2025` נותנת לכם `Projects/2025/Kickoff.md`.

לחיצה על **שם ההערה** פועלת באותה דרך כלפי התיקייה שלה, ובוחרת את השם **בלי הסיומת** — שינוי שם הוא העריכה הנפוצה, והקלדה ישירות מעל בחירה שכללה את `.md` נהגה בעבר לשנות בטעות את סוג הקובץ. הסיומת נשארת גלויה במרחק לחיצה אחת: <kbd>→</kbd> מגיע אליה, והלחיצה הכפולה שמרחיבה לכל השורה לוקחת את כולה.

הלחיצה על התיקייה כבר בחרה מקטע אחד, ולכן **לחיצה נוספת אחת** מרחיבה את הבחירה לכל השורה — התיקייה הזו *וכל* מה שמתחתיה — והקלדה מחליפה אז את שארית הנתיב בבת אחת. עובד אותו דבר בניווט ובמצב שינוי שם/העברה.

זה חל רק כהמשך ללחיצה שפתחה את השדה. ברגע שהשתמשתם בשדה, הוא מתנהג ככל שדה טקסט אחר: לחיצה ממקמת את הסמן, לחיצה כפולה לוקחת מילה, לחיצה משולשת לוקחת את השורה.

בכל מקרה שארית הנתיב נשארת גלויה סביב השדה, כשבבות לפניה וכטקסט לא נבחר אחריה, כך שהנתיב המלא לעולם לא נעלם מהכותרת. הקלידו כדי להחליף את הבחירה, או לחצו <kbd>→</kbd> כדי לשמור עליה ולערוך משם. הרשימה מציגה את כל התיקייה בלי קשר למה שממולא מראש; היא מתחילה לסנן רק כאשר אתם באמת מקלידים.

## ירידה באמצעות המפריד

לחיצה על מפריד (כאשר **שם התיקייה פותח את הרשימה** כבוי) יורדת לתיקייה שלפניו: הרשימה מציגה את תוכן *אותה* תיקייה, ושארית הנתיב נפתחת מסומנת בשדה. בחירת תיקייה מוסיפה אותה לשובל הנתיב ופותחת מיד את הרשימה הבאה, כך שאפשר ללחוץ במורד עץ בלי לעזוב את שורת הכותרת.

## הרשימה נפתחת במקום שבו אתם נמצאים

הרשימה נפתחת על הפריט שבו אתם עומדים — ההערה ששורת ניווט זו
שייכת לה, או, כאשר לחיצה על תיקייה הציגה את ההורה שלה, אותה
תיקייה — במקום על השורה הראשונה. בתיקייה של מאתיים הערות
השורה הראשונה רחוקה מכם מאוד.

**גלגלת מעל שם פותחת את הרשימה שלו ומטיילת בה.** הסיבוב הראשון פותח
את אותה רשימה שהלחיצה על השם פותחת, וכל סיבוב אחרי כן מזיז את ההדגשה
שורה אחת, ומכניס את מה שאתם מצביעים עליו לשדה בדיוק כפי שחצים
עושים — כך שאח ניתן למצוא ולקחת בלי המקלדת. סיבוב כלפי הקצה
בכל כיוון מחזיר לכם את הטקסט שלכם. שורה עם יותר נתיב מחלונית עונה
לגלגלת בגלילה הצדה במקום זאת, וזו הקריאה שמנצחת כל עוד היא רלוונטית.

הרשימה **גבוהה ככל שהחלון מאפשר**. Obsidian מגביל את רשימות ההצעות
שלו ל‑300 פיקסלים לא משנה מה נמצא מתחתיהן; רשימה זו יורדת עד תחתית
החלון, נעצרת כמה פיקסלים לפני הקצה, וגוללת רק כאשר בתיקייה יש
יותר מזה. היא **לא רחבה יותר מסרגל הנתיב**: שם שאינו נכנס
מקוצר באותה דרך שהשורה מקצרת אותו, ומוצג במלואו כשאתם מצביעים עליו.

מעבר ברשימה **מכניס את מה שאתם מצביעים עליו לשדה**, בין אם במקש חץ
ובין אם ברחיפה — במקום המקטע שערכתם, כשהשארית של הנתיב נשארת
עומדת — כך שהשורה שאתם נמצאים בה היא גם הנתיב שהייתם מקבלים.

שארית הנתיב מוצגת **רק עד כמה שהיא קיימת תחת מה שאתם מצביעים
עליו**. כשעומדים בתיקייה אחת עם `2026/note.md` מאחורי המקטע שאתם
עורכים, הצבעה על תיקייה שיש בה `2026` עם `note.md` בתוכה מציגה
הכול; אחת שיש בה `2026` בלי הערה מציגה `2026`; אחת שאין בה אף
אחד מהם לא מציגה דבר אחרי השם כלל, וכך גם קובץ, כי דבר לא חי
תחתיו. **מה שהקלדתם** שומר על נתיבו המלא בזמן שאתם מקלידים
אותו, כמה שלא יהיה קיים ממנו עדיין — שם שהוקלד רק בחלקו אינו
החלטה. קביעת שם היא החלטה, ומה שלא ניתן להגיע אליו ממנה נחתך
בנקודה הזו; התיקיות שאתם יוצרים הן אלה שאתם מקלידים *אחריה*, וזה
המקום שבו <kbd>Enter</kbd> יוצר אותן.
הטקסט שהקלדתם נשמר: מעבר **אל מעבר לכל קצה של הרשימה** — כלפי מעלה
מהפריט הראשון, או כלפי מטה מהאחרון — משחרר אותו ומחזיר את הטקסט
שלכם, בלי שום דבר מודגש. השדה הוא עצירה בטבעת ככל פריט, כך שסבב
עובר דרכו במקום לקפוץ מהשורה האחרונה לראשונה, ולחיצה מתמשכת משם
נושאת אתכם לקצה השני.

הסרת **הסמן מהרשימה** מחזירה גם את הטקסט שלכם — ומעבירה
את ההדגשה בחזרה למה שהחזיק בה לפני שהעכבר הגיע: הפריט שאליו הגעתם
בחצים, המוצג שוב בשדה, או זה שהרשימה נפתחה עליו כי שם אתם נמצאים.
ריחוף הוא דרך להסתכל ולא לבחור, כך שהעברת סמן על פני הרשימה לא
עולה לכם דבר.

הרשימה עצמה לא משתנה בזמן שאתם עוברים בה — היא ממשיכה לסנן לפי
מה שהקלדתם, לא לפי מה שהוצג בתצוגה מקדימה בשדה — כך שהפריט
שמתחתיכם לעולם לא זז מתחת ללחיצה הבאה. הקלדה מחליפה את התצוגה המקדימה
ומסננת כרגיל.

**מה שהיא מסננת לפיו הוא המקטע שאתם עורכים**, לא כל מה שבשדה.
לחיצה על תיקייה משאירה את שארית הנתיב שם מאחורי השם שאתם משנים,
כך שסינון לפי כולו יחפש ילד בשם `2026/Kickoff.md` ולא ימצא דבר —
הרשימה תיסגר בהקשה הראשונה שלכם לא משנה מה תקלידו. **הסיומת גם היא
מושמטת מכך**, כל עוד הסמן נמצא לפני הנקודה: לחיצה על שם הערה בוחרת
את הגזע ומשאירה את `.md` מאחוריה, כך שהקלדת אות אחת גורמת לשדה
לקרוא `a.md`, וזה לא מה שאתם מחפשים. הזיזו את הסמן מעבר לנקודה
והסיומת נספרת ככל דבר אחר. שם שבאמת לא תואם דבר עדיין סוגר את
הרשימה, כי רשימה ריקה היא התשובה הכנה.

תצוגה מקדימה **מחליפה את המקטע ההוא בלבד ומשאירה את שאר הנתיב
כמות שהוא**: הצבעה על תיקייה שואלת מה אם השלב הזה יהיה זה, לא
לזרוק את הנתיב. הסרת הסמן מהרשימה משחזרת את הטקסט *ואת* הבחירה
שהייתה לכם, כך שההקשה הבאה מחליפה את מה שהייתה אמורה להחליף לפני
שהסתכלתם.

## פריטי הרשימה הם שורות אמיתיות של מנהל קבצים

כל קובץ ותיקייה ברשימה מתנהגים כמו השורה שלהם בסייר קבצים:

- **קליק ימני** לתפריט ההקשר הזהה שסייר קבצים נותן, פריט לפריט — כולל אלה שתוספים אחרים מוסיפים. תיקייה מציעה *הערה חדשה*, *תיקייה חדשה*, *קנבס חדש*, *בסיס נתונים חדש*, *יצירת עותק*, *העברת תיקייה אל…*, *חיפוש בתיקייה*, *העתקת נתיב*, *הצגה בסייר המערכת*, *שינוי שם…* ו*מחיקה*; קובץ מציע את המקבילה שלו, כולל *פתיחה ביישום ברירת המחדל*.
- **גרירה** של פריט לכל מקום ש‑Obsidian מקבל בו קובץ: לתוך עורך כדי להוסיף קישור, על תיקייה בסייר קבצים כדי להעביר אותה, על שורת הכרטיסיות כדי לפתוח אותו.

ניסוח התפריטים מגיע מהתרגומים של Obsidian עצמו, ולכן הוא תואם לשאר היישום בכל שפה.

## הקלדת נתיב

- לחיצה על **השטח הריק** לפני שביל הניווט או אחריו פותחת שדה טקסט על הנתיב כולו *ומציגה את הפתק בסייר הקבצים*, כך שהעץ עוקב אחר החלונית בלי מחווה נוספת. השדה **סופר את הלחיצות שלכם**: אחת בוחרת את הנתיב בלי הסיומת, שתיים בוחרות אותו עם הסיומת, שלוש בוחרות את הנתיב שהמכונה מכירה. לחיצה על **שם הקובץ** נספרת באותו אופן אך מתחילה שלב אחד נמוך יותר, על השם עצמו: אחת בוחרת אותו בלי הסיומת, שתיים עם הסיומת, ושלוש מרחיבות לנתיב כולו *מתיקיית הכספת שלכם* — הצורה שקישור או חיפוש רוצים, ולא זו של המכונה. לחיצה רביעית מגיעה לזו.
- **הספירה שייכת לרצף שפתח את השדה.** ברגע שהוא פג — השהיתם, הקלדתם, או לחצתם פעם אחת במקום כלשהו בטקסט — השדה הוא שדה טקסט רגיל ככל שדה אחר, ולחיצה כפולה בו בוחרת את המילה שמתחת למצביע בדיוק כמו בכל מקום אחר. הקלידו על מה שנבחר, או ערכו במקום. (לחיצה על שם הקובץ עצמו בוחרת רק את שם הקובץ; ראו למעלה.) לחיצה ימנית על אותו שטח **מעתיקה** את אותם השלושה, בלחיצה שנייה, שלישית ורביעית — כפתור אחד מציג אותם, האחר לוקח אותם. לחיצה ימנית **בודדת** פותחת את הנתיב כשכולו נבחר ומציעה מה אפשר לעשות בו: גזירה, העתקה, הדבקה, בחירת הכול, במילותיה של Obsidian עצמה.
- **לחצו לחיצה אמצעית על השטח הריק** כדי להדביק על הנתיב: השדה נפתח על הנתיב כולו *משורש הכספת*, כך שהלוח מחליף אותו כולו, ומה שנוחת נבחר. <kbd>Enter</kbd> אז עובר לשם.
- **<kbd>Ctrl</kbd>+לחיצה על השטח הריק** כדי לפתוח את הפתק הזה שוב בכרטיסייה משלו, המהבהבת בסייר הקבצים כדי שהכרטיסייה השנייה לא תיחשב בטעות לראשונה. על **שם הכספת**, <kbd>Ctrl</kbd>+לחיצה או לחיצה אמצעית פותחת כרטיסייה שלא מחזיקה דבר, עומדת בשורש הכספת כשהרשימה כבר מוצגת — מקום להקליד ממנו נתיב מאפס.
- הקלדה בזמן ששביל ניווט מוצג הופכת את המקטע האחרון לשדה קלט קטן עם השלמה אוטומטית חיה המוגבלת לתיקייה הנוכחית.
- **אפשר להקליד נתיב משורש מערכת הקבצים.** `/` לפני שדה ריק פותח כזה במקום להשלים שלב, כל לוכסן אחריו שייך לו, ו-`~` היא תיקיית הבית שלכם. כל עוד השדה מחזיק נתיב כזה, הרשימה מציגה את המכונה ולא את הכספת, והמקטע הפותח של השורה זז הצידה — מה שבשדה מתחיל בשורש ואומר זאת. כשה*גישה לקבצים חיצוניים* כבויה, הרשימה עומדת ריקה במקום זאת, כי <kbd>Enter</kbd> היה מסרב לנתיב בכל מקרה.
- **אפשר להקליד עמוד, ולא רק לבחור אותו.** `:graph`, `:search`, או מה שהתוספים שלכם רושמים — התוויות שה[רשימה של שורש הכספת](#חלונית-ללא-קובץ) מציעה. הקלדת נקודתיים בכל מקום מזמנת אותם, שכן אף שם לא יכול להכיל אחת, ו-<kbd>Enter</kbd> פותח את התצוגה הזו בחלונית זו. `:graph` שמוקלד **בתוך תיקייה** פותח את הגרף של אותה תיקייה — הגרף מסונן ל-`path:"that/folder"` בתיבת החיפוש שלו, כאילו הוקלד שם; בשורש הכספת זה הגרף כולו. <kbd>Tab</kbd> משלים את השם כפי שהוא משלים שם של תיקייה — ולוקח איתו את כל מה שהשדה החזיק עד כה, שכן עמוד אינו בתוך שום תיקייה ושום דבר לא חי מתחתיו. לחיצה על התווית בעמוד כזה פותחת את השדה כשהוא כבר מחזיק אותה.
- **מה ש-<kbd>Tab</kbd> היה כותב מוצע תוך כדי הקלדה.** במקום שבו כל צאצא שמתחיל במה שהקלדתם ממשיך להסכים לזמן מה, ההסכמה הזו מופיעה אחרי הסמן, נבחרת; במקום שבו הם מפסיקים להסכים, הצעד לכיוון הראשון מביניהם עושה זאת — או לכיוון השורה שאליה חיציתם, שכן זו זו ש-<kbd>Tab</kbd> היה מכוון אליה. הקלדה על שם משאירה את הסיומת שלו במקום ומציעה לפניה, ותיקייה שנכנסתם אליה זה עתה מציעה את הצעד הראשון שלה, כך שאין מצב שבו שום דבר לא מוצע ו-<kbd>Tab</kbd> כותב משהו בכל זאת. הקלידו את האותיות הללו והן נבלעות אחת בכל פעם; הקלידו כל דבר אחר והצעת נעלמת. <kbd>Tab</kbd> או <kbd>End</kbd> לוקח אותה כולה, <kbd>→</kbd> לוקח אות אחת ממנה, <kbd>Backspace</kbd> מחזיר אותה בלי לגעת באות שהקלדתם, ושום דבר לא מוצע שוב עד שתקלידו — כך שתמיד יש דרך החוצה משם שלא רציתם. אחרי לחיצה על <kbd>Tab</kbd> הצעד הבא מוצע מיד, כמו אחרי אות שהוקלדה. מה שהרשימה מציגה מסונן לפי מה **שאתם** הקלדתם, לעולם לא לפי מה שהוצע.
- **ההצעות מתעלמות מרישיות/קטנות.** `sch` מציעה `Schemes`, מאוית כפי שהשם מאוית; ביטול ההצעה מחזיר לכם את האותיות שלכם כפי שהקלדתם אותן. במקום שבו גם `Test` וגם `test` קיימים, זו המאוית כפי שהקלדתם מוצעת.
- בשדה החלק המוצע פשוט **נבחר**. הרשימה היא המקום שבו הוא מפורש: כל שורה מציגה את החלק בה **שתאם למה שהקלדתם במודגש**, בכל מקום בשם שבו התאים — `kick` מוצא את `Weekly kickoff` ואומר זאת. **שמות שמתחילים במה שהקלדתם מופיעים ראשונים**, לפני אלה שרק מכילים זאת, ומסומנים בקו לאורך קצהם: **כחול** במקום שבו הם חולקים יותר ממה שהקלדתם, כך של-<kbd>Tab</kbd> יש מה להוסיף עבור כולם, ו**ירוק** על הענף שההצעה לוקחת במקום שבו הם נפרדים — `te` עם `test1`, `test2`, `text1` ו-`text2` מציעה `te`+`st`, כך ששתי שורות ה-`test` ירוקות ושתי שורות ה-`text` שומרות על הקו הרגיל. כל אחת מהן **מסמנת בקו תחתון את הצעד ש-<kbd>Tab</kbd> היה לוקח לכיוונה**, לא רק את זו שמוצעת, והקו התחתון עוקב אחר ההצעה כשהיא משתנה.
- **הקלדה משחררת את השורה המודגשת.** הרשימה נפתחת על הערך שבו אתם עומדים, אך ברגע שאתם מקלידים מדובר במקום אחר, והדגשה שאף אחד לא שם שם נקראת כבחירה שכבר נעשתה.
- ההצעה היא תמיד רק טקסט לפניכם: האותיות שהקלדתם נשארות מאוית כפי שהקלדתם אותן בזמן שאתם מקלידים, ולקיחת ההצעה כותבת מחדש את השם כפי שהתיקייה מאייתת אותו, כי נתיב חייב להתאים לדיסק. `sk` + <kbd>Tab</kbd> מגיע ל-`Skyline`, לא ל-`skyline`.
- **השדה לובש את הצבע של מה שהוא מכנה**, אותו צבע כמו השורה שלו ברשימה: סגול לפתק, כולל הפתק של תיקייה עצמה, כתום לכל מה שאינו פתק, כחול לפתק שבו אתם נמצאים. השורה שממנה השדה לוקח את הצבע היא זו הנקראת בדיוק כמו מה שהקלדתם, ואם לא — השורה המודגשת, ואם לא — הראשונה שההקלדה שלכם עדיין מובילה אליה.
- **השדה הופך אדום ברגע ששום דבר לא עונה למה שבו** — לא קובץ, לא תיקייה, ואף שורה ברשימה שעדיין מובילה אליו. מכאן <kbd>Enter</kbd> יוצר את מה שבשדה במקום לפתוח אותו, והאדום אומר זאת לפני שאתם מבצעים. הוא לעולם לא מופיע לכתובת אינטרנט, שאינה מקום על המכונה הזו לחפש בו. **כל** השדה נצבע ולא רק החלק החסר: שדה טקסט לא יכול לצבוע חצי מהתוכן שלו. במצב העברה/שינוי שם השדה שומר על האדום שלו עבור שם שאינו חוקי — שם, שם שאף דבר לא עונה לו הוא בדיוק העניין. העובדה ששם **כבר תפוס** מטופלת כשמבצעים אותו, עם תיבת דו-שיח ששואלת מה לעשות עם הקובץ שבדרך — ראו [שם שתפוס](#שם-שתפוס): כל שם שהוקלד לכיוון `Notes.md` עובר דרך שמות שיכולים להיות קבצים משלהם, כך שסימונו אות אחר אות היה מזהיר על שם שאיש עוד לא ביקש.
- `/` מבצע את המקטע שאתם מקלידים ויורד לתוכו, שומר על כל מה שמאחוריו — אותו הדבר ש-<kbd>Tab</kbd> עושה כשהוא נכנס פנימה.
- <kbd>Backspace</kbd> בשדה ריק חוזר אחורה לתיקיית האב, פותח מחדש את שמה עם הסמן בסופו. כך גם <kbd>Backspace</kbd> לפני סיומת שנותרה לבדה — שדה שמחזיק רק `.md` לא מכנה דבר — והסיומת הבודדת הולכת איתו.
- **לחיצה על תיקייה בזמן ששדה פתוח מרחיבה אותו לנתיב כולו אחרי אותה תיקייה**, כשהשם של התיקייה עצמה נבחר — אותו הדבר שלחיצה עליה הייתה עושה מהשורה, וכל מה שהשדה החזיק נשמר. מה שבשדה הוא זנב השורה בזמן שהוא פתוח, כך שתיקייה שנלחצת גבוה יותר מחזירה את הנתיב שהסשן הלך בו ולא את זה שממנו הפתק התחיל.
- **חיצה אל מחוץ לחזית השדה מכניסה את התיקייה שלפניו פנימה**, כאילו הנתיב כולו היה שורת טקסט אחת. עם הסמן ממש בהתחלה, <kbd>←</kbd> לוקח את אותה תיקייה לתוך השדה ונוחת בסוף שמה, <kbd>Ctrl</kbd>+<kbd>←</kbd> נוחת בתחילתה, ו-<kbd>Home</kbd> לוקח כל תיקייה עד שורש הכספת — או עד המקום שבחרתם, מחוץ לכספת — בבת אחת. החזיקו <kbd>Shift</kbd> והבחירה נמתחת מעל מה שנכנס. ב-macOS קפיצת המילה היא <kbd>Option</kbd>+<kbd>←</kbd> ו-<kbd>Cmd</kbd>+<kbd>←</kbd> הוא <kbd>Home</kbd>. בכל מקום מלבד החזית אלה מקשי טקסט רגילים. **בזמן שהרשימה מוצגת, <kbd>Home</kbd>, <kbd>End</kbd>, <kbd>PgUp</kbd> ו-<kbd>PgDn</kbd> שייכים לה** — שורה ראשונה, שורה אחרונה, עמוד למעלה, עמוד למטה, כשעמוד הוא מה שהרשימה מציגה, כשהשורה המודגשת שומרת על מקומה על המסך — ומגיעים לטקסט רק לאחר שהיא נסגרה; <kbd>Shift</kbd>+<kbd>Home</kbd> לוקח כל תיקייה גם כשהרשימה פתוחה.
- **הרשימה עוקבת אחר הסמן.** בחרו חלק אחר בנתיב — גררו מעליו, לחצו לתוכו, או חצו לאורכו — והרשימה מציגה את הצאצאים של *אותה* תיקייה, ולא את זו שבה השדה נפתח. התיקייה נספרת מהשבבים בתוספת כל מה שבשדה נמצא לפני הסמן, כך שלחיצה לתוך `Notes.md` בשדה המחזיק `2026/Notes.md` מציגה מה שיש ב-`2026`. הצבעה על שורה כותבת אותה לתוך המקטע שבו הסמן נמצא, והרחקת המצביע מהרשימה מחזירה לכם את הטקסט ואת הבחירה שלכם בדיוק כפי שהיו.
- **גרירת בחירה מחוץ לשדה** ושחרורה במקום אחר לא סוגרת אותו. לחיצה שמתחילה בשדה שייכת לעריכה לא משנה כמה רחוק היא נוסעת; רק לחיצה שמתחילה *מחוץ* לו היא לחיצה החוצה.
- <kbd>Enter</kbd> מבצע — וכשהשדה לא מכנה דבר בכלל, כמו בתיקייה ריקה שבה מעולם לא היה מה להשלים, הוא אומר *No file selected* ונשאר פתוח במקום להיסגר כאילו נבחר משהו. <kbd>Esc</kbd> או לחיצה במקום אחר מבטלת בחזרה לנתיב האמיתי של הקובץ. לחיצה אחת על <kbd>Esc</kbd> מספיקה: היא סוגרת את הרשימה, עוזבת את השדה ומחזירה את המיקוד לפתק, במקום לקחת לחיצה אחת לכל שכבה.

השדה נטול מסגרת — בלי תיבה, בלי גבול — ולכן הוא נקרא כטקסט הנתיב עצמו, והוא גדל מעצמו תוך כדי הקלדה.

## כל חלק בשורה, כפתור אחרי כפתור

כל השורה במבט אחד. עמודת לחיצה ימנית מציגה מה נותנת לכם לחיצה **אחת**; אותו כפתור גם סופר לחיצות, ול[טבלה משלו](#לחיצה-ימנית-לחיצה-אחת-שתיים-שלוש) שלמטה יש את השנייה, השלישית והרביעית. הטבלה הזו מניחה ש**שם התיקייה פותח את הרשימה** פעיל, וזו ברירת המחדל — כשהוא כבוי, שם התיקייה והמפריד מחליפים ביניהם את העמודה הראשונה, כפי שכתוב ב[טבלה שבראש הדף](#שביל-הניווט-בכותרת).

| היכן לוחצים | לחיצה | לחיצה כפולה | <kbd>Ctrl</kbd>+לחיצה, או לחיצה אמצעית | לחיצה ימנית | גרירת משהו לשם |
| --- | --- | --- | --- | --- | --- |
| **שם הכספת** | פותח את רשימת המיקומים — כספות אחרות, בית המשתמש, שורש מערכת הקבצים, כוננים מחוברים. כבוי כברירת מחדל; כשהוא כבוי, חושף במקום זאת את הכספת בסייר הקבצים | מסמן את **כל הנתיב המוחלט**. הרשימה הזו נפתחת כאשר הנתיב כבר נמצא בשדה ורק החלק של הכספת עצמה מסומן; לחיצה שנייה מרחיבה את הסימון לשאר הנתיב. אין מה להרחיב כשהרשימה כבויה | כרטיסייה שלא מכילה דבר, עומדת בשורש הכספת כאשר הרשימה כבר מוצגת — מקום להקליד ממנו נתיב מאפס | תפריט ההקשר של הכספת עצמה: מה אפשר לעשות לכספת ששם המקטע קורא לה | **קובץ** עובר לשורש הכספת. **טקסט** פותח את השדה בשורש, כדי לתת שם לפתק שהוא אמור להפוך אליו |
| **שם תיקייה** | בוחר את התיקייה הזו לעריכה, עם תוכן ההורה שלה מוצג מתחת | מקליד מחדש את התיקייה הזו ואת כל מה שמתחתיה | פותח את התיקייה הזו בכרטיסייה חדשה | תפריט ההקשר של התיקייה הזו — זה של סייר הקבצים עצמו | **קובץ** עובר לתוך התיקייה הזו. **טקסט** פותח את השדה שם, כדי לתת שם לפתק שהוא אמור להפוך אליו |
| **מפריד** | פותח את התיקייה שלפניו — את פתק־התיקייה שלה במקום שתוסף פתקי־תיקייה פועל ואחד כזה קיים, אחרת חושף ומרחיב אותה בסייר הקבצים | **יוצר את פתק התיקייה** של אותה תיקייה ועובר אליו, במקום שתוסף פתקי־תיקייה פועל ולתיקייה עדיין אין כזה. במקום שכבר יש לה אחד, זו פשוט אותה לחיצה בודדת שוב | פתק התיקייה בכרטיסייה חדשה במקום שקיים אחד; אחרת כרטיסייה שעומדת באותה תיקייה עם הרשימה מוצגת | אותו תפריט הקשר של התיקייה שהשם נותן — זה של פתק התיקייה שלה, במקום שיש לה אחד | לסוף פתק התיקייה, במקום שיש לה אחד, לאחר אישור |
| **שם הפתק** | פותח את השם לעריכה — התיקיות נשארות כשבבים לצידו — עם הכול מלבד הסיומת מסומן | מוסיף גם את הסיומת לסימון | פותח את הפתק בכרטיסייה חדשה | תפריט ההקשר של הקובץ — אותו אחד ששורת סייר הקבצים נותנת | לסוף הפתק הזה, לאחר אישור |
| **המרחב הריק** | פותח את **כל הנתיב** לעריכה, מסומן עד לסיומת. התיקיות נכנסות לשדה יחד איתו, וזה מה שהופך את המחווה הזו להקלדה מחדש של נתיב ולא של שם | מוסיף גם את הסיומת לסימון | <kbd>Ctrl</kbd> פותח את הפתק הזה שוב בכרטיסייה משלו, שמוהבהבת בסייר הקבצים כדי שהעותק לא יתבלבל עם הראשון. לחיצה אמצעית *אינה* אותה מחווה: היא מדביקה על הנתיב | מסמן את כל הנתיב ומציע מה אפשר לעשות לטקסט המסומן | |

**הלחיצה השנייה עוקבת אחרי הראשונה.** יצירת פתק תיקייה יושבת על אותו חלק בשורה ש*פותח* את התיקייה ההיא, שהוא המפריד כברירת מחדל ושם התיקייה כשההחלפה כבויה — אותה מטרה שהקו התחתי מסמן, ואותה מטרה שלחיצה אחת כבר מבקשת עבורה את פתק התיקייה. זה מוצע רק כאשר תוסף פתקי־תיקייה פועל, כי פתק תיקייה הוא מוסכמה ולא עובדה על מערכת הקבצים, ורק במקום שלתיקייה עדיין אין כזה. היכן הוא נמצא ואיך הוא נקרא נקראים מתוך ההגדרות של **Folder notes** עצמו, כך שכספת ששומרת את פתקי התיקיות שלה לצד התיקייה, או קוראת להם `_index`, מקבלת את זה בהתאם; הקובץ עצמו הוא תמיד Markdown, וזה מה שפקודת היצירה המובנית של אותו תוסף יוצרת ומה שהוא מוצא, תהיה אשר תהיה סוג הקובץ שהכספת מוגדרת אליו. מצב שינוי שם/העברה מחוץ לתמונה כליל — שום דבר בשורה לא פותח תיקייה בזמן שהעברה ממתינה.

**לחיצות על השם ממשיכות הלאה.** ארבעת השלבים הם אותם ארבעה שמקש שינוי השם עובר, באותו סדר: השם, השם עם הסיומת שלו, הנתיב מהכספת, הנתיב משורש המערכת. כך שלחיצה שלישית מגיעה לנתיב הכספת ורביעית לזה של המכונה — אותם ארבעה דברים ש<kbd>Tab</kbd> מעבר לסוף השדה נותן לכם, ואותם ארבעה שהכפתור הימני *מעתיק* במקום לסמן.

**ריחוף** הוא תשובה בפני עצמו ולעולם לא משנה דבר: שם מקוצר חוזר במלואו כל עוד אתם מצביעים עליו, והסמל בתחילת השורה אומר היכן הכספת נמצאת.

## לחיצה ימנית: לחיצה אחת, שתיים, שלוש

כל יעד בשורה עונה ללחיצה ימנית, וכמה לחיצות אתם נותנים לו קובע מה תקבלו. מכיוון שלחיצה שנייה עשויה עדיין להגיע, הראשונה ממתינה כשליש שנייה לפני שהיא פועלת — המחיר של שימת שלוש מחוות על כפתור אחד.

| היכן לוחצים | פעם אחת | פעמיים | שלוש פעמים |
| --- | --- | --- | --- |
| **שם הכספת** | תפריט ההקשר של הכספת: מה אפשר לעשות לכספת ששם המקטע קורא לה — כולל *Open this vault*, במקום שהכספת ההיא אינה זו שאתם נמצאים בה | מעתיק את שם הכספת | מעתיק היכן הכספת נמצאת — ולחיצה רביעית, היכן הקובץ הפתוח נמצא |
| **מפריד** | תפריט התיקייה ההיא — של פתק התיקייה שלה, במקום שתוסף פתקי־תיקייה פועל ולתיקייה יש אחד | | |
| **שם תיקייה** | תפריט התיקייה ההיא | מעתיק את שם התיקייה | מעתיק אותו ואת כל מה שמימינו |
| **שם הפתק** | תפריט הקובץ — אותו אחד ששורת סייר הקבצים נותנת | מעתיק את השם | מעתיק אותו עם הסיומת שלו |
| **המרחב הריק** | | מעתיק את הנתיב מתיקיית הכספת שלכם, ללא הסיומת | אותו דבר, עם הסיומת |

לחיצה בודדת על **שם הכספת** פותחת את מה שאפשר לעשות למה שהמקטע הזה קורא לו. עבור **הכספת שאתם נמצאים בה**: פתיחתה בחלון חדש, ניהול כספות, העתקת מיקומה, העתקת המזהה שלה, הצגתה במנהל הקבצים שלכם. עבור **כספת אחרת**, שאליה מגיעים דרך רשימת המיקומים, אותו הדבר פחות החלון החדש — שהיה פותח את *הכספת הזו*, לא את ההיא — ובתוספת הדבר האחד שרק כספת שאתם לא נמצאים בה יכולה להציע: **Open this vault**. היא נקראת בפני Obsidian לפי המזהה שלה ולא לפי שם התיקייה שלה, מכיוון ששתי כספות עשויות לחלוק שם אחד. עבור מקום שאינו כספת כלל — תיקיית הבית שלכם, כונן מחובר — אין מזהה להעתיק ואין מה לפתוח, והתפריט אומר זאת על ידי אי-הצעתם.

זה אינו תפריט שלוש הנקודות של Obsidian עצמו, ששייך לחלון ההתחלה ולא ניתן לפתוח אותו מתוך כספת פועלת — אלה אותם פריטים בנויים מחדש, בניסוח של Obsidian עצמו, לקוחים מתוך הפקודות שלו כך שהם מגיעים בשפה שלכם. שלושה מפריטי התפריט ההוא במכוון **אינם** כאן: *rename vault*,‏ *move vault* ו־*remove from list* כולם פועלים על תיקיית הכספת עצמה או על רישום הכספות של Obsidian, ועשיית זאת לכספת שאתם עומדים בתוכה — עם הקבצים שלה פתוחים והצופים שלה פועלים — היא הדרך שבה כספת נשברת. פתחו את מנהל הכספות (*Open another vault*) ועשו אותם שם, במקום שהכספת סגורה.

שני ההעתקים על **המרחב הריק** הם השורה כפי שהיא כתובה — מה שקישור או חיפוש רוצה — ואלה על **שם הכספת** הם הנתיבים שמערכת הקבצים מכירה, וזה מה שכל דבר מחוץ ל־Obsidian רוצה. כל לחיצה שם מרחיבה למה העותק טוב: שתיים נותנות את שם הכספת, שלוש היכן הכספת נמצאת, ארבע היכן הקובץ הפתוח נמצא. Obsidian עושה את אותה ההבחנה בשתי הפקודות שלו עצמו, *from vault folder* ו־*from system root*; כאן הפריטים הפונים כלפי חוץ יושבים על המקטע שהוא עצמו מחוץ לנתיב.

כל זה עובד גם מחוץ לכספת, על אותם יעדים.

כל העתקה מודיעה על עצמה בהתראה, כי העתקה לא משאירה דבר על המסך שיראה שהיא קרתה, ולחיצה שנספרה בטעות לא אמורה להיראות כמו לחיצה מוצלחת.

## מקשי עזר: פתיחה במקום אחר

שם הפתק ומקטעי התיקיות מתנהגים כמו השורות שלהם בסייר הקבצים.

| | על שם הפתק | על מקטע תיקייה |
| --- | --- | --- |
| לחיצה רגילה | עריכת השם | עיון באותה תיקייה |
| <kbd>Ctrl</kbd> / לחיצה אמצעית | פתיחת הפתק בכרטיסייה חדשה | שליחת התיקייה לכרטיסייה חדשה |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd> | פיצול | פיצול |
| גרירה | הפתק, לכל מקום ש-Obsidian לוקח אליו קובץ | התיקייה, באותו אופן — כולל שורת הכרטיסיות |

תיקייה אינה דבר ש-Obsidian יכול לפתוח, כך ששליחת אחת לכרטיסייה עושה אחד משני דברים: פותחת את פתק התיקייה שלה, במקום שתוסף פתקי־תיקייה פועל ויש כזה, או פותחת כרטיסייה ריקה ששביל הניווט בכותרת שלה כבר עומד באותה תיקייה — ומשאירה לכם רק את השם להקליד. גרירת מקטע תיקייה אל **שורת הכרטיסיות** עושה את אותו הדבר, בכרטיסייה חדשה במקום שאתם משחררים — שורת הכרטיסיות של Obsidian לוקחת רק קבצים בכוחות עצמה, כך שתיקייה שנגררת מחוץ לסייר הקבצים עדיין נדחית שם.

## Tab: השלמת השם, ואז הנתיב, ואז הרחבת הבחירה

<kbd>Tab</kbd> משלים בדיוק כמו שאבטיפוס פקודות (shell) עושה: **הקשה מרחיבה את מה שהקלדתם עד למקום שבו השמות באותה תיקייה מסכימים, ועוצרת במקום שבו הם נחלקים.** הקלידו `Sk` כשרק `Sketches` מתחיל כך והמילה מוכנה; הקלידו `Al` כש‑`Alpha-one`, `Alpha-two` ו‑`Alpine` כולם מתחילים כך ותקבלו `Alp`, כי התו הבא הוא שאלה שרק אתם יכולים לענות עליה.

הקישו שוב בלי להקליד וההשלמה תתקדם לעבר שם אחד — השורה שהרשימה סימנה, או הראשונה — ותיעצר בחילוקי הדעות הבאים של אותו שם: `Alpha-`, ואז `Alpha-one`. הרשימה נפתחת במקום שבו אתם נמצאים כבר, כך שבתיקייה שלכם עצמה ההקשה הראשונה מכוונת להערה הפתוחה ולא למה שממוין ראשון.

**הקשה לעולם אינה בוחרת בין שמות במקומכם.** <kbd>Tab</kbd> נכנס לתיקייה כשמה שהקלדתם משאיר מועמד אחד, או כשהקלדתם את כל שם התיקייה ואין *תיקייה אחרת* שמרחיבה אותו. במקום שיש — `Schemes` לצד `Schemes2026` — <kbd>Tab</kbd> ממשיך להשלים לעבר השם הארוך יותר; <kbd>Enter</kbd> והרשימה הם המחוות שאומרות *זה בדיוק*.

**קובץ** לעולם לא מעכב תיקייה בדרך הזו. תיקייה לצד הערה בשם שלה היא הערת תיקייה, ולא פיצול בנתיב, ו‑<kbd>Tab</kbd> הולך על תיקייות — כך ש‑`Projects` עם `Projects.md` לצדה נכנסים כמו כל דבר אחר.

שני דברים קטנים יותר שנובעים מכך: מה שמופיע בשדה מאויית כפי שהתיקייה מאייתת אותו, כך ש‑`sk` יהפוך ל‑`Sketches`; ורק השם המוקלד מוחלף, כך שנתיב עם עוד תוכן מימינו שומר עליו.

כשמוצע שם בזמן ההקלדה, <kbd>Tab</kbd> **כותב את ההצעה בדיוק כלשונה**: ההצעה היא תמיד מה שההקשה תכתוב, וקו התחתית וקו הירוק ברשימה אומרים בדיוק אותו הדבר, כך שמה שאתם רואים אחרי הסמן זה מה שתקבלו. במקום שבו השמות מפסיקים להסכים, זה הצעד לעבר הראשון מבינם — או לעבר השורה שאליה ניווטתם בחצים, שאותה <kbd>Tab</kbd> נוקט ולא את זו שלצידה — כך שנווטו בחצים לזו שאתם רוצים, או הקלידו מעבר לפיצול, לפני שאתם מקישים. רק כשההצעה משאירה שם *אחד* אותה הקשה נכנסת אליו.

ההגעה לשם הקובץ **היא** המדרגה הראשונה — אין הקשה שמוקדשת רק למיקום הסמן בסוף שם שהוא עומד לסמן. משם ההקשות מפסיקות לזוז על פני הנתיב ומתחילות להרחיב את מה שמסומן:

1. השם
2. השם עם הסיומת שלו
3. הנתיב מתיקיית הכספת שלכם
4. הנתיב משורש המערכת
5. חזרה לתחילת הנתיב **כפי שהוא עומד כרגע** — עומדים במקום שבו ההליכה התחילה, המקטע הראשון מסומן, מוכן להילך בו מחדש

לחיצה רביעית מגיעה ישירות לאותה מדרגה רביעית.

הרחבה תמיד רק **מרחיבה**. שם שכבר שלם בשדה — הושלם באותו מקש, או נבחר מהרשימה — מסומן כמכלול ולא נלקחת ממנו הסיומת קודם: המדרגה הראשונה מיועדת לשם שההליכה *הגיעה* אליו זה עתה, שבו הסיומת עוד אינה הנושא.

הסולם הוא המקום שאליו ההליכה **מגיעה**, לא המקום שממנו היא מתחילה. לחצו על תיקייה באמצע נתיב והשדה נפתח על כל מה שמתחתיה עם שם התיקייה הזו מסומן; כל <kbd>Tab</kbd> אז נוקט **תיקייה אחת** — מסמן את הבאה, ומשאיר את שאר הנתיב מאחוריה — ורק כשלא נותר דבר מלבד שם הקובץ ההרחבה מתחילה:

| הקשה | קטעים | שדה | מסומן |
| --- | --- | --- | --- |
| נלחץ `a` | | `a/b/c/leaf.md` | `a` |
| <kbd>Tab</kbd> | `a` | `b/c/leaf.md` | `b` |
| <kbd>Tab</kbd> | `a › b` | `c/leaf.md` | `c` |
| <kbd>Tab</kbd> | `a › b › c` | `leaf.md` | `leaf` — המדרגה הראשונה |
| <kbd>Tab</kbd> | `a › b › c` | `leaf.md` | `leaf.md` |

**שם שנקבע הוא נקבע, בכל דרך שקבעתם אותו.** השלמתו עם
<kbd>Tab</kbd>, אישורו עם `/`, ובחירתו מהרשימה, כולם
משאירים את השורה באותו מקום עם אותו נתיב, כך שההקשה שאחרי המחווה
פירושה זהה לא משנה איך הגעתם. בחירת תיקייה מה‑
רשימה נהגה במקום זאת לרוקן את השדה, וזרקה נתיב שהגעה לאותה תיקייה
עם <kbd>Tab</kbd> הייתה שומרת.

**נתיב שאתם עדיין כותבים מגיע איתכם בשלמותו.** צעד לתוך התיקייה ממנה תלוי שאר הנתיב אינו טענה שיתר הנתיב קיים — כך נתיב מוקלד לפני זמנו, והתיקיות שהוא מכנה הן אלה ש‑<kbd>Enter</kbd> עומד לייצר. כך שהליכה לתוך `Dokumente` תוך כדי ירידה ב‑`Dokumente/plans/untitled.md` משאירה את `plans/untitled.md` לפניכם, בין אם `plans` קיימת כבר ובין אם לא. הוא הדין בנתיב שהקלדתם מהתחלה: שום דבר בו לא הגיע מירושה משום מקום, כך ששום דבר בו לא נלקח.

**החלפת צעד באחר היא סיפור אחר, ואז הנתיב מגיע רק במידה שהוא באמת קיים שם.** החליפו תיקייה באמצע נתיב באח — לחצו על `a`, הקלידו שם אחר, הקישו <kbd>Tab</kbd> — וכל מה שמתחתיה מגיע איתכם, כי הנתיב שהייתם עליו הוא בדרך כלל רוב הנתיב שאתם רוצים. אבל שורד את המעבר רק מה שקיים שם, כך שהשדה והרשימה שלצידו לעולם לא סותרים זה את זה: מה שנשאר לפניכם הוא נתיב שאפשר באמת ללכת בו. בהתחלה מ‑`a/b/c/leaf.md`, עם `a` נלחץ ושמו מסומן:

| מה שקבעתם | קטעים | שדה | מסומן |
| --- | --- | --- | --- |
| `x`, שאין לה `b` בכלל | `x` | | לא הגיע איתה דבר |
| `y`, שיש לה `b` אבל בלי `c` בתוכה | `y` | `b` | `b` |
| `z`, תאום של `a` עד הסוף | `z` | `b/c/leaf.md` | `b` |

תיקייה שנותרת עומדת בגפה כך היא עדיין תיקייה שנכנסים אליה: ההקשה הבאה נכנסת אליה, ולא מתחילה להרחיב בחירה על שמה.

לשם ש**שום דבר** בתיקייה לא תואם עונים אחרת, כי שום דבר לא נקבע על ידו: ההקשה מסמנת את מה שהקלדתם, מוכן שתקלידו מעליו, ולא עונה במקום אחר.

כל העניין הוא **מעגל, ואין עלות לסבב בו**: ההקשה שאחרי המדרגה האחרונה מחזירה את השורה לתחילת הנתיב, תיקיות וכל, מוכנה לעבור סבב נוסף. הדבר היחיד שיוצא אי פעם מהשורה הוא הקידומת המוחלטת, בהקשה שמפסיקה להציגה.

מה שחוזר הוא **הנתיב שבניתם**, לא זה שממנו התחלתם. פצלו את ההליכה בחצי הדרך — בחרו אח אחר מהרשימה, השלימו לעבר שם אחר — והסבב נסגר במקום שבו אתם באמת נמצאים; ארבע המדרגות שלפניו מתארות את אותו נתיב עצמו, וזו הייתה נהגה להיות המדרגה החריגה שמתארת את העבר.

<kbd>Shift</kbd>+<kbd>Tab</kbd> סוגר את אותה טבעת בכיוון ההפוך: בתחילת הנתיב, בלי מה להחזיר עוד ובלי לאן לעלות עוד, ההקשה הבאה עוברת למדרגה ה**רחוקה** — הנתיב משורש המערכת — וממשיכה לצמצם משם. אף כיוון לא מגיע למבוי סתום.

היא גם לא מבזבזת הקשה על מדרגה שכבר הוצגה. מתחת למדרגה האחרונה — השם בלי הסיומת שלו — הסולם מסתיים, ו*אותה הקשה* יוצאת מהתיקייה: הנתיב משורש המערכת, הנתיב מהכספת שלכם, השם, השם בלי הסיומת, ואז התיקייה, צעד אחד בכל פעם.

גם אין הקשה שמוקדשת למדרגה שאינה משנה דבר: לחיצה על שם הערה כבר מציגה אותו בלי הסיומת שלו, וזה מה שהמדרגה הראשונה מציגה, כך שמשם <kbd>Tab</kbd> מתחיל מהמדרגה השנייה.

כל מדרגה משנה את מה ש*נמצא* בשדה, לא רק את מה שמסומן — בחירה חייבת להיות על הטקסט שהיא מכנה, אחרת <kbd>Enter</kbd> יאשר דבר שונה ממה שנראה כמסומן. הסולם שייך למפגש עריכה אחד. לחצו במקום אחר, או הקלידו כלשהו דבר, וה‑<kbd>Tab</kbd> הבא ישלים שם מחדש.

### <kbd>Shift</kbd>+<kbd>Tab</kbd>: אותה דרך אחורה

<kbd>Shift</kbd>+<kbd>Tab</kbd> נסוג צעד אחד בכל הקשה, בסדר שבו ההקשות נעשו: הבחירה מצטמצמת מדרגה בכל פעם, כל השלמה מוחזרת, וכל תיקייה נעזבת — שמה חוזר לשדה כדי שתוכלו לערוך אותו במקום להקליד מחדש.

**שום דבר לא נמחק בדרך חזרה.** השלמה מוחזרת על ידי *סימון* התווים שהוסיפה, בדיוק כמו שההליכה קדימה מסמנת את מה שהרחיבה עליו — השם נשאר לפניכם, וכל הקשה נוספת מסמנת עוד צעד ממנו:

| | שדה | מסומן |
| --- | --- | --- |
| נכנסו | `Alpha-one` | |
| <kbd>Shift</kbd>+<kbd>Tab</kbd> | `Alpha-one` | `one` |
| <kbd>Shift</kbd>+<kbd>Tab</kbd> | `Alpha-one` | `ha-one` |
| <kbd>Shift</kbd>+<kbd>Tab</kbd> | `Alpha-one` | `Alpha-one` |

הקלדה מחליפה את החלק המסומן, כמו בכל מקום אחר. <kbd>Tab</kbd> מחזיר בדיוק את מה שהסימון החזיר, כך שהליכה שני צעדים החוצה ושני צעדים חזרה מחזירה אתכם למקום שבו הייתם.

כשכל השם מסומן לא נשאר דבר שהקשה שמה שם, וההקשה הבאה עולה *במעלה הנתיב*: היא עוזבת את התיקייה שבה אתם עומדים, בדיוק כמו <kbd>Backspace</kbd> על שדה ריק. גם זה עולה בחינם — שם התיקייה חוזר לשדה **לפני** כל מה שהיה בו, מסומן, וזה בדיוק הטקסט שלחיצה על אותה תיקייה הייתה נותנת לכם. חזרה היא כיוון ולא היסטוריית ביטול — אבל סימון השם קודם פירושו שהקשה אחת לעולם לא גם מחזירה את מה שכתבתם וגם מוציאה אתכם מהתיקייה שבה כתבתם אותו.

טקסט שנפתח **מסומן כבר** — מה שלחיצה על תיקייה משאירה מאחוריה — הוא השם שעליו <kbd>Tab</kbd> פועל בשלב הבא: הוא מושלם ונכנסים אליו כמו כל דבר אחר, והקלדה מחליפה אותו. רק פקודת המיקוד נפתחת על מדרגה בסולם עצמו, כי היא מציגה לכם את הנתיב כולו ולא תיקייה להיכנס אליה.

## הקלדת דבר שאינו נתיב

| מה שהקלדתם | מה שקורה |
| --- | --- |
| `https://…` | נפתח בכרטיסייה חדשה ב**מציג האינטרנט** של Obsidian, אם התוסף המובנה הזה פעיל אצלכם; אחרת בדפדפן שולחן העבודה שלכם |
| `obsidian://…` | מועבר למטפל ה‑URI של Obsidian עצמו |
| `file:///…` | מפוענח ונפתח: כהערה אמיתית אם הוא בתוך הכספת שלכם, במציג אם לא |
| `/home/you/a%20b.md` | אותו דבר, לנתיב שהודבק מדפדפן או ממנהל קבצים |

רק סכמות מפורשות נחשבות — הערה בשם `100%20` נשארת הערה. `/` שמשתייך לסכמה נשאר כלשונו ולא יורד לתיקייה, כך שאפשר להקליד כתובת URL ביד ולא רק להדביק אותה.

## פקודה למקלדת

**מיקוד בשורת הנתיב** פותח את השדה על שם ההערה והולך בו כמו ש‑<kbd>F2</kbd> עושה — השם, השם עם הסיומת שלו, הנתיב מהכספת שלכם, הנתיב משורש המערכת — וההקשה שאחרי כן סוגרת את השדה ומחזירה את הסמן להערה. הוא אינו משנה שם: <kbd>Enter</kbd> מנווט, כמו בכל שדה אחר. אין לו מקש משלו כברירת מחדל, כי ההנחיות של Obsidian מרתיעות תוספים מלתפוס אחד; שורת **קיצורי מקשים** בסוף הגדרות התוסף הזה פותחת את *הגדרות ← קיצורי מקשים* מציגה רק את הפקודות שלו, כך שתוכלו לשייך לו קיצור שם.

## הניווט לעולם אינו נוגע בקובץ הפתוח

במצב ברירת המחדל (ניווט) ההערה הפתוחה **לעולם** אינה משנה שם ואינה מועברת.

- נתיב שמתפענח לקובץ קיים פותח אותו.
- נתיב שאינו קיים עדיין נוצר לפשוט, כולל כל תיקיות ההורה החסרות, ונפתח. כל קובץ וכל תיקייה שנוצרים כך מודיעים על כך בהתראה — תיקייה חדשה אחרת בלתי נראית עד שתחפשו אותה — ופח האשפה של Obsidian עצמו הופך תיקייה לא רצויה לפעולה שאפשר לבטל בהקשת מקש אחת.
- **מחוץ לכספת הוא עדיין שואל קודם.** בחוץ אותה שגיאת הקלדה כותבת לתיקיית מערכת, שבה לא ההתראה ולא פח האשפה של Obsidian הם נחמה גדולה.

## <kbd>Ctrl</kbd> — כרטיסייה חדשה, והעתקה במקום העברה

הערה **שנוצרה, הועברה או הועתקה בתוך הכספת מוצגת במקום שבו נחתה** בסייר הקבצים, מסומנת לרגע בצבע ההדגשה של Obsidian — העץ הוא המקום שבו תחפשו אותה אחר כך, כך שהיא מוצגת לפניכם ולא נשארת בתיקייה שאולי אפילו לא פתוחה. שכפול מודיע על כך גם הוא: העתקה משאירה את המקור במקומו ופותחת את העותק בחלונית משלו, מה שבלי מילה קל לקרוא כאילו לא קרה דבר.

החזקת <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> ב‑macOS) בעת בחירת קובץ מהרשימה, או בעת הקשה על <kbd>Enter</kbd> על נתיב, שולחת את התוצאה ל**כרטיסייה חדשה** במקום לזו:

| | רגיל | עם <kbd>Ctrl</kbd> |
| --- | --- | --- |
| בחירה או הקלדה של קובץ קיים | נפתח כאן | נפתח בכרטיסייה חדשה |
| הקלדת נתיב שאינו קיים | שואל, ואז פותח כאן | שואל, ואז פותח בכרטיסייה חדשה |
| אישור נתיב במצב שינוי שם/העברה | **מעביר** את ההערה לשם | **מעתיק** אותה לשם ופותח את העותק בכרטיסייה חדשה |

מקש הצירוף נקרא לפי הכלל של Obsidian עצמו, ולכן הוא מתנהג בדיוק כמו על קישור או על שורה בסייר קבצים — לחיצה אמצעית גם היא אומרת "כרטיסייה חדשה", <kbd>Ctrl</kbd>+<kbd>Alt</kbd> אומר פיצול, ו‑<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd> חלון חדש.

העתקה מסרבת לשכתב, בדיוק כמו העברה — כולל אל נתיב ההערה עצמה, שבו אין דבר הגיוני להעתיק. מחוץ לכספת הסירוב הזה נאמר בקול גם הוא.

כל זה עובד **גם כשהרשימה פתוחה** וגם בלעדיה: על שורה מסומנת מקש הצירוף חל על אותה שורה, ובעמידה על שום דבר הוא חל על מה שהקלדתם.

## עיון מחוץ לכספת

**זה כבוי כברירת מחדל.** הפעילו תחילה **גישה לקבצים חיצוניים** בהגדרות — קריאה וכתיבה מחוץ לכספת הן הדבר היחיד שהתוסף הזה עושה ו‑Obsidian עצמו אינו עושה, ולכן נכנסים לזה מרצון במקום לצאת מזה. כשזה כבוי, שם הכספת פשוט מציג את הכספת שלכם בסייר קבצים, ושום דבר כאן אינו מביט מעבר לה.

לחיצה על **שם הכספת** (או על סמל 🏠, כאשר *הצגת שם הכספת* כבוי) פותחת רשימה נפתחת של מקומות ולא של תוכן. השדה שנפתח מכיל **את כל הנתיב שבו הייתם, כתוב במלואו**, כאשר המקום שממנו הוא מתחיל מסומן — כך שבחירת מקום אחר, או הקלדה מעל הסימון, מחליפה רק את החלק המוביל הזה ומשאירה את שאר הנתיב לפניכם. **לחצו על השם פעם שנייה** — לחיצה כפולה — והסימון מתרחב על פני כולו, וכך נלקח הנתיב המוחלט במחווה אחת במקום להיסחף בעבודת יד. שנו את דעתכם ו‑<kbd>Esc</kbd> מחזיר את השורה למה שהייתה.

הקלדה כאן מוצעת עם שאר שמו של מקום כמו בכל מקום אחר, ו‑<kbd>Tab</kbd> **קובע את המקום הזה** — זה שאליו אתם מצביעים, או זה היחיד שהשם יכול להתכוון אליו. במקום שבו כמה מקומות עדיין חולקים את מה שהקלדתם, הלחיצה עוצרת בפיצול, כמו בכל מקום. הצבעה על מקום מציגה **את הנתיב של אותו מקום עצמו**, כולו מסומן, ואחריו הנתיב של ההערה שלכם רק עד כמה שהוא באמת קיים שם — וזה בדיוק מה שבחירה בו הייתה מביאה אתכם אליו. מקום אינו צעד בתוך הנתיב שעל המסך אלא מקום שממנו סופרים את הנתיב כולו, כך ששום דבר ממקום היותכם אינו נשאר לפניו.

המקומות המוצעים:

- **הכספות האחרות שלכם**, נקראות מהמרשם של Obsidian עצמו, האחרונה שנפתחה ראשונה, כל אחת תחת סמל הכספת של Obsidian עצמו — זה שהיישום משתמש בו לפקודות הכספת. הכספת שכבר פתוחה אצלכם מקבלת בית: זהו המקום שממנו השורה מתחילה כברירת מחדל, ולא מקום ללכת אליו.
- **תיקיית הבית**, תחת שם החשבון שלכם, מסומנת ב‑`~`. ל‑Lucide אין טילדה, ולכן את זה מצייר התוסף עצמו על רשת 24×24 של Lucide באותו עובי קו — סמל שחסר לערכה, ולא תו טקסט שיושב בין סמלים.
- **שורש מערכת הקבצים**, מתויג `root` — לא מתורגם, שכן זה שמו בכל מערכת — ולא `/`, שהיה נקרא כצעד ריק לצד המפריד שבא אחריו.
- **כוננים מחוברים**, עם סמל לכל סוג היכן שזול לקבוע זאת: שיתופי רשת, תקליטורים, תקליטונים ומדיה נשלפת מקבלים משלהם; כל השאר מקבל כונן כללי. ב‑Windows כוננים מוצגים כ‑`C:` עם סמל כללי — שמות אמצעי אחסון וסוגים מדויקים דורשים WMI, וזה במכוון אינו נעשה.

בחירת כספת אחרת **אינה מעבירה את Obsidian אליה.** כל מה שפתוח אצלכם נשאר פתוח; הנתיב פשוט מתחיל לעיין שם. זו כל הנקודה בכך שזה נמצא בסרגל הנתיב ולא נמסר למחליף הכספות שבסרגל הצד.

זה גם נוחת **קרוב ככל האפשר להערה שאתם נמצאים בה, עד כמה שאותו מקום באמת מגיע**.

- אם המקום שבחרתם *מכיל* את ההערה — תיקיית הבית, או היכן שהכספות שלכם חיות — אתם מקבלים את הנתיב שלה משם: בחרו `~` כשפתוח `takeaways.md` והשדה יקרא `Vaults/your-vault/takeaways.md`.
- אם זה מקום לצד זה — כספת אחרת, כונן אחר — אותו נתיב יחסי מנוסה, עד כמה שהוא באמת קיים. כספות הן לרוב עותקים כמעט זהים זו לזו, והסיבה לקפוץ לאחת היא בדרך כלל אותה הערה שם.

בכל מקרה השורה נשארת במקום שבחרתם ו**התיקייה הראשונה של אותו נתיב נפתחת מסומנת**, אותה צורה שלחיצה על תיקייה נותנת: הצעד שהכי סביר שתשנו כשאתם קופצים למקום אחר הוא זה הקרוב ביותר לראש, ושאר הנתיב נשאר גלוי בזמן שאתם משנים אותו. שום דבר לעולם אינו ממולא מראש אם הוא לא באמת קיים בדיסק.

### בזמן שאתם בחוץ

הנתיב **מתחיל במיקום שבחרתם**, לא במבנה התיקיות של המחשב — וכך גם השדה שאתם מקבלים בלחיצה על השטח הריק או בלחיצה על מקש המיקוד: הוא מכיל את הנתיב מאותו מקום, לא את הנתיב המוחלט של המחשב, כשהשביל מתקפל למקום עצמו בדיוק כפי שהוא מתקפל לשורש הכספת בפנים — בחרו `Archive` והשורה תקרא `Archive / notes / …‎`, לא `/home/you/Vaults/Archive/notes/…‎`. המקטע המוביל נושא סמל למה שהוא (כספת, בית, כונן), ו‑<kbd>Backspace</kbd> עוצר שם במקום להמשיך למעלה לשאר מערכת הקבצים. כאשר *הצגת שם הכספת* כבוי, המקטע הזה הוא הסמל בלבד — ההגדרה נוגעת למקטע הפתיחה של השורה, לא משנה איזו כספת הוא נוקב, ולא רק לשלכם.

סרגל הנתיב **ממוסגר בצבע השגיאה** — אותה טבעת שמצייר מצב שינוי השם — כל עוד הוא מצביע מחוץ לכספת שלכם. הוא מסמן מצב מתמשך, לא רגע: כל עוד הוא שם, אף אחד מהטיפולים של Obsidian עצמו אינו חל על מה שהשורה מציגה, והכתיבה נעולה עד שתאמרו אחרת.

מלבד זאת העיון עובד כמו בפנים: שבבים, מפרידים, הקלדה, השלמה אוטומטית, <kbd>Backspace</kbd> ליציאה צעד אחד. גם אותם כללי נראות חלים, ולכן סיומות שאינן נתמכות עדיין דורשות את *הצג את כל סוגי הקבצים* של Obsidian וקבצי נקודה עדיין דורשים את ההגדרה של התוסף הזה.

**גם לחיצה ימנית עובדת שם בחוץ**, אם כי זהו תפריט אחר: הטיפולים של סייר הקבצים עצמו זקוקים לקובץ שהכספת מכירה, ולכן רשומות מחוץ לכספת נבנות מהנתיב במקום זאת. הן מציעות פתיחה (כאן, מימין, בחלון חדש, או ביישום ברירת המחדל של שולחן העבודה), *העתק נתיב*, *הצג בסייר המערכת*, ו— לאחר שהמנעול פתוח — *הערה חדשה*, *תיקייה חדשה*, *צור עותק*, *שנה שם…* ו*מחק*. **גרירה** עדיין דורשת קובץ כספת ונשארת בלתי זמינה.

אותו תפריט נמצא גם על הקובץ הפתוח במציג, בלחיצה ימנית או משלוש הנקודות של החלונית עצמה, והוא שואל את המנעול בכותרת של אותה תצוגה. הוא אינו שואל דבר אחר: אם הקובץ מעובד או מוצג כמקור אין לזה השפעה על האם ניתן למחוק אותו, ותמונה או PDF — שאין להם תצוגת מקור בכלל — ניתנים למחיקה בדיוק כמו הערה. *מחק* פירושו סל המיחזור של שולחן העבודה, כך שניתן לבטל משם; מערכת ללא סל מיחזור מדווחת על כך במקום להשמיד את הקובץ.

מחיקה מחוץ לכספת מעבירה את הקובץ **לסל המיחזור של המערכת** — Recycle Bin ב‑Windows, Trash ב‑macOS — לעולם לא ביטול קישור. כאן בחוץ אין סל מיחזור של Obsidian לשחזר ממנו, ולכן מחיקה שלא ניתן לבטל אינה מוצעת כלל: היכן שלפלטפורמה אין סל מיחזור, הניסיון מדווח על הכישלון במקום זאת.

### כתיבה מחוץ לכספת

כל דבר שכותב **נעול כברירת מחדל**. כל עוד השורה מצביעה מחוץ לכספת שלכם, מקומו של מתג שינוי השם בכותרת נתפס על ידי **מנעול אדום** — אותו צבע כמו הטבעת סביב השורה, ומאותה סיבה: הוא מסמן סירוב. השניים הם פקד אחד במשבצת אחת, כך שאין אף פעם שאלה איזה מהם שולט על מה.

שלוש לחיצות, במחזור:

| לחיצה | מה מקבלים |
| --- | --- |
| המנעול האדום | כתיבה כאן מותרת. המנעול מוחלף במתג שינוי השם/העברה |
| המתג | מצב שינוי שם/העברה, בדיוק כמו בתוך הכספת |
| המתג שוב | המצב מסתיים והמנעול נסגר שוב — ההרשאה אינה שורדת מעבר לדבר שלמענו נפתחה |

**מקש שינוי השם שואל גם את המנעול.** מחוץ לכספת שלכם, לחיצה עליו מהבהבת
את המנעול פתוח וסגור במקום לפתוח מצב שכל שינוי היה נדחה בו:
הסירוב מגיע לפני העבודה ולא אחריה. לחצו על המנעול, או
לחצו שוב על מקש שינוי השם תוך חצי שנייה — הלחיצה השנייה מעניקה בדיוק
את מה שהכפתור מעניק, למיקום הזה, ופותחת איתה את מצב שינוי השם.

בתוך הכספת שלכם אין מנעול: אין מה לשחרר, והמתג פשוט תופס את המשבצת.

ההרשאה ניתנת **למיקום, לא לרגע**: היא שורדת כל מה שהייתם עושים בזמן עבודה במקום אחד — סיום העברה, לחיצה מחוץ לשדה הקלט, פתיחת קובץ — ומסתיימת כשאתם בוחרים כספת, כונן או שורש אחר מהרשימה הנפתחת, כשהשורה חוזרת לקובץ כספת, או בלחיצה השלישית ההיא. כך שסדרה של העברות בתוך תיקייה אחת דורשת לחיצה אחת, לא אחת לכל קובץ.

כשהמנעול פתוח, סרגל הנתיב מתנהג שם בחוץ כפי שהוא מתנהג בפנים:

| פעולה | תוצאה |
| --- | --- |
| הקלידו שם שאינו קיים, <kbd>Enter</kbd> | אותה שאלת "ליצור אותו?" כמו בפנים; גם תיקיות הורה חסרות נוצרות. שם ללא סיומת הופך ל‑`.md`, בדיוק כמו בפנים |
| מצב שינוי שם/העברה, הקלידו שם חדש | משנה את שם הקובץ שהשורה מציגה. שם ללא סיומת שומר על סיומת הקובץ — כאן בחוץ תיקייה מכילה כל סוג של קובץ, ושינוי שם לא אמור להפוך בשקט `.png` ל‑`.md` |
| מצב שינוי שם/העברה, עיינו במקום אחר, בחרו **שמור על השם הזה** | מעביר אותו לשם תחת השם שכבר יש לו |
| החזיקו <kbd>Ctrl</kbd> בכל אחד מהם | מעתיק במקום להעביר, ופותח את העותק בכרטיסייה חדשה |

בנעילה, כל אלה מדווחים מה חוסם אותם במקום להתרחש. שום דבר אינו נדרס אף פעם בשני המצבים: יעד שכבר קיים נדחה, והסירוב הוא של מערכת הקבצים עצמה (`COPYFILE_EXCL`, יצירה בלעדית) ולא בדיקה שעלולה להפסיד במרוץ. העברה בין מערכות קבצים — מהתקן USB, משיתוף רשת — נסוגה להעתק‑ואז‑מחק, והמקור מוסר רק לאחר שהעותק נחת.

**העברת הערה *החוצה* מהכספת שלכם שואלת קודם.** `fileManager` אינו יכול לעקוב אחר קובץ מעבר לגבול הזה: כל קישור שמצביע להערה מפסיק להיפתר, שום דבר אינו מעדכן אותם, וההערה עוזבת את האינדקס של הכספת. לכן ההעברה מוצעת כהחלטה במקום להידחות או להתבצע בשקט — תיבת דו‑שיח מציינת מה זה עולה וכמה הערות מקשרות לזו שאתם מעבירים. אשרו וזה באמת עובר: מועתק החוצה, ואז מוסר מהכספת דרך המחיקה של Obsidian עצמו, כך שזה ניתן לשחזור בדיוק כמו הערה שנמחקה, וכישלון בכל אחד מהשלבים משאיר את ההערה במקומה. החזקת <kbd>Ctrl</kbd> עדיין מעתיקה אותה החוצה במקום זאת, שאין לה שום בעיה מהסוג הזה. הכיוון ההפוך — הבאת קובץ חיצוני *לתוך* הכספת — עדיין אינו מחובר.

### פתיחת קובץ חיצוני

עיון במערכת הקבצים יכול לחזור **אל תוך הכספת שפתוחה אצלכם** — מהשורש, מהבית, מכל מקום שהכספות שלכם חיות בו. קובץ שהגיעו אליו כך הוא הערה רגילה, ולכן הוא נפתח ככזו: העורך האמיתי, קישורים וקישורים נכנסים, והשורה קופצת בחזרה לנתיב המבוסס על הכספת. רק קבצים ש‑Obsidian אין לו תצוגה עבורם נשארים בתצוגה המקדימה, שכן שם בחוץ התצוגה המקדימה היא התשובה הטובה יותר. במקום שבו תצוגה מקדימה מציגה בכל זאת הערה כזו — סביבת עבודה שנפתחה מחדש, למשל — השורה העליונה שלה מציעה **פתח ב־*(כספת)***, שזה אותו הצעה שהייתם עושים ביד.

העורך של Obsidian עובד רק על קבצים בתוך הכספת, ולכן קובץ חיצוני **אינו יכול** להיפתח כהערה אמיתית עם קישורים, קישורים נכנסים וכל השאר — זו מגבלה של היישום, לא של התוסף הזה. בחירה באחד פותחת במקום זאת **תצוגה מקדימה**, לקריאה בלבד עד שתאמרו אחרת:

| סוג | מוצג כ־ |
| --- | --- |
| `.md`, `.markdown` | Markdown מעובד |
| `.html`, `.htm`, `.xhtml` | הדף המעובד |
| תמונות, שמע, וידאו, PDF | נגן/מציג טבעי |
| כל קובץ **טקסט** אחר (`.json`, `.css`, `.log`, `.txt`, …) | טקסט פשוט כלשונו |
| פורמטים בינריים ללא מציג (`.zip`, `.exe`, …) | נמסר ל*פתח ביישום ברירת המחדל* |

למציג שתי קריאות של קובץ, ומכיוון שהן מוציאות זו את זו, מוצגת רק זו שאליה הייתם עוברים:

| | מה זה עושה | ברירת מחדל עבור |
| --- | --- | --- |
| **הצג כ‑Markdown** | מעבד את הקובץ כהערה, לקריאה בלבד | `.md`, `.markdown` |
| **הצגה כדף** | מעבד את הקובץ כדף שהוא, לקריאה בלבד | `.html`, `.htm`, `.xhtml` |
| **ערוך כטקסט** | המקור, ניתן לעריכה | כל השאר |

מחוץ לכספת, **ערוך כטקסט** הוא גם הלחיצה שמסירה את מצב הקריאה בלבד — המצב וההרשאה הם מחווה אחת ולא שני כפתורים לחשוב עליהם. הוא נצבע אדום **בכל פעם שלחיצה עליו תסיר את הקריאה בלבד**, בין אם אתם דורכים עריכה במקום ובין אם אתם מגיעים ישירות מהתצוגה המעובדת; בתוך הכספת אין מה לשחרר, ולכן הוא נשאר רגיל. **הצג כ‑Markdown** מקבל שטיפת הדגשה קלה — אותו גוון ש‑Obsidian נותן לטקסט מסומן — ומסמן אותו כדרך חזרה ולא כקריאה לפעולה.

מכיוון שהכפתור עוקב אחר ה*עריכה* ולא אחר המצב הגולמי, קובץ שיושב לקריאה בלבד בתצוגת הטקסט עדיין מציע **ערוך כטקסט**: זו הלחיצה שדורכת אותה. קובץ שלעולם לא ניתן להקליד בו — נחתך, או בלתי קריא — אומר במקום זאת **הצג כטקסט**, שכן זה כל מה שהלחיצה יכולה לספק.

ברירות המחדל הן הדרך המועילה ולא המילולית: `#` בסקריפט מעטפת הוא הערה, לא כותרת, ולכן עיבוד `.log` כ‑Markdown היה בולע אותה בשקט. כל אחת מברירות המחדל ניתנת לעקיפה לכל קובץ, והבחירה נכנסת להיסטוריה של הלשונית, ולכן קדימה/אחורה וסביבת עבודה שנפתחה מחדש שומרות עליה — הרבה הערות חיות בקבצי `.txt`, והרבה קבצי `.md` קלים יותר לקריאה כמקור.

#### מה מותר לדף HTML לעשות

שום דבר. הדף מוצג במסגרת שבה **כל הרשאה נמנעת** — אין
סקריפטים, אין טפסים, אין ניווט, אין מקור משלה — ומדיניות תוכן
שאינה מאפשרת לה שום גישת רשת בכלל. זו אינה זהירות לשם עצמה: דף
מקומי שנטען בדרך הרגילה היה חולק את המקור של החלון הזה, והחלון הזה
הוא Obsidian, כך שסקריפט בקובץ HTML שהורדתם היה רץ בתוך
היישום שלכם עם ההישג של היישום שלכם.

מה שזה עולה הוא כל דבר שהדף *עושה*; מה ששומר הוא כל דבר שהדף
*הוא*. גיליונות הסגנון והתמונות היושבים לצד הקובץ נקראים ו‑
נישאים אל תוך המסגרת, כך שדף שמור עדיין נראה כמו עצמו. הפניות
שמצביעות מחוץ לתיקייה של הדף עצמו, והפניות למקום כלשהו ב‑
רשת, נשארות בדיוק כפי שנכתבו ופשוט אינן נטענות — קובץ מקומי לא יכול
לספר בשקט לשרת שפתחתם אותו.

סקריפטים **מוסרים** ולא רק נחסמים, כך שהדף שאתם רואים
והמקור שאליו תוכלו לעבור נבדלים בדרך אחת מוצהרת ולא בכל מה
שהמסגרת בשקט סירבה להריץ. קישורים בתוך הדף אינם עושים דבר. כש
אתם רוצים את הדבר האמיתי — סקריפטים ורשת וכל השאר — *פתח ביישום ברירת המחדל* מוסר אותו
לדפדפן שלכם, שהוא הכלי הנכון לזה.

**קבצים בכספת שלכם ניתנים לעריכה מיד**, בלי שחרור: *ערוך כטקסט* הוא עורך אמיתי וכותב בחזרה תוך כדי הקלדה.

**העריכה נזכרת לאורך המעבר.** מעבר ל*הצג כ‑Markdown* משהה אותה — לעיבוד סטטי אין לאן להקליד, ו‑Live Preview זקוק לעורך של Obsidian עצמו, שקיים רק לקבצים בתוך הכספת — ולכן שום דבר אינו טוען שאתם עורכים בזמן שאתם שם. חזרה ל*ערוך כטקסט* ממשיכה מהמקום שבו עצרתם.

**קבצים מחוץ לכספת נפתחים לקריאה בלבד, ו*ערוך כטקסט* מסיר זאת.** הלחיצה היא כל השער: עד שהיא מתרחשת, שום דבר שם בחוץ אינו נכתב. אחריה הקובץ נשמר תוך כדי הקלדה, בדיוק כמו קובץ בכספת; ושורת המצב משתנה ממנעול לעיפרון. השחרור מכסה את אותו קובץ אחד באותה כרטיסייה אחת — מעבר לקובץ אחר נועל מחדש, וזה במכוון אינו נשמר בהיסטוריית הכרטיסייה, כך שסביבת עבודה שנפתחה מחדש לעולם אינה חוזרת עם כתיבה דרוכה כבר על קובץ מערכת שאינכם זוכרים שפתחתם.

**קבצים חתוכים נשארים לקריאה בלבד בכל מקרה** — שמירת מה שעל המסך הייתה משליכה את כל מה שמעבר לתקרה, ולכן הכפתור אינו מוצע כלל במקום להיות מוצע ואז נדחה. אותו הדבר לגבי קובץ שלא ניתן היה לקרוא: אין מה לכתוב בחזרה מלבד חלונית ריקה.

אם הכתיבה נכשלת — עגינה לקריאה בלבד, קובץ שאינו שלכם — הסיבה של המערכת עצמה מוצגת בהודעה.

קבצים גדולים מאוד מוצגים חתוכים, ושורת המצב אומרת זאת במקום להשאיר לכם לגלות — לצד שאר התנאים ולא בזנב הכפתורים, שכן זו עובדה על הקובץ כמו כל השאר. התקרות נמדדות מול מעבד חי ולא מנוחשות — פריסת מגה‑בייט של טקסט בחלונית אחת הורגת את תהליך העיבוד של Obsidian על המקום, ו‑Markdown עולה פי כמה לכל בייט מטקסט פשוט, ולכן לשניהם מגבלות נפרדות ושורה ענקית יחידה מקוצרת גם כשהקובץ כולו קטן.

**שורות המצב הן תוויות, וההסבר הוא חלונית עצה.** כל שורה מציינת מה נכון בכמה שפחות מילים — *מחוץ לכספת*, *אין עורך לסוג קובץ זה*, *נחתך — הקובץ גדול מדי* — כי הכפתורים שלצדן כבר אומרים באיזה מצב הקובץ. ריחוף מעל אחת מהן נותן את המשפט: מדוע Obsidian אינו יכול לפתוח אותו כהערה, מה היה קורה אחרת לסוג הקובץ הזה, מה החיתוך עולה לכם.

זה חל גם על קבצים **בתוך** הכספת שלכם. Obsidian מוסר כל סיומת שאין לו תצוגה עבורה ישירות ליישום ברירת המחדל של שולחן העבודה — כך ש‑`.txt` או `.json` בכספת שלכם היו עוזבים את Obsidian לגמרי. אלה נפתחים כעת באותו מציג, עם הטבעת הכתומה, שכן "פתח אותו ב‑Obsidian" הוא מה שביקשתם — ומכיוון שהם קבצי כספת, הם ניתנים לעריכה שם ללא כל שחרור. קבצים בינריים ללא מציג שומרים על ההתנהגות של Obsidian; אין מה להציג.

התצוגה המקדימה נפתחת **בכרטיסייה שבה הייתם**, ולכן קדימה/אחורה מחזירים אתכם להערה שממנה באתם; החזיקו <kbd>Ctrl</kbd> לכרטיסייה חדשה כמו בכל מקום אחר. סרגל הכותרת ממשיך להציג את נתיב הקובץ החיצוני כל עוד הוא פתוח, כך שתוכלו להמשיך לעיין משם.

שורה שקטה מעל התוכן מציעה את דרכי היציאה:

- **פתח ב־*(כספת)*** — מוצג כאשר הקובץ שייך לאחת מהכספות האחרות שלכם. מוסר אותו לטיפול ה‑URI של Obsidian עצמו, שפותח את חלון הכספת ההיא עם ההערה בתוכה, כהערה אמיתית הניתנת לעריכה. החלון הזה נשאר בדיוק כפי שהיה; שום דבר אינו מתחלף מתחתיכם.
- **הצג כ‑Markdown** / **הצגה כדף** / **ערוך כטקסט** — שתי הקריאות שיש לקובץ הזה; האחרון גם מסיר את הקריאה בלבד מחוץ לכספת.
- **פתח ביישום ברירת המחדל** — מוסר את הקובץ ליישום ברירת המחדל של שולחן העבודה שלכם, כולל הפורמטים הבינריים שהמציג הזה אינו יכול להציג. מנוסח בדיוק כמו הערך של Obsidian עצמו לאותה פעולה, כי זו אותה פעולה.

המציג עונה גם ל**לחיצה ימנית**: בתוך עורך הטקסט עם *גזור* / *העתק* / *הדבק* / *בחר הכל*, ובכל מקום אחר עם התפריט של הקובץ עצמו. תפריט שלוש הנקודות של Obsidian בכותרת נושא גם הוא את התפריט הזה — מחוץ לכספת הוא היה מציע אחרת רק *פצל ימינה* ו*פצל למטה*.

שום דבר מחוץ לכספת שלכם אינו נכתב אלא אם תלחצו קודם על *ערוך כטקסט*. ראו את הפרק [מחוץ לכספת](README.he.md#מחוץ-לכספת) ב‑README לגילוי המלא.

## גרירת קובץ אל תיקייה בשביל הניווט

כל תיקייה בשורה היא יעד לגרירה, כך ש**פתק שנגרר אל אחת מהן עובר לשם** — הדרך הקצרה ביותר לשם עוברת בין פתק לכל תיקייה מעליו, מכיוון שהיעד כבר מוצג על המסך. גררו מסייר הקבצים, מהרשימה, משם הפתק עצמו בכותרת, או מכל מקום אחר ב-Obsidian שמפיק קובץ: זו הגרירה של האפליקציה עצמה, כך שתווית הריחוף, הסמן וההדגשה הם אלה שמסייר הקבצים מצייר.

**גם שם הכספת קולט גרירה**, מכיוון שהוא התיקייה שבראש השורה — התנועה היחידה שמכניסה פתק לשורש הכספת מכאן.

**ניתן לגרור בחירה שלמה בבת אחת**, והיא נעה כאחת: אם אחד מהפריטים לא היה יכול לעבור, הגרירה נדחית כליל במקום להעביר חלק ולדלג בשקט על השאר.

הקישורים עוקבים אחרי הפתק, בדיוק כפי שהם עושים כשהוא מועבר מסייר הקבצים או בהקלדת נתיב.

תיקייה ש**אינה יכולה לקלוט את הגרירה אינה מציעה דבר משלה** — לא תווית *העברה אל*, לא הדגשה על התיקייה — במקום להציע משהו שייכשל לאחר מכן; התשובה של Obsidian עצמו עבור הכותרת, *פתיחה בכרטיסייה זו*, היא מה שעומד שם במקום. שלושה מקרים:

- התיקייה שהקובץ **כבר נמצא בה**, מכיוון שהוא כבר שם;
- תיקייה שנגררת **לתוך עצמה או לתוך צאצא שלה**, מה שהיה משאיר אותה בלי מקום שממנו הגיעה;
- בחירה המחזיקה **תיקייה ומשהו בתוכה**, מכיוון שהעברת התיקייה לוקחת את הילד יחד איתה.

תיקייה שכבר מחזיקה **קובץ באותו שם** קולטת את הגרירה ושואלת מה לעשות עם זה שבדרך, עם אותה תיבת דו-שיח כמו שם תפוס שהוקלד או נבחר — ראו [שם שתפוס](#שם-שתפוס). דבר כאן אינו דורס.

רק תיקיות **בתוך הכספת שלכם** קולטות גרירות. כאשר השורה מצביעה מחוץ לכספת, המקטעים שלה מסרבים, מכיוון שהוצאת פתק מהכספת שוברת כל קישור אליו — החלטה ששווה שאלה ולא תנועה. הדרך לעשות זאת במכוון היא עדיין להקליד את הנתיב, שמברר קודם ומודיע כמה פתקים ייפגעו.

## גרירת טקסט או קובץ כדי לרשום אותו

אותם יעדים קולטים גם **תוכן**, בנוסף לקבצים, וההבחנה בין השניים נעשית לפי מה שאתם גוררים ולא לפי היכן משחררים.

**אל פתק שהשורה כבר נוקבת בשמו** — שם הפתק עצמו, או מפריד שלתיקייה שלו יש פתק תיקייה — מה שגררתם מתווסף לסופו, אחרי שורה ריקה. הוא שואל קודם, מכיוון שזה כותב לתוך קובץ שכבר קיים וגרירה היא תנועה שיד לא יציבה עלולה לבצע בטעות. טקסט מתוך עורך, קובץ משולחן העבודה ופתק שנגרר מחוץ לכספת זו — כולם עובדים; קובץ נקרא כטקסט, וקובץ בינארי נדחה במקום להידבק כמסך מלא של שטויות.

**אל מקום — שם הכספת או תיקייה** — עדיין לא נכתב דבר, מכיוון שדבר לא נקרא בשם. השדה נפתח שם ומחזיק את מה שגררתם, והשם שאתם מקלידים הוא מה שמאשר את הפעולה: פתק חדש *נוצר* כשהוא מחזיק את הטקסט, ומקובל קיים נשאלים בדיוק כפי שלעיל. <kbd>Esc</kbd>, או לחיצה במקום אחר, משחררים את הכול.

**השורה מקבלת טבעת כחולה** בזמן שגרירה שתנחת כתוכן מרחפת מעליה, ונשארת כחולה בזמן שהשדה מחזיק אחת — אותו כחול, שאומר אותו דבר: מה שקורה הלאה נוגע לטקסט שאתם נושאים. קובץ שנגרר מהכספת שלכם עצמה אל תיקייה עדיין אומר *העביר אותו לשם*, שומר על ההדגשה של Obsidian עצמו, ולעולם לא מקבל טבעת כחולה; אותה תנועה הייתה שם קודם ותוכן נסוג בפניה.

## כאשר הנתיב ארוך מהחלונית

שמות **מתקצרים במקום להידחס**, לפי הסדר של מה שאתם הכי פחות עשויים להזדקק לו:

1. **שם הכספת קודם**, עד לסמל שלו בלבד. אתם יודעים באיזו כספת אתם נמצאים; הסמל ממשיך לומר היכן הנתיב מתחיל.
2. **לאחר מכן סיומת הקובץ**, אם היא מופעלת אצלכם — אותם שלושה תווים כמעט על כל קובץ בכספת. היא נעלמת כולה במקום להתקצר: חצי סיומת לא אומר יותר מכלום.
3. **אחר כך התיקיות, הארוכה ביותר קודם.** שם התיקייה הארוך ביותר מתקצר לאורך של השני בארכו, ואז שניהם יחד, וכן הלאה, כל אחד נעצר בגבול התחתון שלו — כך שתיקייה אחת ארוכה מאוד מוותרת על כל מה שיש לה מעבר לאחרות לפני ששם קצר לצידה מאבד אות אחת.
4. **שם הקובץ עצמו אחרון**, והוא שומר על כשישה תווים. זה מה שהכותרת נועדה לשם.

מקום מתפנה **ברציפות**, בשברי פיקסל ולא אות אחר אות: שם שנסוג נחתך בפיקסל ודועך תחת ה-`…` שלו, כך שחלונית שנגררת לאט מצרה את השורה בחלקות ושום דבר אחריה לא זז בקפיצות. לפני שכל אות הולכת לאיבוד, האוויר סביב המפרידים מתבזבז ראשון — זהו הרווח היחיד של השורה והוא לא עולה שום מידע — ושם מקוצר מסתיים במקום שהמפריד מתחיל, ללא רצועת תיבה ריקה בין השניים.

**השדה לוקח את מה שהוא מחזיק.** פתיחת שדה כדי להקליד נתיב אינה דוחסת את התיקיות שלצדו הצידה: הוא רחב כמו הטקסט שבתוכו וגדל תוך כדי הקלדה, כך שהשביל שומר על כל מה שהשדה לא צריך. רק כשאין מספיק מקום לשניהם השורה גוללת, ואז השדה הוא הדבר היחיד שלעולם לא נסוג — זהו טקסט שנערך, לא שם שמותאם.

דבר לא נחתך מעבר למה שמבחין אותו משכניו: `Projects2025` ו-`Projects2026` באותה תיקייה מצטמצמים ל-`…025` ו-`…026` במקום לקידומת שהייתה הופכת אותם לאותה מילה, בעוד `Reports` לצד `Receipts` יכול לרדת ל-`Rep…`. בנוסף, כל שם שומר על **רוחב קריא** — כארבע אותיות עבור תיקייה ושש עבור שם קובץ, נמדד בגופן שהשורה מצוירת בו בפועל ולא נספר. ארבע אותיות צרות וארבע רחבות אינן אותה כמות שם, כך ש-`lilliliillil` מורשה לשמור על יותר מעצמו מאשר `WWMMWWMMWWMM`, ומה שנשאר על המסך הוא באותו גודל בשני המקרים. שמות קצרים נשארים ללא נגיעה כלל — שם שנשחק ל-`A…` הוא ייחודי ועדיין בלתי קריא. **רווחים אינם נספרים לצורך זה.** שישה תווים כדי לומר איזה קובץ זה הם שישה תווים ששווה לקרוא, כך שהרווחים בין האותיות נוסעים חינם ואחד מהם לעולם לא נשאר צמוד ל-`…`, שם ממילא היה בלתי נראה.

**שם נחתך היכן שהשכנים שלו מסכימים איתו, ובאמצע היכן שאין הסכמה בשום מקום.** שתי תיקיות בשם `aaaa-common-one` ו-`aaaa-common-two` חולקות הכול פרט לשלושת התווים האחרונים, כך שחיתוך הזנב שומר על החלק שאומר משהו: הן יורדות ל-`…one` ו-`…two` במקום, מה שקצר יותר *וגם* מבחין ביניהן. במקום שההסכמה היא בסוף — `alpha-draft` לצד `beta-draft` — הסוף הוא מה שהולך; במקום שהיא בשני הקצוות, מה שנשאר הוא האמצע. שם ללא שכנים קרובים מאבד את האמצע שלו, שכן שם נפתח במה שהוא ונסגר במי הוא — עבור קובץ, הסיומת שלו: `annual…2026.md`.

רצף משותף קצר לא נספר. `parallel structures` נקרה שמסתיים באותן שתי אותיות כמו `Schemes` לצידו, וזו לא סיבה לשמור על אף אחד מהם שלם — שלושה תווים מהתחלה כבר מבחינים ביניהם.

שום דבר לא עובר לשורה שנייה. כשאפילו השמות ההגונים הקצרים ביותר לא נכנסים, השורה **גוללת הצידה**, חונה בקצה שבו נמצא הקובץ — באותה נקודה לא נותר עוד מה לדחוס, וחיתוך נוסף היה מסתיר במקום לקצר. הגלגלת גוללת אותה בכל מקום שהסמן מרחף מעל השורה, וניתן להגיע לשני הקצוות: בזמן שהיא גוללת, השורה מיושרת להתחלתה, לא משנה מה מגדיר הגדרת היישור, מכיוון שתוכן ממורכז בתיבה שגדל ממנה נשפך גם שמאלה וגם ימינה — ולאותו חצי אי אפשר להגיע כלל בגלילה.

**הצביעו על שם מקוצר והוא חוזר במלואו**, כל עוד אתם מצביעים עליו, גלול לקצה השמאלי כך שכל מה שחזר מוצג על המסך. **לחצו עליו והוא נשאר**: השדה נפתח ומציג את התיקייה שלחצתם עליה, מה שמוצע אחריה ומה שתקלידו, וממשיך להציג אותם לאחר שהסמן זז הלאה. שמות נשארים במקומם בזמן שאתם גוללים את השורה או מקלידים לתוכה — שם שקופץ ונפתח תחת תנועה שנועדה לקרוא את השורה היה מזיז את כל מה שאחריו מתחתכם.

ל**מקטע הפתיחה תמיד יש רמז כלים, וזהו הנתיב המוחלט** — `/home/you/Vaults/Notes`, או היכן שהשורה מתחילה. זה הדבר היחיד לגבי השורה שאף דבר על המסך לא יכול לומר: השם אומר לכם *באיזו* כספת, לעולם לא היכן היא נמצאת. הוא שם בין אם משהו נאלץ להתקצר ובין אם לא.

כאשר **הצגת שם הכספת** כבויה, השם אינו מוסר, רק מוחזק באפס — כך שהצבעה על הסמל מחזירה אותו בדיוק כפי שהצבעה על שם שהשורה נאלצה לקצר עושה.

**הצגת סיומות קבצים** מחזירה את הסיומת לשם הקובץ בשורה. כבוי — ברירת המחדל — השורה קוראת לפתק בשם כפי ש-Obsidian מכתיר אותו, ללא ה-`.md` שכמעט כל קובץ בכספת חולק; מופעל, היא קוראת לו כפי שמערכת הקבצים עושה, מה שרצוי כשהכספת מכילה יותר מפתקים. זהו גם הדבר השני שהשורה מוותרת עליו כשהמקום אוזל, מיד אחרי שם הכספת.
רמז כלים נותן לכם את השאר: לא רק את השם אלא הכול שהשורה מציגה מתחתיו, בתור `…/name/folder/note.md`, כך שריחוף אחד עונה גם על "מה זה" וגם על "מה נמצא מתחתיו". סמל הכספת נוקב בשם כספתו באותו האופן, כאשר השם כבוי או נדחס והלך.

הדרגה הכתומה צרה בכוונה. סוגים רשומים (Markdown, canvas, תמונות, PDF, שמע, וידאו) מטופלים כראוי ולא מקבלים דבר. קבצים בינאריים גם לא מקבלים דבר — אתם לא עומדים לערוך `.zip` לבלגן בטעות. מה שנותר הוא בדיוק הסיכון: `.json`, `.css` או `.log` ש**הצגת כל סוגי הקבצים** הפכה גלוי. הרשימה רחבה יותר במכוון: שם, כל מה שאינו פתק הוא כתום — ראו [כיצד נצבעים פריטי הרשימה](#כיצד-נצבעים-פריטי-הרשימה).

## מצב העברה/שינוי שם

כפתור העיפרון בקצה הימני ביותר של הכותרת — לצד כפתור מצב התצוגה, באותו גודל כמו הכפתורים המובנים — מחליף את מצב העברה/שינוי שם. מחוץ לכספת, מנעול אדום עומד במקומו עד שתלחצו עליו; ראו [כתיבה מחוץ לכספת](#כתיבה-מחוץ-לכספת). שורת הכותרת ממוסגרת אז בצבע ההדגשה, בדיוק כמו שינוי שם בסייר הקבצים. אותן לחיצות ומקשים כעת מבצעים העברה או שינוי שם דרך `fileManager.renameFile` של Obsidian, כך שכל הקישורים לפתק עוקבים בהתאם.

בזמן שינוי שם:

- שם הקובץ הנוכחי מוצמד לרשימה של כל תיקייה, כך שהעברת פתק בלי לשנות את שמו היא לחיצה אחת בלבד.
- שמות שכבר תפוסים בתיקיית היעד הם **אדומים** — תיקייה שכבר מחזיקה את השם, וקובץ באותו שם — כך שההתנגשות מוצגת לפני שאתם בוחרים. עדיין ניתן לבחור אותם: ראו למטה.
- הקלט מאומת בזמן אמת מול כללי שינוי השם של Obsidian עצמו — אותם קבוצות תווים, אותן הודעות, אותו רמז כלים אדום שאתם מקבלים בשינוי שם בעץ הקבצים — כך ששם לא חוקי מסומן בזמן ההקלדה ולא ניתן לאשר אותו.
- לחיצה מחוץ לשורת הכותרת, או אובדן המיקוד של הכותרת, מסיימים את מצב שינוי השם.

### שם שתפוס

העברה או שינוי שם לשם שכבר קיים **שואלים במקום לסרב.** תיבת דו-שיח נפתחת עם שני נתיבים שניתן לערוך: לאן הקובץ שלכם הולך, ולאן הקובץ שבדרך הולך — אדום כל עוד הוא עדיין תפוס. כל נתיב מצויר גם כן כפי שפס הנתיב מצייר אחד, עם החלקים השונים צבועים ומתקצרים אחרונים, כך שנתיב ארוך עדיין מציג מה משתנה.

לשני השדות יש רשימה. השנייה מחזיקה את הדרכים הרגילות לצאת מהמצב:

- **החלפת מקומות** — הוא עובר לתיקייה הישנה של הקובץ שלכם, תחת שמו שלו.
- **החלפת שמות** — הוא נשאר במקומו ולוקח את השם הישן של הקובץ שלכם.
- **החלפת שניהם** — הוא לוקח את הנתיב הישן של הקובץ שלכם.
- `-1`, `-bak` ו-`-old` לצד שמו שלו.
- שני השמות שהיו לקבצים.

הרשימה הראשונה מציעה לאן הקובץ שלכם היה הולך, **השארה במקום**, את שמו שלו בתיקיית היעד, ואת `-1`, `-bak` ו-`-old` לצידו. דרך יציאה שהנתיב שלה תפוס אפורה ולא ניתנת לבחירה. בחירה באחת **רק ממלאת את השדה** — עדיין ניתן לערוך אותו — ו**החלה** מעבירה את שניהם, קישורים וכל השאר; **ביטול** לא מעביר דבר. בחירת שם תפוס מהרשימה שואלת את אותה שאלה, וכך גם גרירת פתק לתיקייה שכבר מחזיקה את שמו.

## מקש אחד לשני שינויי השם

פקודת שינוי השם (<kbd>F2</kbd> כברירת מחדל, או כל מקש שמיפיתם לה) **מתחלפת** בין שינוי השם של הכותרת המוטבעת של Obsidian לבין שורת הנתיב בכותרת של תוסף זה. אם כיביתם את הכותרת המוטבעת של Obsidian, שורת הנתיב בכותרת הופכת ליעד היחיד, כך שהמקש אף פעם לא עושה כלום.

בשורת הנתיב הוא פותח את **השם ללא הסיומת שלו** — העריכה שכמעט כל שינוי שם הוא בפועל, ואותו הדבר שקורה בלחיצה על השם עצמו. לחצו עליו שוב והוא עושה מה ש<kbd>Tab</kbd> היה עושה שם: על השם, זהו השלב הבא — השם עם הסיומת שלו, הנתיב מתיקיית הכספת שלכם, הנתיב משורש המערכת; עם משהו שהוקלד, הוא משלים אותו, בדיוק כמו <kbd>Tab</kbd>.

**המחזור נסגר בכותרת.** חמש לחיצות מעבירות אתכם דרכו — הכותרת המוטבעת, השם, השם עם הסיומת שלו, הנתיב מהכספת שלכם, הנתיב משורש המערכת — והלחיצה השישית היא שוב הכותרת המוטבעת. לחיצה זו היא היחידה שונה מ‑<kbd>Tab</kbd>, שבמקום זאת חוזרת להתחלת הנתיב — והלחיצה השביעית מגיעה לאן ש‑<kbd>Tab</kbd> חוזר אליו: שורש הכספת, עם הנתיב המלא בשדה והתיקייה הראשונה שלו מסומנת. כך שכל שלב שאליו <kbd>Tab</kbd> מגיע, גם המקש מגיע אליו.

הפקודה **מיקוד בשורת הנתיב** עושה את אותו הדבר בתוך השדה — כל מה ש‑<kbd>Tab</kbd> היה עושה — ובמקום שבו <kbd>Tab</kbd> היה חוזר להתחלה, היא מחזירה את הסמן לפתק במקום זאת. הלחיצה הבאה שלה היא החזרה: שורש הכספת, עם התיקייה הראשונה מסומנת.

**בשדה שכבר פתוח**, המקש הופך אותו לשינוי שם במקום שבו הוא נמצא — תוך שמירה על הטקסט, מיקום הסמן והבחירה — ו**מיקוד בשורת הנתיב** מסיר ממנו את שינוי השם באותו האופן. **כל דבר אחר** שנלחץ או נלחץ עליו בין הלחיצות מתחיל כל אחד מהמחזורים מחדש, כך שלחיצה לאחר שערכתם משהו לעולם לא נוחתת על שלב שנותר מקודם.

מחוץ לכספת המקש עובד גם כן — אין שם כותרת מוטבעת, כך שהלחיצה הראשונה עוברת ישר לשורת הנתיב.

זה עובד על ידי עטיפת הפקודה `workspace:edit-file-title` במקום חטיפת המקש, ולכן גם מיפוי מחדש של הקיצור וגם הרצת הפקודה מהפלטה עובדים ללא שינוי.

## כיצד נצבעים פריטי הרשימה

| צבע | משמעות |
| --- | --- |
| **סגול** | פתק (`.md`, `.markdown`) — מה ש‑Obsidian יפתח כפתק, נבחר מתוך תיקייה של תוכן מעורב |
| **כתום** | לא פתק — כל דבר ש‑Obsidian לא יפתח ככזה, מ‑PDF ועד `.txt`, ויחד איתם פריטי `:page`. תיקייה של תוכן מעורב נסרקת עבור הפתקים שבה, וצבע אחד לכל השאר אומר זאת מהר יותר מאזהרה על חלקם בלבד; ראו [צבעי האזהרה](#צבעי-האזהרה) |
| **מעומעם** | מחוץ לכספת, כך שהטיפול של הכספת עצמה לא חל |
| **כחול**, מודגש | היכן שאתם כבר נמצאים: הפתק של שורה זו עצמה, והתיקייה שעליה שורת הנתיב עומדת. במצב העברה/שינוי שם הפריט *השאירו שם זה* עומד במקום הפתק — אותו פתק בכל מקרה |

**תיקיות מודגשות**, כך שהפתק של תיקייה לא זקוק לצבע משלו כדי לבלוט מתוך התיקייה שלו: הוא סגול כמו כל פתק אחר. **קו לאורך שולי השורה** מסמן שמות שמתחילים במה שהקלדתם — כחול היכן שהם ממשיכים להתאים, ירוק על הענף שההצעה נוקטת; ראו [הקלדת נתיב](#הקלדת-נתיב).

השדה נוקט באותם צבעים עבור מה שהוא נוקב בו — ראו [הקלדת נתיב](#הקלדת-נתיב).

## כללי נראות

- קבצים עם סיומות שאינן נתמכות מופיעים ברשימות רק אם הגדרת **Detect all file extensions** של Obsidian מופעלת — **בתוך הכספת**. מחוצה לה ההגדרה לא חלה: היא קובעת מה הכספת מוסיפה לאינדקס, ושום דבר בחוץ אינו בכספת, כך ש‑`.txt` לצד הפתקים שלכם מופיע בכל מקרה.
- הרשימה מציגה עד 1,000 פריטים, פי עשרה מהמגבלה של Obsidian עצמו. כשבתיקייה יש יותר, השורה האחרונה מציינת כמה הושמטו; המשיכו להקליד כדי לצמצם את הרשימה.
- קבצי נקודה ותיקיות נקודה מופיעים רק אם הגדרת **Show dot files** של תוסף זה מופעלת.
- **ההגנה מפני שכתוב פועלת באופן זהה ללא קשר לנראות** — קובץ מוסתר עדיין חוסם אתכם מלשכתב אותו.

## דף עזר

נתיב **עטוף במרכאות** מוסר מהעטיפה עבורכם. *Copy as path* של Windows מוסר `"C:\Users\you\note.md"`, מרכאות כלולות, ומעטפת פקודות (shell) עושה את אותו הדבר לכל נתיב עם רווח בו; הדבקת אחד כזה או הקלדתו עובדות בשני המקרים. רק המרכאות הכפולות, ורק כזוג תואם סביב הדבר כולו — הן לא יכולות להופיע בשם אמיתי, שבו גרש דווקא כן יכול.

## החלפת הסמלים

Lure מציג שלושה סמלים: סמל שורש הכספת (כאשר **הצגת שם הכספת** כבויה), מתג ההעברה/שינוי שם, והמנעול שעומד במקומו בזמן שכתיבה מחוץ לכספת נעולה. את כולם ניתן להחליף מתבנית עיצוב או מקטע CSS — קבעו את סימן התחליף והסתירו את זה המובנה בכלל אחד:

```css
.lure-vault-icon {
	--lure-icon-glyph: "🏠";
	--lure-icon-svg: none;
}

.lure-rename-btn {
	--lure-icon-glyph: "✎";
	--lure-icon-svg: none;
}

/* Only ever shown shut: opening it hands the slot to the rename toggle. */
.lure-unlock-btn {
	--lure-icon-glyph: "🔒";
	--lure-icon-svg: none;
}
```

`--lure-icon-glyph` מקבל כל דבר תקף ב‑`content` של CSS, ולכן `url(...)` עובד לתמונה בדיוק כמו לסימן טקסט או אמוג'י. השאירו את `--lure-icon-svg` כמות שהוא כדי לשמור על סמל Lucide ולצייר את הסימן שלכם לצדו.
