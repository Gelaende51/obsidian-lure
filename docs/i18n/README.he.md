# Lure

תוסף ל-[Obsidian](https://obsidian.md) שהופך את שם הקובץ בשורת הכותרת של פתק לנתיב מלא בתוך הכספת, שאפשר ללחוץ עליו ולערוך אותו — בדיוק כמו שורת הכתובת במנהל הקבצים [Dolphin](https://apps.kde.org/dolphin/).

![לחיצה על המפריד שאחרי תיקייה: הסמן מונח עליו, וסייר קבצים הציג את התיקייה הזו ופרש אותה](../images/breadcrumb.png)

Obsidian 1.8.7+ · למחשב שולחני בלבד · AGPL-3.0

## גילוי נאות בנוגע לבינה מלאכותית

- **הסוכן** — **Claude Opus 5** ו-**Claude Sonnet 5** (Anthropic, דרך Claude Code): כתב את ה-TypeScript, את ה-CSS, את כל 45 מערכות התרגום ואת התיעוד. התרגומים נוצרו במכונה ולא נבדקו בידי דוברי שפת אם.
- **צריכה** — 3–13 באוגוסט 2026, תשעה מפגשים, כ-4,928 תשובות: כ-7.2 מיליון אסימונים שנוצרו, כ-23.7 מיליון שנשלחו, כ-1169.6 מיליון קריאות חוזרות מהמטמון (כ-1200.5 מיליון בסך הכול).
- **מקור** — המודל למד מקוד פתוח, מתיעוד ומכתיבה קהילתית שאחרים פרסמו. רוב הקרדיט שייך שם.
- **המחבר** — Vault51: הגדיר כל יכולת, בדק כל גרסה בכספת אמיתית, הנחה את התיקונים וסקר את כל התוצרים.

## יכולות

- **לחיצה על תיקייה** פותחת רשימה של תוכן התיקייה *שמעליה* — החליפו תיקייה אחת בשכנתה בלי לגעת בשאר הנתיב. שם הפתק פועל באותו אופן, כולל הסיומת.
- **לחיצה על המפריד** שאחרי תיקייה מציגה אותה בסייר קבצים ופורשת אותה. הגדרה אחת מחליפה בין שני התפקידים.
- **לחיצה ימנית או גרירה של כל פריט** — תפריט ההקשר והתנהגות הגרירה של סייר קבצים עצמו.
- **לחיצה על שם הקובץ או על שטח ריק** מאפשרת להקליד נתיב, עם השלמה. `/` יורד פנימה, <kbd>Backspace</kbd> עולה רמה אחת, <kbd>Enter</kbd> מאשר.
- **כפתור העיפרון על תיקייה** מעביר את אותן פעולות למצב העברה/שינוי שם, עם אותן בדיקות ש-Obsidian עצמו עושה.
- **החזקת <kbd>Ctrl</kbd>** פותחת בלשונית חדשה — או, במצב העברה/שינוי שם, מעתיקה את הפתק לשם במקום להעביר אותו.
- **<kbd>F2</kbd>** מחליף בין הכותרת שבתוך הפתק לשורת הנתיב.
- **לחיצה על שם הכספת** מאפשרת לעיין בכספות האחרות שלכם, בתיקיית הבית, בשורש מערכת הקבצים ובכוננים המחוברים בלי להחליף כספת. לקריאה בלבד עד שתפתחו מנעול, וכל אותו זמן ממוסגר בצבע השגיאה. כבוי כברירת מחדל — ראו [מחוץ לכספת](#מחוץ-לכספת).
- **שתי דרגות אזהרה** — אדום מחוץ לכספת, כתום לקובצי טקסט שאין ל-Obsidian עורך עבורם. ראו [שני צבעי האזהרה](usage.he.md#שני-צבעי-האזהרה).
- **סמלים שמתאימים לערכת הנושא**, ניתנים להחלפה מקטע CSS — ו-**45 שפות**, כל שפה ש-Obsidian מביא עמו.
- **הגדרות:** יישור, מפרידים מוכנים, איזו לחיצה פותחת את הרשימה, שם הכספת, קבצים מוסתרים.

![אותה רשימה במצב העברה/שינוי שם: שם הקובץ הנוכחי מוצמד למעלה, התיקיות השכנות מתחתיו, והפתקים הקיימים מעומעמים](../images/dropdown.png)

*במצב העברה/שינוי שם אותה רשימה מציעה דבר אחר: שם הפתק הנוכחי מוצמד למעלה כדי להעביר אותו בלי לשנות את שמו, תיקיות שאפשר להעביר אליהן, והשמות התפוסים כבר מעומעמים כדי שדבר לא ידרס בטעות.*

## מחוץ לכספת

מדיניות המפתחים של Obsidian מחייבת תוסף להסביר כל גישה לקבצים מחוץ לכספת, ולכן בפשטות:

**האם הוא בכלל עושה משהו מזה.** רק אם תפעילו את **גישה לקבצים חיצוניים**, שהיא **כבויה כברירת מחדל**. כשההגדרה כבויה אין שום דרך מהתוסף אל נתיב חיצוני, ושום שורה מהקוד שמתואר להלן אינה רצה אי פעם.

**מה הוא קורא.** רק כשאתם מבקשים. לחיצה על שם הכספת מציגה את הכספות האחרות שלכם — הנקראות מתוך `obsidian.json` של Obsidian עצמו — וכן את תיקיית הבית, את שורש מערכת הקבצים ואת הכוננים המחוברים (`/proc/mounts` בלינוקס, `/Volumes` ב-macOS, אותיות כוננים ב-Windows). עיון משם והלאה מציג את תוכן התיקיות, ופתיחת קובץ קוראת אותו קובץ יחיד בלבד.

**מה הוא כותב.** כלום, עד שתלחצו על כפתור שאומר זאת. יש שני כפתורים כאלה, וכל אחד מכסה רק את התחום שלו:

- כפתור **ערוך כטקסט** במציג משחרר את הקובץ שלפניכם, אותו קובץ יחיד באותה לשונית יחידה. מכאן ואילך השינויים שלכם נשמרים אליו תוך כדי הקלדה.
- **המנעול** בשורת הכותרת, שמופיע רק כל עוד שורת הנתיב מצביעה אל מחוץ לכספת, משחרר יצירה, שינוי שם והעברה בנתיבים חיצוניים. הוא ננעל שוב ברגע שאתם חוזרים פנימה, כך שההרשאה לעולם אינה שורדת את התיקייה שעבורה ניתנה.

אף אחד משני השחרורים אינו נשמר במרחב העבודה או בהגדרות, ולכן הכתיבה לעולם אינה דרוכה על קובץ שאינכם זוכרים שפתחתם. באף אחד משני המצבים דבר אינו נדרס — יעד קיים נדחה, תוך שימוש ביצירה הבלעדית של מערכת הקבצים עצמה במקום בבדיקה שעלולה להפסיד את המרוץ — ופתק לעולם אינו יכול *לעבור* אל מחוץ לכספת, כי הקישורים אליו היו נשברים בשקט; החזקת <kbd>Ctrl</kbd> מעתיקה אותו החוצה במקום זאת.

**למה.** הפתקים שאתם מחפשים נמצאים לא פעם בכספת אחרת, בתיקיית סנכרון או על החסן USB, והתשובה של Obsidian עצמו — החליפו כספת — סוגרת את כל מה שהיה פתוח לכם. זה מאפשר לכם ללכת ולהציץ בלי לעזוב, ולתקן שגיאת הקלדה כשאתם כבר שם.

**המגבלה.** העורך של Obsidian קשור לקבצים שבתוך הכספת, ולכן קובץ חיצוני **אינו יכול** להיפתח כפתק אמיתי, עם קישורים, קישורים נכנסים וכל השאר; שום תוסף אינו מסוגל לכך. במקום זאת Lure מציג אותו במציג שלו (Markdown, תמונות, שמע, וידאו, PDF), ולכל השאר מוצע *פתח חיצונית*. שורת הנתיב נשארת ממוסגרת בצבע השגיאה בכל פעם שהיא מצביעה אל מחוץ לכספת, והעקבות מתחילים במקום שבחרתם — שם של כספת, תיקיית הבית שלכם, כונן — ולא במבנה התיקיות של המחשב.

## התקנה

רשום ב-[community.obsidian.md/plugins/lure](https://community.obsidian.md/plugins/lure), אך טרם אושר לדפדפן שבתוך היישום — התקינו אותו באחת מהדרכים האלה:

**ידנית:** הורידו את `main.js`, `manifest.json` ו-`styles.css` מ[הגרסה האחרונה](https://github.com/Gelaende51/obsidian-lure/releases) אל `<vault>/.obsidian/plugins/lure/`, ואז הפעילו אותו תחת **הגדרות ← תוספים קהילתיים**.

**BRAT:** הוסיפו את `Gelaende51/obsidian-lure` כתוסף בטא.

**מהמקור:** `npm install && npm run build` — ראו [פיתוח](../development.md).

## תאימות

אין צורך בשום תוסף. **סייר קבצים** המובנה, אם הוא מופעל, הוא זה שמציג את התיקיות בסרגל הצד; בלעדיו הלחיצות האלה אינן עושות דבר.

נבדק מול תוספי הקהילה שחולקים את שורת הכותרת של הפתק או מגיבים ללחיצה על תיקייה — בשני סדרי הטעינה, כל אחד מופעל ומכובה:

- [Folder notes](obsidian://show-plugin?id=folder-notes) — המפריד פותח את הפתק של התיקייה במקום להציג את התיקייה, וכך כל מקטע בנתיב הופך למקום שאפשר להגיע אליו. זהו תוסף פתקי התיקיות היחיד שתופס את הנתיב בשורת הכותרת; [Folder Note](obsidian://show-plugin?id=folder-note-plugin) ו-[create folder notes with dropdown](obsidian://show-plugin?id=create-folder-notes-with-dropdown) אינם מאזינים שם, ולכן המפריד מציג את התיקייה כרגיל.
- [Quick Explorer](obsidian://show-plugin?id=quick-explorer) ו-[Front Matter Title](obsidian://show-plugin?id=obsidian-front-matter-title-plugin) — שניהם מציירים לאותו רכיב בשורת הכותרת; Lure שומר על השורה שלו לא משנה מי נטען ראשון, וכיבוי אחד מהם משאיר את השני שלם.
- [Nav Link Header](obsidian://show-plugin?id=nav-link-header), [Running Head](obsidian://show-plugin?id=running-head), [Crumbs](obsidian://show-plugin?id=crumbs-obsidian), [Breadcrumbs](obsidian://show-plugin?id=breadcrumbs) — לכל אחד רצועה משלו, והם חיים יחד בלי בעיה.

למחשב שולחני בלבד — מודל האינטראקציה דורש ריחוף עכבר, לחיצות מדויקות ומקלדת. התוצאות המלאות, מה שנותר לבדוק, וההשוואה מול Quick Explorer ו-Breadcrumbs נמצאים ב[תאימות](../compatibility.md).
