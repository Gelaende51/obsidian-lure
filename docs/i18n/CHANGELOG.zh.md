# 更新日志

Lure 的每一个版本，最新的在前。自上次发布以来已合入的内容列在*未发布*下。版本号不带 `v` 前缀，与发布标签一致。

## 未发布[^unreleased]

### 新增

- **从外部把文件带入仓库**。把磁盘上任意位置的文件移动或复制到仓库内的某个路径；它会作为真正的笔记进入仓库，而移动操作只有在复制成功之后才会删除原文件。
- **把文本或文件拖到路径栏上即可记下来**。拖到文件夹上：在该文件夹中新建一篇笔记，名称由你输入。拖到笔记名称上，或拖到带有文件夹笔记的文件夹的分隔符上：经确认后追加到该笔记末尾。
- **创建文件夹笔记**：在运行了文件夹笔记插件、且该文件夹尚无文件夹笔记时，在用来打开该文件夹的位置再按一次即可。它会放在 [Folder notes](https://github.com/LostPaul/obsidian-folder-notes) 自身设置所指定的位置。
- **把文件夹从路径栏拖到标签栏上**即可在那里打开：有文件夹笔记时打开文件夹笔记，否则打开一个停在该文件夹中的标签页。
- **滚轮可以浏览列表**。在名称上方，第一次滚动会打开该名称的列表，之后每滚一下，高亮移动一行。正在横向滚动的行会保留滚轮用于滚动。
- **用方向键越过输入框的开头**，把它前面的文件夹也纳入进来：<kbd>←</kbd> 纳入一个文件夹，<kbd>Shift</kbd>+<kbd>Home</kbd>（列表关闭时为 <kbd>Home</kbd>）纳入全部。
- **输入框带上它所指内容的颜色**，与列表中该行的颜色相同，一旦没有对应的内容就变红——也就是按下 <kbd>Enter</kbd> 将会新建而非打开的那一刻。
- **文件夹笔记在列表中显示为灰色**，这样它们看起来属于各自的文件夹，而不是又一篇普通笔记。
- **中键点击分隔符**即可在新标签页中打开该文件夹：打开它的文件夹笔记，或打开一个停在该文件夹中的标签页。

### 变更

- **挂锁和重命名开关合并为一个控件**。在仓库之外，一把锁着的红色挂锁占据开关的位置；打开它就把位置交给开关，退出重命名模式时它又会重新锁上。
- **重命名键也会询问挂锁**。在仓库之外，按一次会让挂锁闪烁；半秒内再按一次，就会授予挂锁所授予的权限并进入重命名模式。
- **重命名键走完整的一圈**——内联标题、名称、带扩展名的名称、从仓库起的路径、从系统根目录起的路径——再按一次又回到内联标题。
- **<kbd>Ctrl</kbd>+点击和中键点击不再是同义操作**。一个打开标签页并切换过去，另一个在后台打开。
- **右键点击笔记名称会打开该文件自己的菜单**。
- **列表的高度尽可能占满窗口**，而不是 Obsidian 固定的 300 像素。
- **输入框打开时点击文件夹，会保留其后的整个路径**，在输入框内点击进入某个文件夹，会完整列出该文件夹的内容。
- **运行 Folder notes 时，分隔符在任何深度都能打开文件夹笔记**，凡有文件夹笔记之处都会加下划线。此前只有顶层文件夹可以。使用其他文件夹笔记插件时，分隔符仍然定位文件夹。

### 修复

- **打开的输入框比它的文件存续得更久**。在路径栏打开时切换到另一篇笔记，该行会在会话的剩余时间里一直显示旧文件的名称。
- **挂锁打开时，删除、重命名和创建副本在仓库之外被拒绝**，而且对图片、PDF 和网页根本无法使用。
- **列表打开时 <kbd>Ctrl</kbd>+<kbd>Enter</kbd> 没有任何作用**——而每个输入框打开时列表都是打开的。
- **列表打开但没有高亮项时按 <kbd>Enter</kbd>** 没有任何作用；现在会确认你输入的内容。
- **当所有名称都已缩到最短、行仍然溢出时无法滚动**，导致路径的末尾无法触及。
- **停用插件后会留下一个失效的按钮**，出现在它修补过的每篇笔记的标题栏中。

## 1.2.0 — 2026-08-25[^1.2.0]

### 新增

- **语言设置**。Lure 默认跟随 Obsidian 的语言，也可以设置为它自带的任一语言。这也是使用希腊语和梵语翻译的唯一途径，因为 Obsidian 本身不提供这两种语言。该设置自身的标签保持英文，这样即使切换到你看不懂的语言，也总能再找到它。

## 1.1.2 — 2026-08-25[^1.1.2]

### 变更

- **更轻量的样式表**。该行不再使用 `:has()` 选择器，也去掉了大部分 `!important` 规则。重新适配所需的工作更少，插件审核的警告从 56 条降到 7 条。

## 1.1.1 — 2026-08-22[^1.1.1]

### 修复

- **较短的文件夹名称可能在中间出现空隙**——`atlas` 显示为 `atl as`——因为为其缩写形式预留的空间比名称本身还宽。

## 1.1.0 — 2026-08-22[^1.1.0]

### 新增

- **右键操作体系**。按一次打开菜单；按两次、三次会逐步复制更多内容——名称、带扩展名的名称、路径。行上的菜单现在与文件列表的菜单条目一一对应。
- **仓库之外的菜单**。列表行和外部查看器提供打开、*复制路径*和*在系统资源管理器中显示*；挂锁打开时，还有*新建笔记*、*新建文件夹*、*创建副本*、*重命名…* 和*删除*。删除会移到系统回收站，绝不会永久删除。
- **在其他位置打开**。在笔记名称或文件夹上使用 <kbd>Ctrl</kbd>、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd> 和中键点击，可以在新标签页、分屏或新窗口中打开它。两者都可以拖拽，与它们在文件列表中的对应行一样。
- **把笔记拖到路径栏上即可移动**。把一篇笔记、多篇笔记或一个文件夹拖到某个文件夹段或仓库名上。
- **命令：聚焦路径栏**，打开时选中整个路径——没有默认快捷键，请自行绑定。
- **在路径栏中输入网址**：`http(s)://` 和 `obsidian://` 作为链接打开，`file://` 和百分号编码的路径则打开对应文件。
- **Tab 补全**，与 shell 的方式相同：每按一次，补全到该文件夹中各名称一致为止，并在出现分歧处停下。<kbd>Shift</kbd>+<kbd>Tab</kbd> 往回走。没有可补全的内容时，<kbd>Tab</kbd> 改为扩大选区：名称、带扩展名的名称、从仓库起的路径、从系统根目录起的路径。
- **列表在你所处的位置打开**，并把你指向的内容预览到输入框中；离开列表会还原你输入的文本。
- **把笔记移出仓库**，需先经过一个统计将会断开的链接数的确认。笔记先被复制出去，再移入回收站，因此可以像任何被删除的笔记一样恢复。
- **显示文件扩展名**设置；并且能识别带引号的路径（即 Windows 的*复制文件地址*所生成的形式）。
- **设置会出现在 Obsidian 的设置搜索中**，适用于 Obsidian 1.13 及更高版本。

### 变更

- **长路径适应窗格宽度**。名称从最不重要的开始缩短——先是仓库名，然后是扩展名，再是文件夹，笔记自己的名称最后——绝不缩到无法相互区分的程度。悬停在缩短的名称上即可看到全名。
- **点击笔记名称时选中的名称不含扩展名**，所以重命名时不再有改变文件类型的风险。
- **重命名键打开时选中不含扩展名的名称**，继续按会扩大选区。
- **点击文件夹时，路径的其余部分保持可见**，在仓库之外也是如此。
- **从外部浏览回仓库时，文件会以笔记形式打开**，带有链接和反向链接，而不是在外部查看器中打开。

### 修复

- **菜单标签在所有语言中都是英文**；现在它们取自 Obsidian 自己的翻译。
- **当笔记滚动到标题以下时，重命名键会卡在 Obsidian 的重命名对话框上**。
- **<kbd>Esc</kbd> 需要按两次**才能关闭输入框及其列表。
- **<kbd>Ctrl</kbd>+<kbd>Enter</kbd> 在编辑器中打开了链接**，而不是作用于路径栏。
- **在仓库之外重命名时，按下挂锁会丢失已输入的名称**。
- **Tab 可能原地循环而毫无进展**，发生在与自身文件夹笔记并列的文件夹上。

## 1.0.4 — 2026-08-13[^1.0.4]

### 新增

- **你当前所在的笔记在列表中以蓝色标出**，这样浏览回它所在的文件夹时，能看出你是从哪里出发的。

## 1.0.3 — 2026-08-13[^1.0.3]

### 文档

- README 链接了插件在社区目录中的页面，各语言译版的 README 也已更新。

## 1.0.2 — 2026-08-13[^1.0.2]

### 变更

- **需要 Obsidian 1.8.7 或更高版本**（此前为 1.4.0）。路径栏依赖的两项功能——复制文件和输入框下方的错误提示——需要该版本。
- **发布的下载文件附带签名的构建来源证明**，你可以用 `gh attestation verify` 确认 `main.js` 是由本代码仓库构建的。

### 修复

- **用默认应用打开不存在的外部文件时会静默失败**；现在会报告该失败。

## 1.0.1 — 2026-08-13[^1.0.1]

### 修复

- **在重命名模式下，笔记会与自身冲突**——浏览回它自己的文件夹时，它的名称从列表中消失，仿佛它阻挡了自己的重命名。
- **启动 Obsidian 后第一次定位文件夹时没有展开任何内容**。
- **从列表中选择文件夹可能会结束重命名模式**，而不是进入该文件夹。
- **外部编辑可能被另一个写入方悄无声息地覆盖**，例如 Sync 或第二个窗格。现在写入是原子操作。
- **焦点轮廓的重置泄漏到了其他视图中**；现在只作用于 Lure 修补过的标题栏。

### 文档

- README 和使用指南已提供插件所含全部 44 种语言的版本。
- 指南中提到的 Obsidian 设置 *Detect all file extensions*（检测所有文件扩展名）现已更名为 *检测所有类型文件*。

## 1.0.0 — 2026-08-10[^1.0.0]

首次发布。把笔记标题栏中的文件名替换为一条可点击、可编辑的面包屑导航，显示其仓库路径——一个为笔记准备的地址栏，仿照 Dolphin 的地址栏设计。

### 新增

- **点击文件夹**，弹出其父文件夹内容的列表，可以把它换成同级的另一个，路径的其余部分保持不变。
- **点击文件夹后面的分隔符**，在文件列表中定位并展开该文件夹；如果该文件夹由 Folder notes 处理，则打开其文件夹笔记。
- **点击文件名或空白处**即可输入路径，并带自动补全：`/` 进入下一级，<kbd>Backspace</kbd> 退回上一级，<kbd>Enter</kbd> 确认。
- **移动/重命名模式**把同样的交互切换为移动和重命名，校验方式与 Obsidian 一致。
- **<kbd>Ctrl</kbd> 在新标签页中打开**——在移动/重命名模式下，则改为把笔记复制过去。
- **<kbd>F2</kbd> 在内联标题和路径栏之间切换**。
- **仓库之外**（默认关闭）：仓库名会打开你的其他仓库、主目录、文件系统根目录和已挂载的驱动器。在那里，除非你解锁，否则不会写入任何内容；笔记只能复制出仓库，绝不能移动出去。
- **45 种语言**。
