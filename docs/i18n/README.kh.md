# Lure

កម្មវិធីជំនួយសម្រាប់ [Obsidian](https://obsidian.md) ដែលបំប្លែងឈ្មោះឯកសារនៅលើរបារចំណងជើងរបស់កំណត់ចំណាំទៅជាផ្លូវពេញលេញឆ្លងកាត់ឃ្លាំងទាំងមូល ដែលអាចចុចនិងកែសម្រួលបាន — ដូចរបារអាសយដ្ឋាននៅក្នុងកម្មវិធីគ្រប់គ្រងឯកសារ [Dolphin](https://apps.kde.org/dolphin/)។

## ការបង្ហាញអំពី AI

- **ភ្នាក់ងារ** — **Claude Opus 5** និង **Claude Sonnet 5** (Anthropic តាមរយៈ Claude Code)៖ បានសរសេរកូដ TypeScript, CSS, ឈុតបកប្រែទាំង ៤៥ និងឯកសារណែនាំ។ ការបកប្រែធ្វើឡើងដោយម៉ាស៊ីន ហើយអ្នកនិយាយដើមកំណើតមិនបានពិនិត្យទេ។
- **អ្នកនិពន្ធ** — Vault51៖ បានកំណត់មុខងារនីមួយៗ សាកល្បងកំណែនីមួយៗនៅក្នុងឃ្លាំងពិត ដឹកនាំការកែតម្រូវ និងពិនិត្យលទ្ធផលទាំងអស់។
- **ការប្រើប្រាស់** — ថ្ងៃទី ៣–១៣ សីហា ២០២៦ ប្រាំបួនវគ្គ ប្រហែល ៤.៩២៨ ចម្លើយ៖ បង្កើតបានប្រហែល ៧,២ លានថូខឹន បញ្ជូនប្រហែល ២៣,៧ លាន អានឡើងវិញពីឃ្លាំងសម្ងាត់ប្រហែល ១១៦៩,៦ លាន (សរុបប្រហែល ១២០០,៥ លាន)។
- **ប្រភពដើម** — ម៉ូដែលដែលសរសេរកម្មវិធីជំនួយ Obsidian បានរៀនរឿងនេះពីកូដប្រភពបើកចំហ ឯកសារណែនាំ ចម្លើយក្នុងវេទិកា និងរបាយការណ៍កំហុស ដែលមនុស្សបានសរសេរ ហើយផ្តល់ឲ្យដោយឥតគិតថ្លៃ។ គ្មាននរណាម្នាក់ក្នុងចំណោមពួកគេត្រូវបានសួរ ដាក់ឈ្មោះ ឬបង់ប្រាក់ឲ្យទេ។ នោះជាការរួមចំណែកធំបំផុតដែលគ្មានឈ្មោះនៅទីនេះ ហើយវាសមនឹងទទួលការគាំទ្ររបស់អ្នកជាងកម្មវិធីជំនួយនេះ៖ បើអ្នកកំពុងជ្រើសរើសកន្លែងផ្ញើអ្វីមួយ សូមផ្ញើទៅទីនោះ។

## មុខងារ

- **ចុចលើថតមួយ** ដើម្បីមើលបញ្ជីមាតិកានៃថត*មេ*របស់វា — ប្តូរថតមួយទៅថតជាប់គ្នាដោយមិនប៉ះផ្នែកផ្សេងទៀតនៃផ្លូវ។ ឈ្មោះកំណត់ចំណាំក៏ដំណើរការដូចគ្នា រួមទាំងផ្នែកបន្ថែមផង។
- **ចុចលើសញ្ញាបំបែក** បន្ទាប់ពីថតមួយ ដើម្បីបង្ហាញនិងលាតវានៅក្នុងឯកសារ។ ការកំណត់តែមួយប្តូរតួនាទីទាំងពីរនេះ។
- **ចុចខាងស្ដាំ ឬអូសធាតុណាមួយ** — ម៉ឺនុយបរិបទ និងឥរិយាបថអូសរបស់ឯកសារផ្ទាល់។
- **ចុចលើឈ្មោះឯកសារ ឬកន្លែងទំនេរ** ដើម្បីវាយបញ្ចូលផ្លូវ ជាមួយការបំពេញស្វ័យប្រវត្តិ។ `/` ចុះទៅក្នុង, <kbd>Backspace</kbd> ឡើងមួយកម្រិត, <kbd>Enter</kbd> បញ្ជាក់។
- **ប៊ូតុងខ្មៅដៃលើថត** ប្តូរអន្តរកម្មដដែលទៅជារបៀបផ្លាស់ទី/ប្តូរឈ្មោះ ជាមួយការត្រួតពិនិត្យដូចដែល Obsidian ធ្វើដោយខ្លួនឯង។
- **សង្កត់ <kbd>Ctrl</kbd>** ដើម្បីបើកនៅក្នុងផ្ទាំងថ្មី — ឬនៅក្នុងរបៀបផ្លាស់ទី/ប្តូរឈ្មោះ ដើម្បីចម្លងកំណត់ចំណាំទៅទីនោះជំនួសឱ្យការផ្លាស់ទីវា។
- **<kbd>F2</kbd>** ប្តូររវាងចំណងជើងនៅក្នុងកំណត់ចំណាំ និងរបារផ្លូវ។
- **ចុចលើឈ្មោះឃ្លាំង** ដើម្បីរុករកឃ្លាំងផ្សេងទៀតរបស់អ្នក ថតផ្ទះ ឫសនៃប្រព័ន្ធឯកសារ និងដ្រាយដែលបានភ្ជាប់ ដោយមិនចាំបាច់ប្តូរឃ្លាំង។ អានបានតែប៉ុណ្ណោះរហូតដល់អ្នកបើកសោ ហើយក្នុងអំឡុងពេលនោះមានស៊ុមពណ៌កំហុសជុំវិញ។ បិទតាំងពីដំបូង — សូមមើល [ក្រៅឃ្លាំង](#ក្រៅឃ្លាំង)។
- **កម្រិតព្រមានពីរ** — ក្រហមនៅក្រៅឃ្លាំង ទឹកក្រូចសម្រាប់ឯកសារអត្ថបទដែល Obsidian គ្មានកម្មវិធីកែសម្រួល។ សូមមើល [ពណ៌ព្រមានទាំងពីរ](usage.kh.md#ពណ៌ព្រមានទាំងពីរ)។
- **រូបតំណាងតាមរូបរាង** អាចប្តូរបានពីបំណែក CSS — និង **៤៥ ភាសា** គ្រប់ភាសាដែល Obsidian នាំមកជាមួយ។
- **ការកំណត់៖** ការតម្រឹម សញ្ញាបំបែកសម្រេច ការចុចមួយណាបើកបញ្ជី ឈ្មោះឃ្លាំង ឯកសារលាក់។

![បញ្ជីដដែលនៅក្នុងរបៀបផ្លាស់ទី/ប្តូរឈ្មោះ៖ ឈ្មោះបច្ចុប្បន្នរបស់ឯកសារខ្ទាស់នៅខាងលើ ថតជិតខាងនៅខាងក្រោម ហើយកំណត់ចំណាំដែលមានស្រាប់ត្រូវធ្វើឱ្យស្រអាប់](../images/dropdown.png)

## ក្រៅឃ្លាំង

គោលការណ៍សម្រាប់អ្នកអភិវឌ្ឍន៍របស់ Obsidian តម្រូវឱ្យកម្មវិធីជំនួយពន្យល់រាល់ការចូលប្រើឯកសារនៅក្រៅឃ្លាំង ដូច្នេះនិយាយត្រង់ៗ៖

**តើវាធ្វើអ្វីមួយក្នុងចំណោមទាំងនេះឬទេ។** តែក្នុងករណីអ្នកបើក **ការចូលប្រើឯកសារខាងក្រៅ** ដែល**បិទតាំងពីដំបូង**។ ពេលការកំណត់នេះបិទ គ្មានផ្លូវណាពីកម្មវិធីជំនួយទៅដល់ផ្លូវខាងក្រៅទេ ហើយគ្មានកូដណាមួយដែលរៀបរាប់ខាងក្រោមដំណើរការឡើយ។

**តើវាអានអ្វី។** តែពេលអ្នកស្នើសុំប៉ុណ្ណោះ។ ការចុចលើឈ្មោះឃ្លាំងបង្ហាញបញ្ជីឃ្លាំងផ្សេងទៀតរបស់អ្នក — អានចេញពី `obsidian.json` របស់ Obsidian ផ្ទាល់ — បូកនឹងថតផ្ទះ ឫសនៃប្រព័ន្ធឯកសារ និងដ្រាយដែលបានភ្ជាប់ (`/proc/mounts` លើ Linux, `/Volumes` លើ macOS, អក្សរដ្រាយលើ Windows)។ ការរុករកបន្តពីទីនោះបង្ហាញមាតិកាថត ហើយការបើកឯកសារអានតែឯកសារនោះមួយប៉ុណ្ណោះ។

**តើវាសរសេរអ្វី។** គ្មានអ្វីទាល់តែសោះ រហូតដល់អ្នកចុចប៊ូតុងដែលនិយាយបែបនោះ។ ប៊ូតុងបែបនេះមានពីរ ហើយនីមួយៗគ្របដណ្តប់តែផ្នែករបស់ខ្លួន៖

- ប៊ូតុង **កែសម្រួលជាអក្សរ** នៅក្នុងកម្មវិធីមើលដោះសោឯកសារនៅពីមុខអ្នក គឺឯកសារនោះមួយនៅក្នុងផ្ទាំងនោះមួយប៉ុណ្ណោះ។ បន្ទាប់មកការកែប្រែរបស់អ្នកត្រូវរក្សាទុកទៅក្នុងវាតាមពេលអ្នកវាយ។
- **សោ** នៅលើរបារចំណងជើង ដែលបង្ហាញតែពេលរបារផ្លូវចង្អុលទៅក្រៅឃ្លាំង ដោះសោការបង្កើត ការប្តូរឈ្មោះ និងការផ្លាស់ទីនៅលើផ្លូវខាងក្រៅ។ វាចាក់សោវិញភ្លាមៗនៅពេលអ្នកត្រឡប់ចូលក្នុង ដូច្នេះការអនុញ្ញាតមិនដែលរស់យូរជាងថតដែលអ្នកបានផ្តល់ឱ្យវាទេ។

ការដោះសោទាំងពីរមិនត្រូវបានរក្សាទុកនៅក្នុងកន្លែងធ្វើការ ឬនៅក្នុងការកំណត់ទេ ដូច្នេះការសរសេរមិនដែលនៅត្រៀមលើឯកសារដែលអ្នកមិនចាំថាបានបើកនោះទេ។ នៅក្នុងស្ថានភាពទាំងពីរ គ្មានអ្វីត្រូវសរសេរជាន់ទេ — គោលដៅដែលមានស្រាប់ត្រូវបានបដិសេធ ដោយប្រើការបង្កើតផ្តាច់មុខរបស់ប្រព័ន្ធឯកសារផ្ទាល់ មិនមែនការត្រួតពិនិត្យដែលអាចចាញ់ការប្រណាំងនោះទេ — ហើយកំណត់ចំណាំមិនអាច*ផ្លាស់ទី*ចេញក្រៅឃ្លាំងបានឡើយ ព្រោះតំណភ្ជាប់ទៅវានឹងដាច់ដោយស្ងាត់ៗ; ការសង្កត់ <kbd>Ctrl</kbd> ជំនួសមកវិញនឹងចម្លងវាចេញទៅក្រៅ។

**ហេតុអ្វី។** កំណត់ចំណាំដែលអ្នកត្រូវការច្រើនតែស្ថិតនៅក្នុងឃ្លាំងផ្សេង ក្នុងថតធ្វើសមកាលកម្ម ឬលើ USB ហើយចម្លើយរបស់ Obsidian ផ្ទាល់ — ប្តូរឃ្លាំង — បិទអ្វីៗទាំងអស់ដែលអ្នកបានបើកទុក។ វិធីនេះឱ្យអ្នកទៅមើលដោយមិនចាំបាច់ចាកចេញ ហើយកែកំហុសអក្ខរាវិរុទ្ធតែម្តងពេលអ្នកនៅទីនោះ។

**ដែនកំណត់។** កម្មវិធីកែសម្រួលរបស់ Obsidian ចងភ្ជាប់នឹងឯកសារនៅក្នុងឃ្លាំង ដូច្នេះឯកសារខាងក្រៅ**មិនអាច**បើកជាកំណត់ចំណាំពិតប្រាកដ ដែលមានតំណភ្ជាប់ តំណត្រឡប់ និងអ្វីៗផ្សេងទៀតបានទេ; គ្មានកម្មវិធីជំនួយណាធ្វើបានទេ។ Lure បង្ហាញវានៅក្នុងកម្មវិធីមើលផ្ទាល់ខ្លួនជំនួសវិញ (Markdown, រូបភាព, សំឡេង, វីដេអូ, PDF) ហើយសម្រាប់អ្វីៗផ្សេងទៀតទាំងអស់មាន *បើកខាងក្រៅ*។ របារផ្លូវនៅតែមានស៊ុមពណ៌កំហុសជុំវិញរាល់ពេលដែលវាចង្អុលទៅក្រៅឃ្លាំង ហើយដានចាប់ផ្តើមពីកន្លែងដែលអ្នកបានជ្រើសរើស — ឈ្មោះឃ្លាំង ថតផ្ទះរបស់អ្នក ដ្រាយណាមួយ — មិនមែនពីរចនាសម្ព័ន្ធថតរបស់ម៉ាស៊ីនទេ។

## ភាពត្រូវគ្នា

មិនត្រូវការកម្មវិធីជំនួយណាទេ។ **ឯកសារ** ជាកម្មវិធីជំនួយស្នូល បើបានបើក គឺជាអ្វីដែលបង្ហាញថតនៅរបារចំហៀង; បើគ្មានវា ការចុចទាំងនោះនឹងមិនធ្វើអ្វីទាំងអស់។

បានសាកល្បងជាមួយកម្មវិធីជំនួយសហគមន៍ដែលចែករំលែករបារចំណងជើងរបស់កំណត់ចំណាំ ឬឆ្លើយតបនឹងការចុចលើថត — ទាំងពីរលំដាប់នៃការផ្ទុក ហើយនីមួយៗទាំងបើកទាំងបិទ៖

- [Folder notes](obsidian://show-plugin?id=folder-notes) — សញ្ញាបំបែកបើកកំណត់ចំណាំរបស់ថតជំនួសឱ្យការបង្ហាញថត ដែលធ្វើឱ្យផ្នែកនីមួយៗនៃផ្លូវក្លាយជាកន្លែងអាចទៅដល់។ វាជាកម្មវិធីជំនួយកំណត់ចំណាំថតតែមួយគត់ដែលកាន់កាប់ផ្លូវនៅលើរបារចំណងជើង; [Folder Note](obsidian://show-plugin?id=folder-note-plugin) និង [create folder notes with dropdown](obsidian://show-plugin?id=create-folder-notes-with-dropdown) មិនស្តាប់នៅទីនោះទេ ដូច្នេះសញ្ញាបំបែកបង្ហាញថតដូចធម្មតា។
- [Quick Explorer](obsidian://show-plugin?id=quick-explorer) និង [Front Matter Title](obsidian://show-plugin?id=obsidian-front-matter-title-plugin) — ទាំងពីរគូរចូលទៅក្នុងធាតុរបារចំណងជើងតែមួយ; Lure រក្សាជួររបស់ខ្លួនទុកទោះជាមួយណាផ្ទុកមុនក៏ដោយ ហើយការបិទមួយណាក៏ដោយទុកមួយទៀតឱ្យនៅដដែល។
- [Nav Link Header](obsidian://show-plugin?id=nav-link-header), [Running Head](obsidian://show-plugin?id=running-head), [Crumbs](obsidian://show-plugin?id=crumbs-obsidian), [Breadcrumbs](obsidian://show-plugin?id=breadcrumbs) — មានរបារផ្ទាល់ខ្លួន ហើយរស់នៅជាមួយគ្នាដោយគ្មានបញ្ហា។

សម្រាប់កុំព្យូទ័រតុប៉ុណ្ណោះ — គំរូអន្តរកម្មនេះត្រូវការការដាក់កណ្តុរពីលើ ការចុចត្រឹមត្រូវ និងក្តារចុច។ លទ្ធផលពេញលេញ អ្វីដែលនៅសល់ត្រូវផ្ទៀងផ្ទាត់ និងការប្រៀបធៀបជាមួយ Quick Explorer និង Breadcrumbs មាននៅក្នុង [ភាពត្រូវគ្នា](../compatibility.md)។
