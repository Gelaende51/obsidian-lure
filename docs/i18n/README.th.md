# Lure

ปลั๊กอินของ [Obsidian](https://obsidian.md) ที่เปลี่ยนชื่อไฟล์บนแถบหัวเรื่องของโน้ตให้กลายเป็นเส้นทางเต็มทั่วทั้งห้องนิรภัย ซึ่งคลิกได้และแก้ไขได้ — เหมือนแถบที่อยู่ในโปรแกรมจัดการไฟล์ [Dolphin](https://apps.kde.org/dolphin/)

![คลิกที่ตัวคั่นถัดจากโฟลเดอร์: ตัวชี้วางอยู่บนนั้น และ File explorer ได้แสดงและกางโฟลเดอร์นั้นออกแล้ว](../images/breadcrumb.png)

Obsidian 1.8.7+ · เดสก์ท็อปเท่านั้น · AGPL-3.0

## การเปิดเผยเรื่อง AI

- **เอเจนต์** — **Claude Opus 5** และ **Claude Sonnet 5** (Anthropic ผ่าน Claude Code): เขียนโค้ด TypeScript, CSS, ชุดคำแปลทั้ง 45 ภาษา และเอกสารทั้งหมด คำแปลสร้างด้วยเครื่องและยังไม่ผ่านการตรวจโดยเจ้าของภาษา
- **ผู้เขียน** — Vault51: กำหนดทุกความสามารถ ทดลองทุกรุ่นในห้องนิรภัยจริง กำกับการแก้ไข และตรวจผลลัพธ์ทั้งหมด
- **ปริมาณการใช้** — 3–13 สิงหาคม 2026 เก้าวาระ ราว 4,928 คำตอบ: สร้างโทเคนราว 7.2 ล้าน ส่งราว 23.7 ล้าน อ่านซ้ำจากแคชราว 1169.6 ล้าน (รวมราว 1200.5 ล้าน)

## ความสามารถ

- **คลิกที่โฟลเดอร์** เพื่อดูรายการสิ่งที่อยู่ในโฟลเดอร์*แม่*ของมัน — สลับโฟลเดอร์หนึ่งเป็นโฟลเดอร์ข้างเคียงโดยไม่แตะส่วนที่เหลือของเส้นทาง ชื่อโน้ตก็ทำงานแบบเดียวกัน รวมถึงนามสกุลด้วย
- **คลิกที่ตัวคั่น**ถัดจากโฟลเดอร์เพื่อแสดงและกางโฟลเดอร์นั้นใน File explorer การตั้งค่าเดียวสลับบทบาททั้งสองนี้ได้
- **คลิกขวาหรือลากรายการใดก็ได้** — เมนูคลิกขวาและพฤติกรรมการลากของ File explorer เอง
- **คลิกที่ชื่อไฟล์หรือที่ว่าง** เพื่อพิมพ์เส้นทาง พร้อมการเติมคำอัตโนมัติ `/` ลงไปข้างใน <kbd>Backspace</kbd> ถอยขึ้นหนึ่งชั้น <kbd>Enter</kbd> ยืนยัน
- **ปุ่มดินสอบนโฟลเดอร์** เปลี่ยนการโต้ตอบชุดเดียวกันไปเป็นโหมดย้าย/เปลี่ยนชื่อ โดยตรวจสอบแบบเดียวกับที่ Obsidian ตรวจ
- **กด <kbd>Ctrl</kbd> ค้างไว้** เพื่อเปิดในแท็บใหม่ — หรือในโหมดย้าย/เปลี่ยนชื่อ เพื่อคัดลอกโน้ตไปที่นั่นแทนการย้าย
- **<kbd>F2</kbd>** สลับไปมาระหว่างหัวเรื่องในตัวโน้ตกับแถบเส้นทาง
- **คลิกที่ชื่อห้องนิรภัย** เพื่อเลื่อนดูห้องนิรภัยอื่นของคุณ โฟลเดอร์บ้าน รากของระบบไฟล์ และไดรฟ์ที่เมานต์ไว้ โดยไม่ต้องสลับห้องนิรภัย อ่านได้อย่างเดียวจนกว่าคุณจะเปิดกุญแจ และมีกรอบสีแจ้งข้อผิดพลาดตลอดเวลา ปิดไว้ตั้งแต่ต้น — ดู [นอกห้องนิรภัย](#นอกห้องนิรภัย)
- **คำเตือนสองระดับ** — แดงเมื่ออยู่นอกห้องนิรภัย ส้มสำหรับไฟล์ข้อความที่ Obsidian ไม่มีตัวแก้ไขให้ ดู [สองสีของคำเตือน](usage.th.md#สองสีของคำเตือน)
- **ไอคอนที่เปลี่ยนตามธีม** สลับได้จากสไนปเพต CSS — และ **45 ภาษา** ครบทุกภาษาที่ Obsidian มีมาให้
- **การตั้งค่า:** การจัดวาง ตัวคั่นสำเร็จรูป คลิกไหนเป็นตัวเปิดรายการ ชื่อห้องนิรภัย ไฟล์ซ่อน

![รายการเดียวกันในโหมดย้าย/เปลี่ยนชื่อ: ชื่อไฟล์ปัจจุบันปักไว้บนสุด โฟลเดอร์ข้างเคียงอยู่ถัดลงมา และโน้ตที่มีอยู่แล้วถูกทำให้จาง](../images/dropdown.png)

*ในโหมดย้าย/เปลี่ยนชื่อ รายการเดียวกันนี้เสนอสิ่งอื่น: ชื่อปัจจุบันของโน้ตปักไว้บนสุดเพื่อย้ายโดยไม่เปลี่ยนชื่อ ถัดลงมาเป็นโฟลเดอร์ที่จะย้ายเข้าไป และชื่อที่มีคนใช้แล้วถูกทำให้จางเพื่อไม่ให้อะไรถูกเขียนทับโดยไม่ตั้งใจ*

→ [คู่มือการใช้งานฉบับเต็ม](usage.th.md)

## นอกห้องนิรภัย

นโยบายสำหรับนักพัฒนาของ Obsidian กำหนดให้ปลั๊กอินอธิบายการเข้าถึงไฟล์นอกห้องนิรภัยทุกกรณี ดังนั้นขอพูดตรง ๆ:

**มันทำสิ่งเหล่านี้หรือเปล่า** เฉพาะเมื่อคุณเปิด **การเข้าถึงไฟล์ภายนอก** ซึ่ง**ปิดไว้ตั้งแต่ต้น** เมื่อปิดอยู่ ไม่มีทางใดจากปลั๊กอินไปถึงเส้นทางภายนอกได้ และโค้ดที่อธิบายไว้ข้างล่างไม่มีบรรทัดไหนได้ทำงานเลย

**มันอ่านอะไร** เฉพาะตอนที่คุณสั่งเท่านั้น การคลิกที่ชื่อห้องนิรภัยจะแสดงรายการห้องนิรภัยอื่นของคุณ — อ่านจาก `obsidian.json` ของ Obsidian เอง — พร้อมโฟลเดอร์บ้าน รากของระบบไฟล์ และไดรฟ์ที่เมานต์ไว้ (`/proc/mounts` บน Linux, `/Volumes` บน macOS, อักษรไดรฟ์บน Windows) การเลื่อนดูต่อจากตรงนั้นจะแสดงเนื้อในของไดเรกทอรี และการเปิดไฟล์จะอ่านเฉพาะไฟล์นั้นไฟล์เดียว

**มันเขียนอะไร** ไม่เขียนอะไรเลย จนกว่าคุณจะกดปุ่มที่บอกไว้ชัด ๆ ปุ่มแบบนั้นมีสองปุ่ม และแต่ละปุ่มครอบคลุมเฉพาะขอบเขตของตัวเอง:

- ปุ่ม **แก้ไขแบบข้อความ** ในตัวแสดงผลจะปลดล็อกไฟล์ที่อยู่ตรงหน้าคุณ เฉพาะไฟล์นั้นในแท็บนั้นเท่านั้น จากนั้นการแก้ไขของคุณจะถูกบันทึกลงไปขณะที่คุณพิมพ์
- **กุญแจ** บนแถบหัวเรื่อง ซึ่งปรากฏเฉพาะขณะที่แถบเส้นทางชี้ออกไปนอกห้องนิรภัย จะปลดล็อกการสร้าง เปลี่ยนชื่อ และย้ายบนเส้นทางภายนอก มันจะล็อกกลับทันทีที่คุณกลับเข้ามาข้างใน สิทธิ์จึงไม่เคยอยู่นานกว่าโฟลเดอร์ที่คุณให้สิทธิ์ไว้

การปลดล็อกทั้งสองแบบไม่ถูกเก็บลงพื้นที่ทำงานหรือการตั้งค่า การเขียนจึงไม่เคยตั้งท่ารออยู่บนไฟล์ที่คุณจำไม่ได้ว่าเคยเปิด ในทั้งสองสถานะไม่มีอะไรถูกเขียนทับ — ปลายทางที่มีอยู่แล้วจะถูกปฏิเสธ โดยใช้การสร้างแบบผูกขาดของระบบไฟล์เอง ไม่ใช่การตรวจสอบที่อาจแพ้การชิงจังหวะ — และโน้ตไม่มีทาง*ถูกย้าย*ออกไปนอกห้องนิรภัยได้ เพราะลิงก์ที่ชี้มาหามันจะขาดอย่างเงียบ ๆ การกด <kbd>Ctrl</kbd> ค้างไว้จะคัดลอกมันออกไปแทน

**ทำไม** โน้ตที่คุณต้องการมักอยู่ในห้องนิรภัยอื่น ในโฟลเดอร์ซิงก์ หรือในแฟลชไดรฟ์ ส่วนคำตอบของ Obsidian เอง — สลับห้องนิรภัย — จะปิดทุกอย่างที่คุณเปิดค้างไว้ วิธีนี้ให้คุณไปดูได้โดยไม่ต้องจากไป และแก้คำผิดเสียเลยตอนที่อยู่ตรงนั้น

**ข้อจำกัด** ตัวแก้ไขของ Obsidian ผูกอยู่กับไฟล์ในห้องนิรภัย ไฟล์ภายนอกจึง**เปิดเป็นโน้ตจริงไม่ได้** ไม่มีลิงก์ ลิงก์ย้อนกลับ และอย่างอื่นทั้งหมด ไม่มีปลั๊กอินตัวไหนทำได้ Lure จึงแสดงมันในตัวแสดงผลของตัวเองแทน (Markdown, รูปภาพ, เสียง, วิดีโอ, PDF) ส่วนอย่างอื่นทั้งหมดมี *เปิดภายนอก* ให้ แถบเส้นทางจะคงกรอบสีแจ้งข้อผิดพลาดไว้ทุกครั้งที่ชี้ออกไปนอกห้องนิรภัย และร่องรอยจะเริ่มจากที่ที่คุณเลือก — ชื่อห้องนิรภัย โฟลเดอร์บ้านของคุณ หรือไดรฟ์ — ไม่ใช่จากผังไดเรกทอรีของเครื่อง

## การติดตั้ง

มีอยู่ที่ [community.obsidian.md/plugins/lure](https://community.obsidian.md/plugins/lure) แต่ยังไม่ได้รับอนุมัติสำหรับตัวเรียกดูในแอป — จึงติดตั้งด้วยวิธีใดวิธีหนึ่งต่อไปนี้:

**ด้วยตนเอง:** ดาวน์โหลด `main.js`, `manifest.json` และ `styles.css` จาก [รุ่นล่าสุด](https://github.com/Gelaende51/obsidian-lure/releases) ไปไว้ที่ `<vault>/.obsidian/plugins/lure/` แล้วเปิดใช้งานที่ **การตั้งค่า → ปลั๊กอินโดยชุมชน**

**BRAT:** เพิ่ม `Gelaende51/obsidian-lure` เป็นปลั๊กอินรุ่นเบตา

**จากซอร์ส:** `npm install && npm run build` — ดู [การพัฒนา](../development.md)

## ความเข้ากันได้

ไม่ต้องใช้ปลั๊กอินใดเลย **File explorer** ที่เป็นปลั๊กอินแกนหลัก ถ้าเปิดอยู่ ก็คือตัวที่แสดงโฟลเดอร์ในแถบข้าง ถ้าไม่มีมัน การคลิกเหล่านั้นจะไม่ทำอะไรเลย

ทดสอบกับปลั๊กอินของชุมชนที่ใช้แถบหัวเรื่องโน้ตร่วมกันหรือตอบสนองต่อการคลิกโฟลเดอร์ — ทั้งสองลำดับการโหลด และแต่ละตัวทั้งเปิดและปิด:

- [Folder notes](obsidian://show-plugin?id=folder-notes) — ตัวคั่นจะเปิดโน้ตของโฟลเดอร์แทนการแสดงโฟลเดอร์ ทำให้ทุกท่อนของเส้นทางกลายเป็นที่ที่ไปได้ เป็นปลั๊กอินโน้ตโฟลเดอร์ตัวเดียวที่ยึดเส้นทางบนแถบหัวเรื่อง ส่วน [Folder Note](obsidian://show-plugin?id=folder-note-plugin) และ [create folder notes with dropdown](obsidian://show-plugin?id=create-folder-notes-with-dropdown) ไม่ได้ดักฟังตรงนั้น ตัวคั่นจึงแสดงโฟลเดอร์ตามปกติ
- [Quick Explorer](obsidian://show-plugin?id=quick-explorer) และ [Front Matter Title](obsidian://show-plugin?id=obsidian-front-matter-title-plugin) — ทั้งคู่วาดลงในอิลิเมนต์เดียวกันของแถบหัวเรื่อง Lure รักษาแถวของตัวเองไว้ได้ไม่ว่าตัวไหนจะโหลดก่อน และการปิดตัวใดตัวหนึ่งก็ไม่กระทบอีกตัว
- [Nav Link Header](obsidian://show-plugin?id=nav-link-header), [Running Head](obsidian://show-plugin?id=running-head), [Crumbs](obsidian://show-plugin?id=crumbs-obsidian), [Breadcrumbs](obsidian://show-plugin?id=breadcrumbs) — มีแถบของตัวเอง และอยู่ร่วมกันได้โดยไม่มีปัญหา

เดสก์ท็อปเท่านั้น — รูปแบบการโต้ตอบนี้ต้องอาศัยการเลื่อนเมาส์ทับ การคลิกที่แม่นยำ และแป้นพิมพ์ ผลทดสอบทั้งหมด สิ่งที่ยังต้องพิสูจน์ และการเปรียบเทียบกับ Quick Explorer และ Breadcrumbs อยู่ใน [ความเข้ากันได้](../compatibility.md)

## เครดิต

- **Vault51** — ผู้เขียน: การออกแบบ ข้อกำหนด และการทดสอบด้วยมือตลอดทั้งงาน
- **Claude Opus 5** และ **Claude Sonnet 5** (Anthropic ผ่าน Claude Code) — การพัฒนา คำแปล และเอกสาร ภายใต้การกำกับของผู้เขียน ดู [การเปิดเผยเรื่อง AI](#การเปิดเผยเรื่อง-ai)
- **[Obsidian](https://obsidian.md)** — แอปพลิเคชันที่สิ่งนี้ต่อยอด และเป็นที่มาของทุกชิ้นส่วนที่ปลั๊กอินใช้: API สำหรับปลั๊กอิน ชุดไอคอน Lucide ที่อยู่เบื้องหลัง `setIcon` อินสแตนซ์ i18next ที่มากับแอปซึ่งใช้อ่านป้ายกำกับของเมนูคลิกขวา รวมถึงคลาสและตัวแปร CSS ของแอปเอง ไม่มีอะไรจากบุคคลที่สามถูกรวมมาด้วย ปลั๊กอินนี้**ไม่มีการพึ่งพาขณะทำงาน**

> **ทีม Obsidian ไม่ได้มีส่วนร่วมในโครงการนี้แต่อย่างใด** — ไม่ได้เขียน ไม่ได้ตรวจ ไม่ได้รับรอง และไม่ได้สนับสนุน Obsidian เป็นเครื่องหมายการค้าของ Dynalist Inc. ส่วนนี่เป็นปลั๊กอินอิสระที่ไม่มีความเกี่ยวข้องกัน
