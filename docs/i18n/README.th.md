# Lure

ปลั๊กอิน [Obsidian](https://obsidian.md) ที่เปลี่ยนชื่อไฟล์ในแถบหัวเรื่องของโน้ตให้เป็นเส้นทางแบบ breadcrumb ของพาธเต็มในห้องนิรภัย ซึ่งคลิกได้และแก้ไขได้ — เหมือนแถบที่อยู่ในโปรแกรมจัดการไฟล์ [Dolphin](https://apps.kde.org/dolphin/)

![การคลิกตัวคั่นที่อยู่หลังโฟลเดอร์: ตัวชี้เมาส์วางอยู่บนมัน และ File explorer ได้เผยและกางโฟลเดอร์นั้นออกแล้ว](../images/breadcrumb.png)

Obsidian 1.8.7+ · เดสก์ท็อปเท่านั้น · AGPL-3.0

## การเปิดเผยเรื่อง AI

- **เอเจนต์** — **Claude Opus 5** และ **Claude Sonnet 5** (Anthropic ผ่าน Claude Code): เขียนโค้ด TypeScript, CSS, ชุดคำแปลทั้ง 45 ชุด และเอกสารทั้งหมด คำแปลสร้างด้วยเครื่องและยังไม่ผ่านการตรวจโดยเจ้าของภาษา
- **ปริมาณการใช้** — 3 ส.ค. – 6 ก.ย. 2026, 22 เซสชัน, คำตอบราว 13,378 ครั้ง: สร้างโทเคนราว 16.3 ล้าน, ส่งราว 62.3 ล้าน, อ่านซ้ำจากแคชราว 4,245.1 ล้าน (รวมราว 4,323.6 ล้าน)
- **ต้นทาง** — โมเดลเรียนรู้จากโค้ดโอเพนซอร์ส เอกสาร และงานเขียนของชุมชนที่ผู้อื่นเผยแพร่ไว้ เครดิตส่วนใหญ่เป็นของพวกเขา
- **ผู้เขียน** — Vault51: กำหนดทุกความสามารถ ทดสอบทุกรอบการพัฒนาในห้องนิรภัยจริง กำกับการแก้ไข และตรวจผลลัพธ์ทั้งหมด

## ความสามารถ

- **คลิกที่โฟลเดอร์** เพื่อเปิดลิสต์ของสิ่งที่อยู่ใน*โฟลเดอร์แม่*ของมัน — สลับโฟลเดอร์หนึ่งเป็นโฟลเดอร์พี่น้อง โดยไม่แตะส่วนที่เหลือของเส้นทาง ชื่อของโน้ตก็ทำงานแบบเดียวกัน โดยเลือกชื่อไว้ให้โดยไม่รวมนามสกุล
- **คลิกที่ตัวคั่น** ที่อยู่หลังโฟลเดอร์ เพื่อเผยและกางโฟลเดอร์นั้นใน File explorer มีการตั้งค่าหนึ่งรายการที่สลับบทบาททั้งสองนี้ได้
- **คลิกขวาหรือลากรายการใดก็ได้** — ได้เมนูคลิกขวาของ File explorer เองแบบรายการต่อรายการ พร้อมพฤติกรรมการลากของมัน ส่วนเส้นทางนอกห้องนิรภัยจะได้เมนูเทียบเท่าที่สร้างขึ้นมาให้โดยเฉพาะ ลงไปถึง *ลบ* ผ่านถังขยะของระบบ
- **คลิกที่ชื่อไฟล์หรือที่ว่าง** เพื่อพิมพ์เส้นทาง พร้อมการเติมข้อความอัตโนมัติ `/` ลงลึกเข้าไป <kbd>Backspace</kbd> ถอยออกมา <kbd>Enter</kbd> ยืนยัน — และเส้นทางที่ยังไม่มีอยู่ก็จะถูกสร้างขึ้นเสียเลย พร้อมการแจ้งเตือนที่บอกว่ามันไปอยู่ที่ใด
- **ลิสต์เปิดที่รายการที่คุณยืนอยู่** และการกดลูกศรหรือชี้เมาส์ไล่ไปในลิสต์จะเติมช่องด้วยสิ่งที่คุณกำลังชี้อยู่ การเลื่อนพ้นปลายลิสต์ทั้งสองด้านจะคืนข้อความที่คุณพิมพ์ไว้กลับมา และการเอาตัวชี้เมาส์ออกจากลิสต์จะคืนไฮไลต์กลับไปยังที่ที่คุณอยู่
- **ปุ่มดินสอบนโฟลเดอร์** เปลี่ยนการโต้ตอบชุดเดียวกันให้เป็นการย้าย/เปลี่ยนชื่อ โดยตรวจสอบความถูกต้องแบบเดียวกับที่ Obsidian ตรวจ
- **กด <kbd>Ctrl</kbd> ค้างไว้** เพื่อเปิดในแท็บใหม่ — หรือในโหมดย้าย/เปลี่ยนชื่อ จะคัดลอกโน้ตไปที่นั่นแทน ชื่อของโน้ตและส่วนที่เป็นโฟลเดอร์รับปุ่มร่วมชุดเดียวกัน และลากได้เหมือนแถวของมันใน File explorer
- **ชื่อเติมเต็มตัวเองขณะพิมพ์** — ตรงที่ชื่อต่าง ๆ ในโฟลเดอร์นั้นตรงกัน ส่วนที่ตรงกันจะปรากฏหลังเคอร์เซอร์ในสภาพถูกเลือกไว้ การพิมพ์จะกลืนมันไปทีละตัวอักษร <kbd>Tab</kbd> หรือ <kbd>→</kbd> รับมันมาทั้งก้อน <kbd>Backspace</kbd> คืนมันกลับไป ลิสต์ยังคงกรองตามสิ่งที่คุณพิมพ์ ไม่ใช่ตามสิ่งที่มันเสนอให้
- **<kbd>Tab</kbd> เติมเต็มอย่างเชลล์**: มันต่อสิ่งที่คุณพิมพ์ไปไกลเท่าที่ชื่อในโฟลเดอร์นั้นยังตรงกัน เดินเข้าหาชื่อใดชื่อหนึ่งทีละก้าวเมื่อชื่อเหล่านั้นไม่ตรงกัน และลงไปในโฟลเดอร์ก็ต่อเมื่อเหลือชื่อเดียวเท่านั้น เมื่อเลยปลายเส้นทางไปแล้ว มันจะขยายส่วนที่เลือกแทน: ชื่อ, ชื่อพร้อมนามสกุล, เส้นทางนับจากห้องนิรภัย, เส้นทางนับจากรากของระบบ <kbd>Shift</kbd>+<kbd>Tab</kbd> เดินเส้นทางเดียวกันย้อนกลับ — โดยทำเครื่องหมายสิ่งที่มันคืนให้แทนที่จะลบทิ้ง — และเมื่อเลยจุดเริ่มต้นไปก็ยังไต่ขึ้นไปตามเส้นทางต่อ แล้ววนกลับมาที่เส้นทางของระบบ ไม่ว่าจะไปทางไหน ครบรอบหนึ่งก็จะกลับมาที่เส้นทางที่คุณสร้างไว้
- **คลิกขวาเพื่อคัดลอก** — สองครั้งได้ชื่อ สามครั้งได้ทุกอย่างที่อยู่ทางขวาของมัน และคลิกขวาบนที่ว่างได้เส้นทางทั้งเส้นหรือเส้นทางของระบบ
- **ลากโน้ตไปวางบนโฟลเดอร์ในแถบ** เพื่อย้ายมันไปที่นั่น พร้อมลิงก์ทั้งหมด — ปลายทางอยู่บนหน้าจออยู่แล้ว จึงเป็นการลากครั้งเดียว แทนที่จะต้องเดินทางผ่านต้นไม้ไฟล์ ชื่อของห้องนิรภัยก็ใช้ได้เช่นกัน สำหรับรากของมัน สิ่งที่เลือกไว้ทั้งชุดย้ายไปพร้อมกัน และโฟลเดอร์ที่รับสิ่งที่ยื่นให้ไม่ได้จะไม่แสดงอะไรเลย แทนที่จะล้มเหลวเอาทีหลัง
- **วางข้อความลงบนแถบเพื่อจดมันไว้** — วางบนโฟลเดอร์หรือบนชื่อห้องนิรภัยเพื่อตั้งชื่อโน้ตใหม่ให้มัน วางบนชื่อของโน้ตเองเพื่อต่อท้ายสิ่งที่คุณกำลังอ่านอยู่ ไฟล์จากเดสก์ท็อปของคุณก็ทำงานแบบเดียวกัน และแถบจะเรืองขอบสีน้ำเงินตรงจุดที่มันจะลง
- **ช่องสวมสีของสิ่งที่มันเอ่ยถึง** — สีเดียวกับที่แถวของมันมีในลิสต์ สีเทาสำหรับโน้ตของโฟลเดอร์ — และ**เปลี่ยนเป็นสีแดง**เมื่อไม่มีอะไรตอบรับชื่อนั้น คุณจึงเห็นได้ก่อนกด <kbd>Enter</kbd> ว่ามันจะเปิดโน้ตหรือจะสร้างโน้ตขึ้นใหม่
- **ไฟล์ HTML แสดงเป็นหน้าเว็บ** ในเฟรมที่ถูกริบสิทธิ์ทุกอย่าง — ไม่มีสคริปต์ ไม่มีเครือข่าย ไม่มีต้นทางของตัวเอง — โดยดึงสไตล์ชีตและรูปภาพที่อยู่ข้าง ๆ ไฟล์เข้ามาด้วย หน้าที่บันทึกไว้จึงยังดูเหมือนตัวมันเอง ส่วนซอร์สอยู่ห่างไปเพียงหนึ่งกด
- **พิมพ์ URL** — `https://`, `obsidian://` หรือเส้นทางแบบ `file://` หรือที่เข้ารหัสเปอร์เซ็นต์ — แล้วมันจะถูกเปิด แทนที่จะถูกมองว่าเป็นชื่อโน้ต ที่อยู่เว็บจะไปเปิดในแท็บของ Web viewer ของ Obsidian เอง หากคุณเปิดใช้มันไว้
- **เส้นทางยาวจะสั้นลงตรงที่ตัวอักษรเกินจำเป็น** — ไม่เคยสั้นเกินจุดที่ยังแยกโฟลเดอร์หนึ่งออกจากโฟลเดอร์ข้าง ๆ ได้ และย่ออย่างลื่นไหลแทนที่จะทีละตัวอักษร — และจะเลื่อนก็ต่อเมื่อไม่เหลืออะไรให้บีบอีกแล้ว ชี้เมาส์ที่ชื่อที่ถูกย่อเพื่อดูมันเต็ม ๆ อีกครั้ง
- **<kbd>F2</kbd>** สลับไปมาระหว่างชื่อเรื่องในบรรทัดกับแถบพาธ โดยเปิดที่ชื่อโดยไม่รวมนามสกุล แล้วขยายออกไปจนถึงเส้นทางเต็มเมื่อกดต่อ มันผ่านกล่องเปลี่ยนชื่อของ Obsidian ไปได้อย่างราบรื่นเมื่อชื่อเรื่องถูกเลื่อนพ้นสายตา และมีคำสั่ง *โฟกัสแถบพาธ* ให้ผูกปุ่มลัดได้ หากคุณต้องการท่าทางแบบแถบที่อยู่
- **คลิกที่ชื่อห้องนิรภัย** เพื่อเรียกดูห้องนิรภัยอื่น ๆ ของคุณ โฟลเดอร์บ้าน รากของระบบไฟล์ และไดรฟ์ที่เมานต์ไว้ โดยไม่ต้องสลับห้องนิรภัย อ่านได้อย่างเดียวจนกว่าคุณจะเปิดกุญแจสีแดงที่เข้ามาแทนที่ปุ่มสลับโหมดเปลี่ยนชื่อเมื่ออยู่ข้างนอก และมีกรอบสีของข้อผิดพลาดล้อมอยู่ตลอดเวลา ปิดไว้ตั้งแต่ต้น — ดู [นอกห้องนิรภัย](#นอกห้องนิรภัย)
- **คำเตือนสองระดับ** — สีแดงเมื่ออยู่นอกห้องนิรภัย สีส้มสำหรับไฟล์ข้อความที่ Obsidian ไม่มีตัวแก้ไขให้ ดู [สองสีของคำเตือน](usage.th.md#สองสีของคำเตือน)
- **ไอคอนที่เปลี่ยนตามธีม** สลับได้จาก CSS snippet — และ **46 ภาษา**: ทุกภาษาที่ Obsidian มีให้ บวกกับภาษากรีกและสันสกฤต ซึ่ง Obsidian ไม่มีการตั้งค่าให้ เลือกภาษาเฉพาะของปลั๊กอินนี้ หรือจะตามภาษาของ Obsidian เองก็ได้
- **การตั้งค่า:** ภาษา, การจัดวาง, ชุดตัวคั่นสำเร็จรูป, การคลิกแบบใดที่เปิดลิสต์, ชื่อห้องนิรภัย, ไฟล์ที่ขึ้นต้นด้วยจุด, นามสกุลไฟล์

## นอกห้องนิรภัย

นโยบายสำหรับนักพัฒนาของ Obsidian กำหนดให้ปลั๊กอินอธิบายการเข้าถึงไฟล์ใด ๆ ที่อยู่นอกห้องนิรภัย ดังนั้นพูดกันตรง ๆ:

**มันทำสิ่งเหล่านี้หรือเปล่า** ก็ต่อเมื่อคุณเปิด **การเข้าถึงไฟล์ภายนอก** เท่านั้น ซึ่ง**ปิดไว้ตั้งแต่ต้น** เมื่อปิดไว้ ไม่มีทางใดเลยที่จะไปถึงเส้นทางภายนอกจากปลั๊กอินนี้ได้ และโค้ดทั้งหมดที่ว่าด้านล่างนี้ก็ไม่เคยทำงาน

**มันอ่านอะไร** เฉพาะตอนที่คุณสั่งให้อ่านเท่านั้น การคลิกที่ชื่อห้องนิรภัยจะแสดงรายชื่อห้องนิรภัยอื่น ๆ ของคุณ — อ่านจาก `obsidian.json` ของ Obsidian เอง — บวกกับโฟลเดอร์บ้าน รากของระบบไฟล์ และไดรฟ์ที่เมานต์ไว้ (`/proc/mounts` บน Linux, `/Volumes` บน macOS, ตัวอักษรไดรฟ์บน Windows) การเรียกดูต่อจากนั้นจะแสดงสิ่งที่อยู่ในไดเรกทอรี และการเปิดไฟล์ก็อ่านเฉพาะไฟล์นั้นไฟล์เดียว

**มันเขียนอะไร** ไม่เขียนอะไรเลย จนกว่าคุณจะกดปุ่มที่บอกไว้ชัดเจน ปุ่มแบบนั้นมีอยู่สองปุ่ม แต่ละปุ่มครอบคลุมเฉพาะขอบเขตของตัวเอง:

- ปุ่ม **แก้ไขแบบข้อความ** ของตัวแสดงผล ปลดล็อกไฟล์ที่อยู่ตรงหน้าคุณ เฉพาะไฟล์นั้นไฟล์เดียวในแท็บนั้นแท็บเดียว จากนั้นสิ่งที่คุณแก้จะถูกบันทึกกลับลงไปขณะที่คุณพิมพ์
- **กุญแจสีแดง** ในแถบหัวเรื่อง ซึ่งเข้ามาแทนที่ปุ่มสลับโหมดเปลี่ยนชื่อขณะที่แถบพาธชี้ไปนอกห้องนิรภัยของคุณ ปลดล็อกการสร้าง เปลี่ยนชื่อ ย้าย และลบที่เส้นทางภายนอก — แล้วคืนช่องนั้นให้ปุ่มสลับเมื่อเปิดแล้ว มันล็อกกลับเมื่อคุณกลับเข้ามาข้างใน และเมื่อกดออกจากโหมดเปลี่ยนชื่อ สิทธิ์จึงไม่เคยอยู่ยืนยาวกว่าโฟลเดอร์ที่คุณมอบสิทธิ์ให้

การปลดล็อกทั้งสองแบบไม่ถูกเก็บไว้ในเวิร์กสเปซหรือในการตั้งค่า การเขียนจึงไม่เคยถูกง้างค้างไว้บนไฟล์ที่คุณจำไม่ได้ว่าเปิดไว้ ไม่มีอะไรถูกเขียนทับในทั้งสองสถานะ — ปลายทางที่มีอยู่แล้วจะถูกปฏิเสธ โดยใช้กลไกสร้างแบบผูกขาดของระบบไฟล์เอง แทนที่จะเป็นการตรวจสอบซึ่งอาจแพ้การชิงจังหวะ

การย้ายโน้ต*ออก*จากห้องนิรภัยของคุณคือการเขียนอย่างเดียวที่มีราคาซึ่งไม่มีอะไรคืนให้ได้: Obsidian อัปเดตลิงก์เฉพาะภายในห้องนิรภัยเท่านั้น ทุกลิงก์ที่ชี้มายังโน้ตนั้นจึงขาด มันถูกเสนอให้อยู่หลังกล่องยืนยันที่บอกเรื่องนี้และนับจำนวนโน้ตที่ได้รับผลกระทบ และมันทำงานแบบคัดลอกแล้วลบผ่านถังขยะของ Obsidian เอง จึงกู้คืนได้เท่า ๆ กับการลบโน้ตหนึ่งใบ การกด <kbd>Ctrl</kbd> ค้างไว้จะคัดลอกมันออกไปแทน

**ทำไม** โน้ตที่คุณต้องการมักอยู่ในห้องนิรภัยอื่น ในโฟลเดอร์ซิงก์ หรือในแฟลชไดรฟ์ และคำตอบของ Obsidian เอง — สลับห้องนิรภัย — ปิดทุกอย่างที่คุณเปิดค้างไว้ สิ่งนี้ให้คุณไปดูได้โดยไม่ต้องจากไป แล้วแก้คำผิดไปด้วยเลยระหว่างที่อยู่ที่นั่น

**ข้อจำกัด** ตัวแก้ไขของ Obsidian ผูกอยู่กับไฟล์ที่อยู่ในห้องนิรภัย ไฟล์ภายนอกจึง**เปิดเป็นโน้ตจริงไม่ได้** ที่มีลิงก์ แบ็กลิงก์ และอื่น ๆ ครบ ไม่มีปลั๊กอินใดทำได้ Lure จึงแสดงมันในตัวแสดงผลของตัวเองแทน (Markdown, รูปภาพ, เสียง, วิดีโอ, PDF) พร้อม *เปิดด้วยโปรแกรมภายนอก* สำหรับทุกอย่างที่เหลือ แถบพาธจะคงกรอบสีของข้อผิดพลาดไว้ทุกครั้งที่มันชี้ไปนอกห้องนิรภัยของคุณ และเส้นทางจะเริ่มต้นที่ตำแหน่งที่คุณเลือก — ชื่อห้องนิรภัย โฟลเดอร์บ้าน หรือไดรฟ์ — แทนที่จะเริ่มที่โครงสร้างไดเรกทอรีของเครื่อง

## การติดตั้ง

มีรายชื่ออยู่ที่ [community.obsidian.md/plugins/lure](https://community.obsidian.md/plugins/lure) แต่ยังไม่ได้รับอนุมัติให้เข้าตัวเรียกดูในแอป จึงต้องติดตั้งด้วยวิธีใดวิธีหนึ่งต่อไปนี้:

**ด้วยตนเอง:** ดาวน์โหลด `main.js`, `manifest.json` และ `styles.css` จาก[รีลีสล่าสุด](https://github.com/Gelaende51/obsidian-lure/releases) ไปไว้ใน `<vault>/.obsidian/plugins/lure/` แล้วเปิดใช้งานที่ **การตั้งค่า → ปลั๊กอินโดยชุมชน**

**BRAT:** เพิ่ม `Gelaende51/obsidian-lure` เป็นปลั๊กอินรุ่นเบตา

**จากซอร์ส:** `npm install && npm run build` — ดู [การพัฒนา](../development.md)

## ความเข้ากันได้

ไม่ต้องใช้ปลั๊กอินใดเลย ปลั๊กอินแกนหลัก **File explorer** หากเปิดใช้งานอยู่ คือสิ่งที่เผยโฟลเดอร์ในแถบข้าง หากไม่มีมัน การคลิกเหล่านั้นจะไม่ทำอะไร

ทดสอบกับปลั๊กอินของชุมชนที่ใช้แถบหัวเรื่องของโน้ตร่วมกัน หรือที่ตอบสนองต่อการคลิกโฟลเดอร์ — ทั้งสองลำดับการโหลด และทั้งเปิดและปิดในแต่ละกรณี:

- [Folder notes](obsidian://show-plugin?id=folder-notes) — ตัวคั่นจะเปิดโน้ตของโฟลเดอร์แทนการเผยโฟลเดอร์ ทำให้ทุกส่วนของเส้นทางเป็นที่ที่คุณไปได้ ไม่ว่าจะลึกแค่ไหน: โน้ตนั้นถูกหาตำแหน่งจากธรรมเนียมของปลั๊กอินนั้นเอง แทนที่จะปล่อยให้มันเป็นคนตอบ และมันยังเป็นตัวเดียวที่ประกาศธรรมเนียมแบบนั้นไว้ ส่วน [Folder Note](obsidian://show-plugin?id=folder-note-plugin) และ [create folder notes with dropdown](obsidian://show-plugin?id=create-folder-notes-with-dropdown) ไม่ประกาศอะไรไว้เลยและไม่เคยอ้างสิทธิ์เส้นทางในแถบหัวเรื่อง เมื่อใช้กับสองตัวนี้ ตัวคั่นจึงเผยโฟลเดอร์ตามปกติ
- [Quick Explorer](obsidian://show-plugin?id=quick-explorer) และ [Front Matter Title](obsidian://show-plugin?id=obsidian-front-matter-title-plugin) — ทั้งคู่วาดลงในเอลิเมนต์แถบหัวเรื่องเดียวกัน Lure รักษาแถบไว้ได้ไม่ว่าตัวไหนจะโหลดก่อน และการปิดตัวใดตัวหนึ่งก็ไม่กระทบอีกตัว
- [Nav Link Header](obsidian://show-plugin?id=nav-link-header), [Running Head](obsidian://show-plugin?id=running-head), [Crumbs](obsidian://show-plugin?id=crumbs-obsidian), [Breadcrumbs](obsidian://show-plugin?id=breadcrumbs) — มีแถบของตัวเอง และอยู่ร่วมกันได้

เดสก์ท็อปเท่านั้น — รูปแบบการโต้ตอบต้องอาศัยการชี้เมาส์ การคลิกที่แม่นยำ และแป้นพิมพ์ ผลการทดสอบฉบับเต็ม สิ่งที่ยังคาดหวังอยู่ และการเปรียบเทียบกับ Quick Explorer และ Breadcrumbs อยู่ใน [ความเข้ากันได้](../compatibility.md)
