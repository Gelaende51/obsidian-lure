# 更新日誌

Lure 的每一個版本，由新到舊排列。上次發布以來已合併的變更列於*尚未發布*之下。版本號不帶 `v` 前綴，與發布標籤一致。

## 尚未發布[^unreleased]

### 新增

- **從外部把檔案帶進儲存庫。** 將磁碟上任何位置的檔案移動或複製到儲存庫內的某個路徑；它會成為真正的筆記，而移動時，只有在複製成功之後才會移除原始檔案。
- **把文字或檔案拖放到路徑列上即可記下來。** 放到資料夾上：在該資料夾中建立一則新筆記，名稱由你輸入。放到筆記名稱上，或放到擁有資料夾筆記的資料夾的分隔符號上：經過確認後，附加到該筆記的末尾。
- **建立資料夾筆記**：在有資料夾筆記外掛運作、而該資料夾還沒有資料夾筆記時，對用來開啟該資料夾的操作再按一次即可。建立的位置依 [Folder notes](https://github.com/LostPaul/obsidian-folder-notes) 本身的設定而定。
- **把資料夾從路徑列拖到分頁列上**即可在那裡開啟：有資料夾筆記就開啟資料夾筆記，否則開啟一個停在該資料夾的分頁。
- **滾輪可以在清單中移動。** 在名稱上方，第一次滾動會開啟該名稱的清單，之後每滾一格，醒目標示就移動一列。正在橫向捲動的列會保留滾輪用於捲動。
- **用方向鍵移出欄位前端**，即可把前一個資料夾帶進來：<kbd>←</kbd> 帶入一個資料夾，<kbd>Shift</kbd>+<kbd>Home</kbd>（或清單關閉時的 <kbd>Home</kbd>）帶入全部。
- **欄位會帶上它所指名稱的顏色**，與清單中該列的顏色相同；一旦沒有任何東西與之對應就會變成紅色——也就是按下 <kbd>Enter</kbd> 會建立新東西、而不是開啟既有東西的那一刻。
- **資料夾筆記在清單中呈灰色**，讓它們看起來屬於所在的資料夾，而不只是又一則筆記。
- **中鍵點擊分隔符號**即可在新分頁中開啟該資料夾：開啟它的資料夾筆記，或一個停在該資料夾的分頁。

### 變更

- **掛鎖與重新命名切換鈕合為同一個控制項。** 在儲存庫之外，一個紅色、鎖上的掛鎖會佔據切換鈕的位置；打開它便把位置交給切換鈕，離開重新命名模式時它會再次鎖上。
- **重新命名鍵也會詢問掛鎖。** 在儲存庫之外，按一下會讓掛鎖閃爍；在半秒內再按一次，就會授予掛鎖所授予的權限，並開啟重新命名模式。
- **重新命名鍵會走完整一輪**——行內標題、名稱、含副檔名的名稱、從儲存庫起算的路徑、從系統根目錄起算的路徑——再按一次又回到行內標題。
- **<kbd>Ctrl</kbd>-點擊與中鍵點擊不再是同義詞。** 一個會開啟分頁並切換過去，另一個則在背景開啟。
- **對筆記名稱按右鍵會開啟該檔案本身的選單。**
- **清單的高度會盡量達到視窗允許的高度**，而不是 Obsidian 固定的 300 像素。
- **欄位開啟時點擊資料夾，會保留其後的完整路徑**；在欄位中點進某個資料夾，則會完整列出該資料夾的內容。
- **在執行 Folder notes 時，分隔符號可以開啟任何深度的資料夾筆記**，而且凡是有資料夾筆記之處都會加上底線。以前只有最上層的資料夾有效。搭配其他資料夾筆記外掛時，分隔符號仍會顯示資料夾。

### 修正

- **開啟中的欄位比它的檔案活得更久。** 在路徑列開啟時切換到另一則筆記，該列在整個工作階段剩下的時間裡都仍顯示舊檔案的名稱。
- **在儲存庫之外、掛鎖已打開時，刪除、重新命名與建立副本仍被拒絕**，而且對圖片、PDF 與網頁根本無法使用。
- **清單開啟時 <kbd>Ctrl</kbd>+<kbd>Enter</kbd> 沒有作用**——而每個欄位開啟時，清單都是開著的。
- **清單開啟但沒有醒目標示任何項目時按 <kbd>Enter</kbd>** 沒有作用；現在會確認你輸入的內容。
- **當每個名稱都已縮到最短、該列仍然溢出時無法捲動**，導致路徑末端無法觸及。
- **停用外掛後會留下失效的按鈕**，出現在它修改過的每則筆記的標題列中。

## 1.2.0 — 2026-08-25[^1.2.0]

### 新增

- **語言設定。** Lure 預設跟隨 Obsidian 的語言，也可以設定為它自己支援的任何語言。這也是使用希臘文與梵文翻譯的唯一途徑，因為 Obsidian 本身並未提供這兩種語言。這項設定本身的標籤維持英文，這樣即使切換到你看不懂的語言，也總能再把它找回來。

## 1.1.2 — 2026-08-25[^1.1.2]

### 變更

- **更輕量的樣式表。** 該列不再使用 `:has()` 選擇器，也不再使用大部分的 `!important` 規則。重新調整版面所需的工作更少，外掛審查的警告也從 56 個降到 7 個。

## 1.1.1 — 2026-08-22[^1.1.1]

### 修正

- **較短的資料夾名稱可能會顯示出空隙**——`atlas` 變成 `atl as`——因為為其縮短形式保留的空間比名稱本身還寬。

## 1.1.0 — 2026-08-22[^1.1.0]

### 新增

- **右鍵操作詞彙。** 按一下開啟選單；按兩下、三下則複製越來越多內容——名稱、含副檔名的名稱、路徑。該列的選單現在與檔案瀏覽器的選單項目一一對應。
- **儲存庫之外的選單。** 清單中的列與外部檢視器提供開啟、*複製路徑*與*在系統檔案總管中顯示*；掛鎖打開時，還有*新增筆記*、*新增資料夾*、*建立副本*、*重新命名…*與*刪除*。刪除會移至系統資源回收筒，絕不會永久刪除。
- **在其他位置開啟。** 在筆記名稱或資料夾上使用 <kbd>Ctrl</kbd>、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd> 與中鍵點擊，可在新分頁、分割畫面或新視窗中開啟。兩者都可以拖曳，就像它們在檔案瀏覽器中的列一樣。
- **把筆記拖到該列上即可移動。** 將一則筆記、多則筆記或一個資料夾拖放到資料夾段落或儲存庫名稱上。
- **指令：聚焦路徑列**，並選取整個路徑——沒有預設快速鍵，請自行綁定。
- **在路徑列中輸入網址**：`http(s)://` 與 `obsidian://` 會以連結開啟，`file://` 與百分比編碼的路徑則會開啟該檔案。
- **Tab 補全**，就像 shell 的做法：每按一次就補全到資料夾中各名稱一致之處，並在分歧處停下。<kbd>Shift</kbd>+<kbd>Tab</kbd> 往回走。沒有可補全的內容時，<kbd>Tab</kbd> 改為擴大選取範圍：名稱、含副檔名的名稱、從儲存庫起算的路徑、從系統根目錄起算的路徑。
- **清單會在你所在之處開啟**，並把你指向的項目預覽到欄位中；離開清單會還原你輸入的文字。
- **將筆記移出儲存庫**：先經過一個會計算將失效連結數量的確認對話框。筆記會先被複製出去，再移到垃圾桶，因此可以像任何被刪除的筆記一樣復原。
- **顯示副檔名**設定；另外也能辨識加了引號的路徑（例如 Windows 的*複製為路徑*（Copy as path）所產生的路徑）。
- **設定會出現在 Obsidian 的設定搜尋中**，適用於 Obsidian 1.13 及更新版本。

### 變更

- **長路徑會配合窗格寬度。** 名稱從最不重要的開始縮短——先是儲存庫名稱，然後是副檔名，接著是資料夾，筆記本身的名稱最後——絕不縮到彼此無法區分的程度。將游標停在縮短的名稱上即可閱讀全名。
- **點擊筆記名稱會選取不含副檔名的名稱**，所以重新命名時不再有改變檔案類型的風險。
- **重新命名鍵開啟時會選取不含副檔名的名稱**，再按則擴大選取範圍。
- **點擊資料夾時，路徑的其餘部分保持可見**，在儲存庫之外也是如此。
- **瀏覽回儲存庫內時會以筆記開啟檔案**，具備連結與反向連結，而不是在外部檢視器中開啟。

### 修正

- **選單標籤在每一種語言中都是英文**；現在改用 Obsidian 本身的翻譯。
- **重新命名鍵會卡在 Obsidian 的重新命名對話框**，發生在筆記已捲過其標題時。
- **<kbd>Esc</kbd> 需要按兩次**才能關閉欄位與其清單。
- **<kbd>Ctrl</kbd>+<kbd>Enter</kbd> 會在編輯器中開啟連結**，而不是作用於路徑列。
- **在儲存庫之外重新命名會遺失已輸入的名稱**，發生在按下掛鎖時。
- **Tab 可能原地打轉、毫無進展**，發生在與自身資料夾筆記並列的資料夾上。

## 1.0.4 — 2026-08-13[^1.0.4]

### 新增

- **清單中會以藍色標示你目前所在的筆記**，這樣瀏覽回它的資料夾時，就能看出你是從哪裡出發的。

## 1.0.3 — 2026-08-13[^1.0.3]

### 文件

- README 加上了外掛在社群目錄中頁面的連結，翻譯版的 README 也已更新至最新。

## 1.0.2 — 2026-08-13[^1.0.2]

### 變更

- **需要 Obsidian 1.8.7 或更新版本**（原為 1.4.0）。路徑列所依賴的兩項功能——複製檔案，以及欄位下方的錯誤提示——需要此版本。
- **發布的下載檔附有經簽署的建置來源證明**，你可以用 `gh attestation verify` 確認 `main.js` 是從本程式碼庫建置出來的。

### 修正

- **以預設應用程式開啟不存在的外部檔案時會無聲無息地失敗**；現在會回報錯誤。

## 1.0.1 — 2026-08-13[^1.0.1]

### 修正

- **在重新命名模式下，筆記會與自己衝突**——瀏覽回它自己的資料夾時，它的名稱會從清單中消失，彷彿它擋住了自己的重新命名。
- **啟動 Obsidian 後第一次顯示資料夾時，什麼都沒有展開。**
- **從清單中選擇資料夾可能會結束重新命名模式**，而不是進入該資料夾。
- **外部編輯可能被其他寫入者無聲無息地覆寫**，例如 Sync 或第二個窗格。寫入現在是原子操作。
- **焦點外框的重設會外洩到其他檢視**；現在只套用於 Lure 修改過的標題列。

### 文件

- README 與使用指南已提供外掛支援的全部 44 種語言版本。
- 指南中提到的 Obsidian 設定*偵測所有副檔名*（Detect all file extensions），現在名為*顯示所有檔案類型*（Show all file types）。

## 1.0.0 — 2026-08-10[^1.0.0]

首次發布。將筆記標題列中的檔名替換為可點擊、可編輯的儲存庫路徑麵包屑導覽——一個為筆記打造的網址列，以 Dolphin 的網址列為範本。

### 新增

- **點擊資料夾**會開啟其上層資料夾內容的下拉清單，用來把它換成同層的另一個資料夾，路徑的其餘部分保持不變。
- **點擊資料夾後面的分隔符號**，即可在檔案瀏覽器中顯示並展開該資料夾；若由 Folder notes 處理，則開啟其資料夾筆記。
- **點擊檔名或空白處**即可輸入路徑，並有自動補全：`/` 往下進入，<kbd>Backspace</kbd> 往上退出，<kbd>Enter</kbd> 確認。
- **移動／重新命名模式**會把同樣的互動切換成移動與重新命名，並以與 Obsidian 相同的方式驗證。
- **<kbd>Ctrl</kbd> 會在新分頁中開啟**——在移動／重新命名模式下，則改為把筆記複製過去。
- **<kbd>F2</kbd> 可切換**行內標題與路徑列。
- **儲存庫之外**（預設關閉）：儲存庫名稱會開啟你的其他儲存庫、家目錄、檔案系統根目錄與已掛載的磁碟。在你解鎖之前，外面的任何東西都不會被寫入，而且筆記只能從儲存庫複製出去，永遠無法移出。
- **45 種語言。**
