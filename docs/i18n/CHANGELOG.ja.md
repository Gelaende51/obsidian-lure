# 変更履歴

Lure の全リリースを、新しいものから順に並べています。最後のリリース以降に入ったものは *未リリース* の下にあります。バージョンにはリリースタグと同じく `v` を付けません。

## 未リリース[^unreleased]

### 追加

- **保管庫の外からファイルを取り込む。** ディスク上のどこにあるファイルでも、保管庫の中のパスへ移動またはコピーできます。取り込まれたものは本物のノートとして届き、移動の場合はコピーが成功して初めて元のファイルが削除されます。
- **テキストやファイルを行にドロップして書き留める。** フォルダーにドロップすると、そのフォルダーの中に、入力した名前で新しいノートを作ります。ノートの名前、またはフォルダーノートを持つフォルダーの区切り文字にドロップすると、確認のうえでそのノートの末尾に追加されます。
- フォルダーノート系のプラグインが動いていて、そのフォルダーにまだフォルダーノートがないとき、フォルダーを開く操作をもう一度行うと**フォルダーノートを作成**します。置かれる場所は [Folder notes](https://github.com/LostPaul/obsidian-folder-notes) 自身の設定に従います。
- **パスバーからフォルダーをタブバーへドラッグ**すると、そこに開きます: フォルダーノートがあればそれを、なければそのフォルダーに立つタブを開きます。
- **ホイールで一覧をたどれます。** 名前の上では、最初の一回転でその名前の一覧が開き、以後は一回転ごとにハイライトが一行ずつ動きます。横スクロール中の行では、ホイールはスクロールのために使われます。
- **入力欄の先頭から矢印キーで外に出る**と、その前のフォルダーが入力欄に入ります: <kbd>←</kbd> で一つ、<kbd>Shift</kbd>+<kbd>Home</kbd>（一覧が閉じているときは <kbd>Home</kbd>）ですべて。
- **入力欄は、それが指すものの色をまといます** — 一覧でのその行と同じ色です — そして該当するものがなくなると赤くなります。ちょうど <kbd>Enter</kbd> が、開くのではなく作ることになる瞬間です。
- **一覧の中でフォルダーノートは灰色**になり、ただのノートの一つではなく、そのフォルダーのものとして読み取れます。
- **区切り文字を中クリック**すると、そのフォルダーを新しいタブに開きます: フォルダーノート、またはそこに立つタブです。

### 変更

- **南京錠と名前変更トグルは一つのコントロールになりました。** 保管庫の外では、赤い閉じた南京錠がトグルの場所を占めます。それを開くとその場所がトグルに渡され、名前変更モードを抜けると再び閉じます。
- **名前変更キーは南京錠にも問い合わせます。** 保管庫の外では、一度押すと南京錠が点滅し、半秒以内にもう一度押すと南京錠が与えるものを許可したうえで名前変更モードに入ります。
- **名前変更キーは一巡します** — インラインタイトル、名前、拡張子つきの名前、保管庫からのパス、システムのルートからのパス — そして次に押すとまたインラインタイトルに戻ります。
- **<kbd>Ctrl</kbd> クリックと中クリックはもう同義ではありません。** 一方はタブを開いてそこへ移り、もう一方は背面で開きます。
- **ノートの名前を右クリックすると、そのファイル自身のメニューが開きます。**
- **一覧はウィンドウが許す高さまで広がります**。Obsidian の固定の 300 ピクセルではなくなりました。
- **入力欄が開いている状態でフォルダーをクリックすると、その後ろのパス全体が保たれます**。また、入力欄の中でフォルダーの位置をクリックすると、そのフォルダーの中身が省略なく一覧されます。
- **区切り文字は、どの深さでもフォルダーノートを開きます**（Folder notes が動いている場合）。フォルダーノートがあるところでは下線が付きます。以前は最上位のフォルダーでしか働きませんでした。他のフォルダーノート系プラグインと一緒のときは、区切り文字はこれまでどおりフォルダーを表示します。

### 修正

- **開いている入力欄がファイルより長く残っていました。** パスバーを開いたまま別のノートに切り替えると、その行がセッションの残りのあいだ古いファイルの名前を示し続けていました。
- **保管庫の外では、南京錠を開いていても削除・名前の変更・コピーの作成が拒否され**、画像・PDF・ページではそもそもたどり着けませんでした。
- **一覧が開いているあいだ <kbd>Ctrl</kbd>+<kbd>Enter</kbd> が何もしませんでした** — 入力欄はどれも一覧が開いた状態で始まるにもかかわらず。
- **一覧が開いていて何もハイライトされていないときの <kbd>Enter</kbd>** は何もしませんでしたが、入力した内容を確定するようになりました。
- **どの名前も最短になってなお行があふれる場合にスクロールできず**、パスの末尾に手が届きませんでした。
- **プラグインを無効にしても、書き換えた各ノートのヘッダーに死んだボタンが残っていました。**

## 1.2.0 — 2026-08-25[^1.2.0]

### 追加

- **言語設定。** Lure は既定で Obsidian の言語に従い、自身が備えるどの言語にも設定できます。Obsidian 自身が提供していないギリシャ語とサンスクリット語の翻訳に到達する手段はこれだけです。この設定自身のラベルは英語のままなので、読めない言語からでも必ず見つけ直せます。

## 1.1.2 — 2026-08-25[^1.1.2]

### 変更

- **スタイルシートが軽くなりました。** 行はもう `:has()` セレクターも、`!important` 規則のほとんども使いません。より少ない処理で再配置でき、プラグインレビューの警告は 56 件から 7 件に減りました。

## 1.1.1 — 2026-08-22[^1.1.1]

### 修正

- **短いフォルダー名が途中に隙間を空けて描かれることがありました** — `atlas` が `atl as` のように — 短縮形のために確保した幅が、名前そのものより広かったためです。

## 1.1.0 — 2026-08-22[^1.1.0]

### 追加

- **右クリックの語彙。** 一度押すとメニューが開き、二度・三度と押すごとにコピーされる範囲が広がります — 名前、拡張子つきの名前、パス。行のメニューはファイルエクスプローラーのものと項目単位で一致するようになりました。
- **保管庫の外でのメニュー。** 一覧の行と外部ビューアーからは、開く操作・*パスをコピー*・*システムのエクスプローラーで表示* が使えます。南京錠を開いていれば、*新規ノート*・*新規フォルダー*・*コピーを作成*・*名前を変更…*・*削除* も加わります。削除はシステムのゴミ箱へ移すもので、完全な削除には決してなりません。
- **別の場所に開く。** ノートの名前やフォルダーに対する <kbd>Ctrl</kbd>、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>、中クリックで、新しいタブ・分割・ウィンドウに開きます。どちらもファイルエクスプローラーの行と同じようにドラッグできます。
- **ノートを行にドラッグして移動。** 一つのノート、複数のノート、あるいはフォルダーを、フォルダーの要素や保管庫の名前にドロップできます。
- **コマンド: パスバーにフォーカス**、パス全体が選択された状態で開きます — 既定のホットキーはないので、自分で割り当ててください。
- パスバーに **URL を入力**できます: `http(s)://` と `obsidian://` はリンクとして開き、`file://` やパーセントエンコードされたパスはそのファイルを開きます。
- **Tab 補完**、シェルと同じやり方で: 一度押すごとにフォルダー内の名前が一致する範囲まで補い、食い違うところで止まります。<kbd>Shift</kbd>+<kbd>Tab</kbd> は逆にたどります。補うものがなくなると、<kbd>Tab</kbd> は代わりに選択範囲を広げます: 名前、拡張子つきの名前、保管庫からのパス、システムのルートからのパス。
- **一覧は今いる位置で開き**、指したものを入力欄にプレビューします。一覧から離れると、入力していた文字が戻ります。
- **ノートを保管庫の外へ移動**できます。壊れるリンクの数を数える確認を経てから行われます。外へコピーしたうえでゴミ箱へ送るので、削除した他のノートと同じように復元できます。
- **拡張子を表示**の設定と、（Windows の *パスとしてコピー* が生成するような）引用符付きのパスの解釈に対応しました。
- **Obsidian 1.13 以降では、設定が Obsidian の設定検索に表示されます。**

### 変更

- **長いパスがペインに収まります。** 名前は役に立たないものから順に短くされます — 保管庫の名前、次に拡張子、そしてフォルダー、ノート自身の名前は最後 — 見分けがつかなくなる手前までで止まります。短くなった名前にポインターを合わせると全体が読めます。
- **ノートの名前をクリックすると拡張子を除いて選択される**ので、名前の変更でファイル形式まで変えてしまう心配がなくなりました。
- **名前変更キーは拡張子を除いた名前で開き**、さらに押すと選択範囲が広がります。
- **フォルダーをクリックしてもパスの残りが見えたまま**になります。保管庫の外でも同じです。
- **保管庫の中へたどり戻ると、ファイルはノートとして開きます**。外部ビューアーではなく、リンクとバックリンクを備えた形で開きます。

### 修正

- **メニューのラベルがどの言語でも英語でした**。Obsidian 自身の翻訳から取るようになりました。
- **ノートがタイトルより下までスクロールされていると、名前変更キーが Obsidian の名前変更ダイアログで行き止まりになっていました。**
- **<kbd>Esc</kbd> が 2 回必要でした** — 入力欄とその一覧を閉じるために。
- **<kbd>Ctrl</kbd>+<kbd>Enter</kbd> がエディター内のリンクを開いていました**。パスバーに作用する代わりに。
- **保管庫の外での名前変更で、南京錠を押すと入力した名前が失われていました。**
- **自身のフォルダーノートと並んでいるフォルダーでは、Tab が進まないまま堂々巡りになることがありました。**

## 1.0.2 — 2026-08-13[^1.0.2]

### 変更

- **Obsidian 1.8.7 以降が必要になりました**（以前は 1.4.0）。パスバーが頼る二つの機能 — ファイルのコピーと、入力欄の下に出るエラーツールチップ — に必要です。
- **リリースのダウンロードには署名付きのビルド証跡が付きます**。`gh attestation verify` で `main.js` がこのリポジトリからビルドされたことを確認できます。

### 修正

- **存在しない外部ファイルを既定のアプリで開こうとすると黙って失敗していました**。失敗が報告されるようになりました。

## 1.0.1 — 2026-08-13[^1.0.1]

### 修正

- **名前変更モードでノートが自分自身と衝突していました** — 自分のフォルダーへたどり戻ると、自分の名前が一覧から隠され、自分自身の名前変更を妨げているかのように見えていました。
- **Obsidian を起動してから最初のフォルダー表示で何も展開されませんでした。**
- **一覧からフォルダーを選ぶと、そこへ下りる代わりに名前変更モードが終わってしまうことがありました。**
- **外部からの編集が、別の書き手 — Sync や二つ目のペインなど — によって黙って上書きされることがありました。** 書き込みはアトミックになりました。
- **フォーカスアウトラインのリセットが他のビューにも漏れていました**。Lure が書き換えたヘッダーにのみ適用されるようになりました。

### ドキュメント

- README と使い方ガイドが、プラグインの備える 44 言語すべてで利用できるようになりました。
- ガイドが Obsidian の *すべてのファイル拡張子を検出* 設定に言及していましたが、現在の名称は *すべてのファイルタイプを表示* です。

## 1.0.0 — 2026-08-10[^1.0.0]

最初のリリース。ノートのヘッダーにあるファイル名を、保管庫内でのパスを示す、クリックも編集もできるパンくずリストに置き換えます — Dolphin にならった、ノートのためのアドレスバーです。

### 追加

- **フォルダーをクリック**すると、その親の中身が一覧で出ます。パスの残りには触れずに、同階層の別のものへ差し替えられます。
- フォルダーの後ろの**区切り文字をクリック**すると、そのフォルダーをファイルエクスプローラーで表示して展開します。Folder notes が担っている場合は、そのフォルダーノートを開きます。
- **ファイル名または空白部分をクリック**するとパスを入力でき、補完が効きます: `/` で下に降り、<kbd>Backspace</kbd> で一段上がり、<kbd>Enter</kbd> で確定します。
- **移動／名前の変更モード**は、同じ操作を移動と名前の変更に切り替えます。検証は Obsidian 自身と同じ方法で行われます。
- **<kbd>Ctrl</kbd> で新しいタブに開きます** — 移動／名前の変更モードでは、代わりにノートをそこへコピーします。
- **<kbd>F2</kbd>** でインラインタイトルとパスバーが交互に切り替わります。
- **保管庫の外**（既定ではオフ）: 保管庫の名前から、他の保管庫・ホーム・ファイルシステムのルート・マウント済みのドライブを開けます。そこにあるものは解除するまで一切書き込まれず、ノートは保管庫の外へコピーできるだけで、移動はできません。
- **45 言語。**
